# Zone Learning Objective

The model should learn zone quality before it learns direct trade outcome.

Primary targets:

- MFE/MAE;
- tail expansion;
- dead-zone filtering;
- time-to-expansion;
- path smoothness;
- stable stop availability;
- child-zone need.
