# No Stop, No Trade

A zone with no stable stop is not an execution zone.

It can still be:

- a watch zone;
- a context zone;
- a parent zone;
- an area for lower-timeframe search;
- a warning area;
- a potential failure scenario.

But it cannot receive a limit order until a stop/expiration edge is defined.
