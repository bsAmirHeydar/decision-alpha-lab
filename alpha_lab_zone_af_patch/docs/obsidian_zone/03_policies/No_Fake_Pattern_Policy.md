# No Fake Pattern Policy

A visual pattern is not useful unless it creates a measurable risk contract.

A pattern is useful only when it defines at least one of:

- movement constraint;
- entry edge;
- expiration edge;
- potential path;
- failure scenario;
- measurable MFE/MAE advantage.

If it cannot define cost and potential, it is not an alpha source.
