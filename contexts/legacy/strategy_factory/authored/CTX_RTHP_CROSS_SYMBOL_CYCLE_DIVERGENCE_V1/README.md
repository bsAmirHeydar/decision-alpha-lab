# CTX_RTHP_CROSS_SYMBOL_CYCLE_DIVERGENCE_V1

Canonical ACL-02 Context package for cross-symbol divergence between corresponding cycle levels. The package is pure Context and contains no Entry, Stop, Target, Sizing, Treatment, or Execution authority. All repository documentation and source translations in this release are English.

- Version: `1.0.2`
- Status: `SEMANTICALLY_VALIDATED`
- Documentation language: `English`
- Artifact: `al://alpha-lab/contexts/context/CTX_RTHP_CROSS_SYMBOL_CYCLE_DIVERGENCE_V1@1.0.2#sha256:abac746292c964be66eed0bb311a8a79e2b7116532a5471d6a1d9b094ea70c37`


## ACL-03 compilation compatibility

Release `1.0.2` adds three non-semantic occurrence identity aliases required by the central ACL-03 compiler:

- `anchor_time` = `confirmation_close_time`
- `direction` = intrinsic `relation_polarity`
- `subject_key` = `symbol_pair_id`

The aliases do not create Entry, Treatment, Execution, order, or capital authority.
