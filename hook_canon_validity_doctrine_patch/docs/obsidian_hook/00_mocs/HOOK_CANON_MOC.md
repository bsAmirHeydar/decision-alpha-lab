# Hook Canon MOC

## Purpose

This Obsidian map is the canonical entry point for the valid Hook doctrine.

The goal is to prevent future implementation patches from mixing:

- Hook counting;
- Hook validity;
- Hook cycle rendering;
- Hook sequence labels;
- Hook zones.

## Implementation order

1. Count all structural Hook sequences.
2. Build Hook origin-groups/cycles.
3. Compute terminal semantics.
4. Assign validity family.
5. Build visible Hook group set.
6. Draw only valid cycles and their labels.
7. Draw nothing if no valid cycle exists.
