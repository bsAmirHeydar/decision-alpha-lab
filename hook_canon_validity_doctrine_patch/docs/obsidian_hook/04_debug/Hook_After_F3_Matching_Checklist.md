# Hook After F3 Matching Checklist

## Valid conditions

- Latest relevant F3 is opposite to Hook direction.
- F3 has formed its flag / F3 structure.
- Hook is born from the terminal side of that F3 environment.
- Hook is not merely a random later Hook after an old F3.

## Debug questions

- Which F3 is considered the latest opposing F3?
- Where is the F3 terminal area?
- Does the Hook origin start from that terminal side?
- Is the Hook direction opposite to the F3?
