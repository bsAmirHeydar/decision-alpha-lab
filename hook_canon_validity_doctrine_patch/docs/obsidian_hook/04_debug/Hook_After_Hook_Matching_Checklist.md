# Hook After Hook Matching Checklist

## Valid conditions

- Hook-1 completed its sequence/cycle.
- Hook-2 is the same kind as Hook-1.
- Hook-2 starts from Hook-1 terminal / death-near endpoint.
- Hook-1 is shown as parent companion.

## Debug questions

- What is Hook-1 structural terminal node?
- What is Hook-1 cycle terminal price/time?
- What is Hook-2 origin node/price/time?
- Are both Hooks the same kind?
- Is Hook-1 only a parent companion, or also independently valid?
