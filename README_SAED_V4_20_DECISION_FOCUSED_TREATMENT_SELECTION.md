# SAED V4-20 — Decision-Focused Treatment Selection

This additive patch implements the V4-20 synthetic reference boundary. It consumes immutable V4-18 policy-value evidence and immutable V4-19 proof envelopes, freezes a closed treatment universe, compiles per-context action masks, computes utility and risk-adjusted candidate scores, builds scenario regret and deterministic Pareto sets, calibrates reference scores, constructs bounded set-valued selections, applies explicit abstention and emits a content-addressed non-executable selection certificate.

## Implemented modules

The Python package includes closed contracts, canonical hashing, treatment-universe compilation, action masks, utility accounting, tail and drawdown risk, uncertainty bounds, scenario regret, decision-focused objectives, Pareto frontier construction, deterministic ranking, reference calibration, set-valued selection, abstention, baseline preservation, budget and exposure ledgers, security scanning, provenance, replay, certificate verification, handoff generation, CLI and an integrated service.

The patch also includes closed JSON schemas and examples, synthetic golden artifacts, negative and mutation fixtures, a complete Obsidian implementation dossier, MQL5 static mirror contracts, full QA orchestration, phase status, inventory, file index, SHA-256 ledger and delivery validation.

## Claim ceiling

Passing local QA establishes deterministic synthetic reference conformance only. It does not establish real policy value, real alpha, production treatment selection, runtime parity, promotion authorization, production authorization or live readiness. MetaEditor compilation and all external operational evidence remain separate gates.
