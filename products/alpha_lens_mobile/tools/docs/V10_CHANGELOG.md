# Alpha Lens Mobile — v10 Changelog

## اصلاحات

1. **زمان ثبت خودکار**
   - فیلد زمان ثبت اضافه شد.
   - مقدار آن همیشه از ساعت فعلی دستگاه خوانده می‌شود.
   - هنگام Snapshot و Export، زمان فعلی داخل داده ذخیره می‌شود.

2. **رفع مشکل ورق‌زدن تایم‌فریم‌ها**
   - منطق carousel بازنویسی شد.
   - دیگر به `scrollLeft` در حالت RTL وابسته نیست.
   - تب‌ها و swipe افقی هر دو تایم‌فریم فعال را تغییر می‌دهند.

3. **فارسی‌سازی لیبل‌ها**
   - متن‌های قابل مشاهده UI فارسی و یکدست‌تر شدند.
   - `Child` در UI به `زیرزون` تبدیل شد.
   - تایم‌فریم‌ها با برچسب‌های کوتاه فارسی نمایش داده می‌شوند.
