# Canonical F Logic

Canonical F Logic is the already-defined F1/F2/F3 grammar of Alpha Lab.

The Zone layer must use this grammar as input. It must not create a second F grammar.

## Canon Rule

```text
F-counting decides what F1, F2, and F3 are.
Zone-AF decides whether a canonical F state creates a usable risk contract.
```
