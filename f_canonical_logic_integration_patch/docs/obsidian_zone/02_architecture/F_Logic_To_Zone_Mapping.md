# F Logic To Zone Mapping

## Mapping Pipeline

```text
Canonical F event
→ lifecycle state
→ movement constraint
→ reversal-potential field
→ zone candidate
→ risk-contract validation
→ child-zone refinement if needed
```

## F1

F1 may create a more direct zone when the F1 waist supplies a meaningful risk reference and the post-flag context allows directional continuation.

## F2

F2 may create broad reversal-potential fields, especially through the canonical waist-break branch:

```text
1 = F2 Waist
2 = node that passes F2 Waist
```

From Point 2 onward, reversal potential can become relevant. Direct execution still requires a stable stop edge, usually from lower-timeframe refinement.

## F3

F3 is usually a broad terminal environment. It is not automatically a direct execution zone. It often needs lower-timeframe refinement or a valid opposing hook after F3.
