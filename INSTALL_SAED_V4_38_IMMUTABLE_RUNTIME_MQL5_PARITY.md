# Install SAED V4-38

1. Place the ZIP patch in the repository root.
2. Expand it with overwrite enabled.
3. Remove the ZIP from the repository root.
4. Run V4-38 full QA and delivery validation.
5. Stage only the paths in `SAED_V4_38_FILE_INDEX.txt`.
6. Check staged diff, commit with `COMMIT_MESSAGE.md`, and push.

V4-37 must already be installed. Actual MetaEditor and MT5 Terminal evidence is intentionally not fabricated by this patch.
