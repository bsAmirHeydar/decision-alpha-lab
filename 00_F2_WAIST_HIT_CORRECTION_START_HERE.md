# F2 Waist-Hit Correction — Start Here

This patch corrects the F2 Case B interpretation inside the Zone-Centric Antifragile Architecture.

## Correction Summary

The previous wording treated the second F2 case as:

```text
F2 forms point 1 and point 2
and also hits the F2 waist
```

The corrected doctrine is more specific and must follow the original F-counting grammar:

```text
F2 can hit its own waist.
That waist-hit can become Point 1.
The next relevant hit/extension becomes Point 2.
From Point 2 and beyond, reversal potential becomes active.
```

This is still usually not a direct parent-timeframe trade because the stop edge is not naturally stable. It is a parent reversal-potential area that requires lower-timeframe refinement before limit execution.

## Primary Rule

```text
F2 waist-hit can re-anchor F2 as Point 1.
Point 2 then activates the reversal field from Point 2 onward/beyond.
No stable parent stop = no direct parent trade.
```
