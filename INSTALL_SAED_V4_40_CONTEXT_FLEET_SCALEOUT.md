# Install SAED V4-40

1. Place the V4-40 ZIP patch in the repository root.
2. Expand it with overwrite enabled.
3. Remove the ZIP from the repository root.
4. Run V4-40 full QA and delivery validation.
5. Stage only paths listed in `SAED_V4_40_FILE_INDEX.txt`.
6. Check the staged diff, commit with `COMMIT_MESSAGE.md`, and push.

SAED V4-39 must already be installed. This patch intentionally distinguishes synthetic fleet-scale evidence from actual external MetaEditor, Terminal, broker and soak evidence.
