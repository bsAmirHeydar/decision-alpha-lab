# Phase 14 deterministic governance fixture

This directory is an immutable reference bundle for model registration, promotion evaluation, registry state transitions, champion assignment, release packaging and rollback planning. All identities are deterministic. The fixture is research governance evidence only and carries no execution or capital authority.

The Python command below regenerates the same semantic bundle:

```powershell
strategy-factory-governance emit-reference .\examples\legacy\strategy_factory\phase14\generated
```
