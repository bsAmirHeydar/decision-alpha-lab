# Install Alpha Lab LCM-16A

Apply from a clean Windows PowerShell session at the repository root. Git LFS must be installed because LCM-12A depends on two large JSONL evidence objects. The release command supplied with the patch performs archive path validation, a temporary overlay, LFS materialization, hash verification, package QA, direct tests, full governed regression, exact staging, commit and push.

Do not use `git add .` or `git add -A`. Do not skip the LFS pointer check. Do not reinterpret MetaEditor or Strategy Tester `UNKNOWN` as PASS.
