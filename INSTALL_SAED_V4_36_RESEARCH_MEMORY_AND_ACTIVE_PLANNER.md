# Install SAED V4-36

1. Place the ZIP patch in the repository root.
2. Expand it into the repository root with overwrite enabled.
3. Remove the ZIP from the repository root.
4. Run full QA and delivery validation.
5. Stage only paths in `SAED_V4_36_FILE_INDEX.txt`.
6. Validate the staged diff, commit with `COMMIT_MESSAGE.md`, and push.

V4-35 must already be installed. All V4-36 capability files are additive; the canonical roadmap note and root commit metadata are updated in place.
