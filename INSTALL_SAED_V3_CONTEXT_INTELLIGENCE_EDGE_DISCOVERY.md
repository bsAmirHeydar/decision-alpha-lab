# Install SAED V3

1. Extract the ZIP into the project root.
2. Stage only paths listed in `SAED_V3_FILE_INDEX.txt`.
3. Review `SAED_V3_QA_REPORT.json`, `SAED_V3_PATCH_MANIFEST.json`, and `SAED_V3_FILE_HASHES.sha256`.
4. Open the V3 Home note in Obsidian.
