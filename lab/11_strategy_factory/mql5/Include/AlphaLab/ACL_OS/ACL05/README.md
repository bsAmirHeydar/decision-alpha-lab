# ACL-05 MQL5 Static Contract Mirror

These headers mirror immutable identities and fail-closed guards for downstream MQL5 integration. They contain no order API, no position sizing, no broker calls and no capital authority. Python JSON artifacts remain canonical. MetaEditor compilation is an environment-specific verification obligation and is not claimed by the reference package.
