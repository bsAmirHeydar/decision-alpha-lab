# MQL5 Execution / Visual Terminal

This folder documents the MT5 side of Decision Alpha Lab.

Current direction:

```text
Python research engine -> CSV visual contract -> MQL5 chart visualizer
```

The MQL source lives in:

```text
mql5/Experts/DecisionAlphaLab/M0001_VisualLab.mq5
```

The exported visual files are generated by:

```text
tools/export_m0001_to_mql.py
```

Default generated CSV path:

```text
mql5/Files/DecisionAlphaLab/M0001/{SYMBOL}_{TIMEFRAME}_visual.csv
```

Copy the CSV into the terminal's `MQL5/Files/DecisionAlphaLab/M0001/` folder and attach the expert to the chart.
