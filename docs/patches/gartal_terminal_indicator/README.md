# Gartal Terminal Indicator Patch

این پچ پوشه محصول `gartal terminal` را به Product Lab اضافه می‌کند.

## اضافه‌شده‌ها

- پوشه کامل اندیکاتور خبری
- داکیومنت Obsidian
- Product Spec
- UI/UX Design System
- Data Source and Parser Model
- Algorithm Architecture
- Inputs Reference
- Alert Engine
- Chart Timeline Model
- Validation Plan
- Release Plan
- Customer Guide Persian draft
- MQL5 scaffold
- Packaging script
- Registry entry

## مسیر اصلی

```text
product_lab/indicators/gartal_terminal/
```

## هدف

ساخت یک اندیکاتور خبری قابل فروش که خبرهای اقتصادی امروز را به شکل داشبورد، timeline، خطوط چارت و alert نمایش دهد.
