# راهنمای فارسی Phase 52

## قرارداد اجرایی

این پروفایل فقط از دو منبع وارد معامله می‌شود:

```text
هوک معتبر بعد از هوک
هوک معتبر بعد از F3 مخالف
```

هوک مثبت سفارش `Buy Limit` و هوک منفی سفارش `Sell Limit` می‌سازد. قیمت سفارش همان terminal خام هوک است:

```text
هوک مثبت: پایین‌ترین دره terminal
هوک منفی: بالاترین قله terminal
```

حد ضرر پشت origin/death هوک با buffer پوینت و اسپرد قرار می‌گیرد. Take Profit ثابت وجود ندارد.

## خروج

بعد از پر شدن لیمیت، معامله تا زمانی نگه داشته می‌شود که یک زنجیره کامل F1 سپس F2 سپس F3 در همان جهت معامله ساخته و F3 تأیید/تکمیل شود.

```text
Buy → خروج با F123 صعودی جدید
Sell → خروج با F123 نزولی جدید
```

در حالت پیش‌فرض، F1 و F2 این زنجیره باید بعد از زمان واقعی بازشدن پوزیشن آغاز شده باشند. بنابراین ساختاری که قبل از ورود شروع شده است، خروج جدید محسوب نمی‌شود.

## ممنوعیت معامله هم‌زمان

برای Magic این استراتژی در کل ترمینال فقط یکی از این دو حالت مجاز است:

```text
یک pending order
یا
یک open position
```

قبل از ارسال سفارش، علاوه بر شمارش سفارش‌ها و پوزیشن‌ها، یک lock سراسری terminal گرفته می‌شود تا دو چارت نتوانند هم‌زمان دو سفارش بفرستند.

## فعال‌سازی

برای مشاهده بدون ارسال:

```text
InpNDSHookTradeEnabled = true
InpNDSHookTradeSendLiveOrders = false
```

برای ارسال واقعی روی حساب آزمایشی/کنترل‌شده:

```text
InpNDSHookTradeEnabled = true
InpNDSHookTradeSendLiveOrders = true
```

هر دو گزینه به‌صورت پیش‌فرض `false` هستند.
