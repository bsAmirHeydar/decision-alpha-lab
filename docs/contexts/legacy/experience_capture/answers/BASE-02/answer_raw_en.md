# BASE-02 — Raw Answer

## Topic

Definition of scenario.

## Original Experience, translated to English

A scenario means that we must bring reasons for the states I described earlier and then compare them.

That means we try to build a bullish case.

Then, for the bullish case, we ask:

- What bullish reasons come from Hook?
- What bullish reasons come from Rally?

Then we do the same for the bearish side.

First, we look broadly.

After that, we build the scenario around possible entry location.

This must be done with fractal context.

For example:

If the higher timeframe is bullish, then an F3 bearish move on the lower timeframe can be a good place for a bullish entry.

So the whole process is multi-sided analysis.

Naturally, based on the schematics and market anatomy that we have, there are places that invalidate each scenario.

Each scenario has its own invalidation based on our base market anatomy.

The process has three important layers:

1. First, we talk about direction.
2. Then, we talk about the approximate good zone for entry.
3. Then, we talk about the exact entry point.

These three layers are very important.
