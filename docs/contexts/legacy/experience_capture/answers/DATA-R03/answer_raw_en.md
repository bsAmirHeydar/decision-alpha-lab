# DATA-R03 — Raw Answer

## Topic

Layered training, context-zone-entry learning sequence, knowledge consolidation, reusable trained infrastructure, human inspectability, and training as capital.

## Original Experience, translated to English

I will say the important things very simply.

I want to make the training layered, in the same way that we once built the anatomy and it became our infrastructure. We should train layer by layer and then use the knowledge from each layer for the next layers.

But the issue is that I want this trained knowledge to remain and become stabilized, so that we do not start the game from zero every time. Some issues should become finished and solved forever.

Therefore, the system should go experience the market in three layers:

Context.

Zone.

Entry.

These should be separate. First context. The first two are fractal. The third is only one timeframe.

So I want to complete the context layer first, in a way that I can understand what it learned, correct its problems, and even learn from it myself. Then we optimize the algorithms and make its context view correct first. Then we go to the next layer and then the next.

Overall, I think infrastructurally. I want every part I build to become capital for me.
