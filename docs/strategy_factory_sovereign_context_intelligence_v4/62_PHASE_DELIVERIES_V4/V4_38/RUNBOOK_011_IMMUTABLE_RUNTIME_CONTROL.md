# SAED V4-38 — Immutable Runtime Control Runbook 011

This **research-only** runbook operationalizes immutable bundle compilation, parity evidence isolation, fail-closed fallback and baseline preservation.

## Preconditions

- V4-37 certificate and handoff hashes are verified.
- Feature, model, policy, output and state ABIs are frozen.
- The compiler has no network, environment-variable or wall-clock dependency.
- The bundle hash and file manifest are known before any replay.

## Procedure

1. Rebuild from the canonical fixture in a clean workspace.
2. Compare bundle hash, file Merkle root and generated source hashes.
3. Run Python golden and mutation tests.
4. Run MQL5 static authority checks.
5. Record MetaEditor and Terminal evidence only when generated by the actual external environment.
6. On any discrepancy, quarantine the candidate and preserve the manual baseline.

## Failure action

ABSTAIN, preserve the baseline, seal the incident evidence, and escalate to runtime engineering, MQL5 review, model risk and independent validation.
