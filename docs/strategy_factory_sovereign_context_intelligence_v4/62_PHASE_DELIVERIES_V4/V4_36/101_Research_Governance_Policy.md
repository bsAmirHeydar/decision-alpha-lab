# V4-36 Delivery 101 — Research Governance Policy

## Purpose

This delivery freezes **Research Governance Policy** as a first-class component of the sovereign research-memory and active-planning layer. The component is additive, deterministic, known-time bounded, evidence-backed and subordinate to the existing UCEE, model-risk and production-authority boundaries.

## Contract

The corresponding artifact uses canonical serialization, immutable identity, SHA-256 content binding, closed JSON schema validation and explicit lineage. Unknown fields, future-known records, hidden negative results, destructive memory updates, unresolved authority, missing owners, unbound approvals and budget overruns fail closed.

## Operating invariant

Memory is append-only; correction occurs through explicit supersession rather than silent rewriting. Negative results, limitations, incidents and risk findings remain retrievable. The planner may rank and schedule research proposals for human review but cannot start experiments, mutate UCEE, select treatments, allocate capital, compile live runtime or submit orders.

## Verification

Verification covers deterministic replay, future-suffix isolation, semantic duplicate rejection, contiguous hash chains, evidence coverage, contradiction visibility, negative-knowledge retrieval, budget accounting, protected exploration and replication floors, prerequisite ordering, human quorum, independent challenge and baseline preservation.

## Failure semantics

Missing evidence, duplicate memory without supersession, blocking contradiction, stale or future-known records, risk hard-limit violation, infeasible budgets, dependency cycles, missing independent review or authority escalation causes rejection, abstention and preservation of the existing baseline. No implicit downgrade or automatic waiver is allowed.

## Evidence boundary

The accepted evidence is a synthetic deterministic reference. Real longitudinal memory migration, external semantic retrieval, external literature connectors, real compute scheduling, external committee approval, MetaEditor compilation, Python/MQL5 runtime parity, prospective success and production authorization remain separate external gates.

## Handoff

The artifact contributes only immutable memory identity, negative knowledge, evidence coverage, bounded research agenda, budget and risk constraints to V4-37. It transfers no execution, capital, treatment, runtime, promotion or production authority.
