# Atomic Rule — Stream Version Is Immutable

## Definition

Stream Version Is Immutable is an atomic institutional rule of SAED V4-03. Violating it invalidates the affected event evidence or forces a fail-closed state.

## Consequence

The rule must be visible in contracts, tests, telemetry and review packets. It cannot remain an informal convention.
