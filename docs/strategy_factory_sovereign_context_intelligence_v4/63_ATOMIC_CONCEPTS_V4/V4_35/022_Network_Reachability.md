# SAED V4-35 Atomic 022 — Network Reachability

**Definition.** Network Reachability is an explicit immutable control object, not an informal checklist item.

**Invariant.** It remains deterministic, closed-schema, known-time safe, lineage-complete, independently reviewable and incapable of granting trading or production authority.

**Failure action.** Reject the artifact, quarantine the subject, expire the waiver, stop distribution, preserve evidence and retain the existing baseline. Silent acceptance is forbidden.

**Evidence.** The minimum evidence is a content hash, source identity, owner, known-time cutoff, validation receipt and governance disposition. External claims remain false until real third-party or runtime evidence is attached.

**Integration.** The concept is additive to UCEE and is passed to V4-36 only as immutable research memory. No execution authority crosses the handoff.
