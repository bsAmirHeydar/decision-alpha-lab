# Runtime Parity Is Not Broker Qualification

**Invariant.** Runtime Parity Is Not Broker Qualification. This invariant is enforced in the V4-28 closed reference through known-time ordering, exact contracts, canonical hashes, deterministic replay, and explicit authority denial. A violation invalidates the local evidence bundle or forces a safe `skip`; it never creates a model-selection, runtime, risk, or execution entitlement.
