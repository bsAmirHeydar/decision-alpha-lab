# Exposure Counts Need A Ledger

## Atomic statement

**Exposure Counts Need A Ledger.** This statement is a non-negotiable invariant of the V4-25 research boundary.

## Meaning

V4-25 studies how frozen knowledge can be transferred across chronological context tasks without silently importing future information, protected query outcomes, unsupported similarity assumptions, or production authority. The invariant keeps the manual baseline recoverable, makes every transfer edge auditable, and requires unsupported paths to return to `scratch_baseline`.

## Engineering consequence

The invariant is represented in exact-field contracts, closed JSON schemas, deterministic Python logic, negative and mutation tests, content-addressed golden artifacts, and static MQL5 mirrors. A challenger implementation is acceptable only when it preserves the same known-time, budget, fallback, and authority semantics.

## Failure mode prevented

Without this invariant, meta-learning can become a channel for evaluation leakage, negative transfer, catastrophic forgetting, uncontrolled online mutation, or false claims of production readiness. V4-25 treats those outcomes as evidence failures rather than optimization trade-offs.
