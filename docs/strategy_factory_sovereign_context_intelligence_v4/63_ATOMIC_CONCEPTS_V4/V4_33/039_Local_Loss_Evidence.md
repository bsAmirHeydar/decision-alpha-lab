# SAED V4-33 Atomic 039 — Local Loss Evidence

**Atomic rule:** Local Loss Evidence is independently testable and cannot be inferred from a neighboring artifact. Its identity, inputs, outputs, failure action and claim ceiling remain explicit.

A mutation that violates this rule must be rejected or quarantined before aggregation or certificate issuance.
