# Incidence Mask

## Definition

A visible indicator that an edge contains one or more masked members. It is not a negative relation and cannot be interpreted as evidence against a Treatment.

## Invariants

- The concept is subordinate to source package integrity, bitemporal visibility, Evidence Role isolation, exact registry and policy versions, and UCEE authority.
- It cannot silently create canonical truth, fit adaptive statistics, learn a relation, generate or select a Treatment, allocate risk, activate runtime, or send an order.
- Unsupported or contradictory states remain explicit and fail closed.
