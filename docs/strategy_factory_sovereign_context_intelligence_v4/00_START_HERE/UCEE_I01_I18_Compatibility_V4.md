# UCEE compatibility

SAED V4 is additive to UCEE I01–I18. It consumes immutable Context and evidence contracts and returns bounded candidate policies.

| UCEE phase | SAED V4 dependency |
|---|---|
| I01–I05 | canonical identity, known-time and context truth |
| I06–I10 | feature/view contracts, outcome truth, datasets and folds |
| I11 | experiment and trial orchestration |
| I12 | statistical promotion and admission |
| I13 | manual/AI/hybrid authority, fallback and abstention |
| I14 | immutable runtime and MQL5 parity |
| I15 | context treatment tournament |
| I16 | scalable context onboarding |
| I17 | risk, capacity and portfolio allocation |
| I18 | release, operations and recovery |

SAED V4 modifies none of these central authorities.
