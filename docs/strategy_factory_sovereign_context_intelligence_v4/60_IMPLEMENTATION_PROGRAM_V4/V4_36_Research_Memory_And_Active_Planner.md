# Phase V4-36: Research Memory And Active Planner

## Mission

Implement a deterministic, append-only and evidence-bound research-memory system plus a human-governed active planner. The phase captures hypotheses, experiments, results, negative findings, claims, limitations, incidents, models, datasets, decisions and unanswered questions without allowing destructive updates or hidden failures.

## Completed engineering slices

1. Immutable V4-35 certificate and handoff binding.
2. Twenty-clause research-memory and planner constitution.
3. Closed memory contracts, semantic fingerprints, explicit supersession and hash-chain/Merkle integrity.
4. Evidence registry, lineage, independent evidence and coverage accounting.
5. Mandatory negative-knowledge preservation and retrieval.
6. Claim, contradiction, evidence-gap and knowledge-state registries.
7. Deterministic lexical retrieval with query receipts and no network access.
8. Compute, exposure, review and risk budgets with reserves.
9. Value-of-information scoring with novelty, replication, negative-knowledge and coverage dimensions.
10. Risk hard limits, protected floors, fail-closed deterministic selection and prerequisite-aware wave scheduling.
11. Human quorum, independent challenge, risk and negative-knowledge review.
12. Baseline preservation, evidence bundle, certificate and bounded V4-37 handoff.
13. Golden/negative fixtures, closed schemas, mutation tests, MQL5 static mirror and Obsidian corpus.

## Acceptance gates

- Zero unknown fields in closed contracts.
- No future-suffix sensitivity.
- Deterministic identity, retrieval, scoring, selection and replay.
- Complete memory/evidence/exposure accounting.
- Negative results and limitations cannot be deleted or hidden.
- Baseline preserved and automatic execution denied.
- UCEE compatibility and no central-engine mutation.
- External scheduler, MetaEditor and runtime evidence remain explicitly separate.

## Claim ceiling

The accepted implementation is a synthetic deterministic research-memory and agenda reference. It does not claim real semantic embedding retrieval, real longitudinal migration, real experiment scheduling, prospective market success, runtime parity, production authorization or live trading.
