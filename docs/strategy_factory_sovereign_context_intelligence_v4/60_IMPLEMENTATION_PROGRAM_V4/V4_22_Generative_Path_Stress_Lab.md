# Phase V4-22: Generative Path Stress Lab

## Mission

Build an additive, closed-contract and independently reproducible generative path laboratory for stress discovery and robustness falsification. Synthetic paths remain explicitly watermarked and cannot create positive promotion evidence.

## Implemented engineering slices

1. Immutable and hash-verified V4-21 intake.
2. Closed state, generator, invariant, stress, fidelity, exploitability and budget contracts.
3. Deterministic moving-block, regime-Markov, latent-linear ensemble and residual-flow reference generators.
4. Watermarked native rollout sets with source lineage and action masking.
5. Gap, volatility, liquidity, spread, chop, regime and execution stress composition.
6. Market invariant enforcement and quarantine semantics.
7. Multi-dimensional fidelity, distinguishability and trusted-horizon diagnostics.
8. Real-replay simulator-exploitation challenge.
9. Budgeted adversarial failure search.
10. Content-addressed certificate, replay receipt, evidence bundle and V4-23 handoff.

## Acceptance state

The local deterministic synthetic reference is accepted. Actual MetaEditor compilation, Python/MQL5 runtime parity, real-market generative fidelity, prospective success, real alpha and production authorization remain outside this evidence class.

## Non-goals

This phase does not authorize treatment selection, risk allocation, runtime compilation, order submission or live adaptation. Synthetic gains cannot be presented as empirical edge.

## Handoff

The next phase is [[V4_23_Offline_Policy_Research|V4-23 Offline Policy Research]]. It may consume only immutable real replay plus labeled synthetic stress challenge artifacts and must preserve every authority denial.
