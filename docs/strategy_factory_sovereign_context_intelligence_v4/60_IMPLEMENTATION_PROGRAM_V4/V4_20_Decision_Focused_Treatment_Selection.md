# Phase V4-20: Decision-Focused Treatment Selection

## Mission

Implement a closed, deterministic and auditable research layer that maps frozen V4-18 policy-value evidence and V4-19 proof-carrying setup reasoning into constrained treatment rankings, Pareto sets, set-valued selections and explicit abstention. The phase remains additive and preserves UCEE authority.

## Implemented engineering slices

1. Closed decision-problem, treatment-universe, utility, constraint, risk, selection-policy and budget contracts.
2. Immutable treatment-universe compiler and per-context proof/support/overlap action masks.
3. Net utility, lower-confidence utility, CVaR, ambiguity, complexity, turnover, tail and drawdown accounting.
4. Scenario regret, minimax-regret summaries, deterministic Pareto frontier and decision-focused hybrid objective.
5. Deterministic ranking, reference calibration, bounded set-valued selection and entropy/margin measurement.
6. Proof, support, uncertainty and baseline-preservation abstention with canonical Skip fallback.
7. Content-addressed non-executable selection certificate, replay receipt, provenance and exposure ledger.
8. Golden, negative, mutation, future-suffix and baseline-preservation fixtures.
9. Python reference implementation, MQL5 static mirror, closed schemas, QA tooling and Obsidian dossier.
10. Narrow research-only handoff to V4-21 Robust Optimization and Regret.

## Acceptance boundary

The implementation proves local deterministic synthetic conformance only. It does not establish real policy value, real alpha, production treatment selection, runtime parity, promotion authorization, production authorization or live readiness. External qualification remains mandatory.
