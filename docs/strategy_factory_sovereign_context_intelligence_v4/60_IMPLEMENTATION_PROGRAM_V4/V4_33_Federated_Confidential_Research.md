# Phase V4-33: Federated Confidential Research

## Mission

Construct a closed, deterministic and independently reproducible reference layer for cross-cell research without centralizing row-level data. The phase binds sovereign cell identity, residency, protocol eligibility, local manifest evidence, clipped update commitments, bounded privacy accounting, threshold aggregation, robust screening, cross-cell provenance, exposure accounting, human release review and a zero-authority certificate.

## Claim ceiling

This phase is a synthetic single-process reference. It does not claim real cryptographic confidentiality, secure multiparty computation, formal differential privacy, network transport security, hardware attestation, Byzantine-fault tolerance, prospective alpha, runtime parity, broker qualification or production authorization.

## Engineering architecture

1. Immutable V4-32 certificate and handoff binding.
2. Federated constitution and deny-by-default export policy.
3. Sovereign cell identity and jurisdiction/residency registry.
4. Closed protocol and message-type registry.
5. Known-time federated study specification.
6. Local data manifest and training receipt boundary.
7. Clipping and privacy-budget accounting.
8. Commitment-only secure-update envelope reference.
9. Threshold aggregation and dropout accounting.
10. Robust outlier quarantine with incident preservation.
11. Global research-model receipt with no runtime authority.
12. Federated provenance and complete exposure ledgers.
13. Human checkpoints, adversarial review and fail-closed certificate.
14. Bounded handoff to V4-34 Sovereign Distributed Compute.

## Acceptance

All closed schemas, mutation tests, future-suffix invariance, deterministic replay, raw-data residency, privacy-budget accounting, threshold aggregation, provenance, exposure, MQL5 static mirrors and documentation checks must pass. External evidence remains explicitly unclaimed.
