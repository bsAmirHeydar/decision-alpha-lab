# Dataset Contract Template

## Required Fields

```markdown
# Dataset [ID]
- Owner / Producer / Consumers
- Schema version
- Row grain
- Primary key
- Field dictionary with type, unit, null, availability
- Timezones and cutoffs
- Sort order
- Lineage
- Retention
- Compatibility and migration
- Validation commands
```
