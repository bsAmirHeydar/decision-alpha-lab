# Python Coding Standard

Use type hints, dataclasses for contracts, `pathlib`, explicit CLI/config, deterministic seeds/order, UTC, no import side effects, and pytest/unittest coverage. Notebooks call tested modules; they do not hold hidden canonical logic.
