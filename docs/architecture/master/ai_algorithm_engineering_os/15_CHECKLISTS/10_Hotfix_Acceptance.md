# Hotfix Acceptance Checklist

- [ ] Exact first causal failure reproduced.
- [ ] Patch is minimal and bounded.
- [ ] Cascading diagnostics disappear after root fix.
- [ ] Relevant adjacent modules recompile/test.
- [ ] Regression check added.
- [ ] Rollback is executable.
- [ ] Follow-up debt is separate and owned.
