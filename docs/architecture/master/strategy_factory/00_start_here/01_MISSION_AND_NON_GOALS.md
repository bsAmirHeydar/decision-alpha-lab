# Mission, Scope, and Non-Goals

The factory maximizes the speed with which a market view can be converted into a falsifiable and executable strategy without sacrificing causality, statistical discipline, or operational safety.

## Mission

The system must compress the repeated work after anatomy formalization. Once an anatomy engine can emit stable events, the factory should automatically create candidate executions, label outcomes, produce statistics, train models, compare baselines, run anti-overfit controls, and carry approved decisions into paper and live environments. The output is not merely a backtest. It is a chain of evidence with identities, lineage, rollback, and explicit execution authority.

## What remains strategy-specific

Only five areas may normally vary by strategy: the anatomy adapter, anatomy-specific features, invalidation semantics, allowed candidate policies, and anatomy-specific null/placebo tests. If a new strategy requests a private walk-forward engine, private model registry, private paper broker, or private risk engine, the request is presumptively rejected.

## Non-goals

The factory does not invent market doctrine, guarantee alpha, choose an ontology, or allow an LLM to rewrite canonical definitions. It does not make random search respectable through automation. It does not turn every detectable event into a trade. It does not equate a high in-sample score with economic value. It does not bypass broker constraints or human promotion approval.

## Speed doctrine

Speed comes from standardization, prebuilt policies, shared artifacts, and aggressive negative testing—not from skipping evidence. The target is to make the first strategy expensive to build and every later strategy cheap to connect. The fastest valid route is: adapter → standard event table → bounded candidate matrix → outcome table → baseline → purged OOS → paper. Anything that does not shorten this route must justify itself.
