# Dependence, Clustering, and Bootstrap

Market observations are serially and cross-sectionally dependent; ordinary row bootstrap and textbook standard errors are often false precision.

## Cluster bootstrap

Resample entire market-event clusters. For time dependence, resample day or moving blocks. Compare intervals from row, cluster, and block methods; use the widest defensible interval for promotion.

## Effective sample size

Report unique days, sessions, clusters, and regimes alongside rows. Candidate count does not increase evidence when all candidates derive from one event.

## Concentration

Measure contribution by day, week, event cluster, symbol, and tail trade. A strategy whose profit comes from a few related episodes is a hypothesis about those episodes, not a general edge.
