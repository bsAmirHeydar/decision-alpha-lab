# Golden Fixture Standard

Fixtures are immutable, small enough for review and broad enough to represent edge behavior. Every fixture records data source, timezone, availability, symbol metadata, expected events, expected state and prohibited outputs.

Synthetic fixtures prove mechanics. Historical fixtures characterize behavior. Prospective evidence remains outside migration claims.
