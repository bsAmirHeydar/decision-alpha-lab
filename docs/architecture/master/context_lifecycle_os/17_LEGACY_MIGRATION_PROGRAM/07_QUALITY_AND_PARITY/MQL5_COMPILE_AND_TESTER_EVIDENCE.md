# MQL5 Compile and Strategy Tester Evidence

For each cutover candidate record MetaEditor build, source digest, include graph, compile warnings/errors, output digest, terminal build, symbol specification, tester mode, data range, timezone/session assumptions and journal artifacts.

Linux static checks do not substitute for MetaEditor or MT5 Strategy Tester evidence. Unavailable tooling is reported as UNKNOWN and blocks runtime cutover where relevant.
