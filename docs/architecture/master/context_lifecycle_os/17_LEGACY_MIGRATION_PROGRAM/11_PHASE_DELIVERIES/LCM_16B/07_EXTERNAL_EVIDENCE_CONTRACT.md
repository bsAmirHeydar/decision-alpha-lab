# External evidence contract

The exact dimensions are Git LFS materialization, clean MetaEditor compilation, Strategy Tester golden replay, terminal-compiled parity and out-of-repository external-consumer reachability. The dimension set is closed; omitting a dimension or adding an ungoverned substitute fails.

Evidence files are hash-bound under an explicit evidence root. Relative path escape, missing logs, absent journals, nonzero compiler errors, parity mismatches and unresolved consumers fail closed.
