# LCM-09A — Moc

This document is part of LCM-09A freeze `SETUPFREEZE_8638449DF9A774634FE9B8F9E17EF891`. It is authoritative for the reference migration evidence produced by this patch, but it does not authorize runtime, live orders, capital activation, consumer cutover, source movement, source deletion, semantic merging or treatment extraction. UNKNOWN is preserved as a blocking state.

## Engineering record

The frozen baseline contains 60 provisional Setup identities, 6 family groupings that explicitly do not imply semantic equivalence, 60 variant records, 60 blocked canonical contract shells and 117 unresolved embedded candidates. Source hashes are immutable evidence. Static lexical findings are not behavioral proof.

## Non-compensatory controls

- A missing named owner blocks implementation.
- Missing observed characterization blocks semantic normalization.
- A blocked Context cannot be referenced as canonical.
- Treatment binding remains pending LCM-10.
- Broker, drawing and quota surfaces are boundary findings, not Setup semantics.
- Similar names, output shapes or family labels do not authorize merge.

## Verification

Verification is bound to the package manifest, per-record content digests, root SHA-256 ledger, exact patch index, hostile review and clean-overlay installation. Failure in any mandatory gate prevents expansion of authority.
