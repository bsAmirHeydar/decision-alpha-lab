# LCM-00 Event Ledger

Eight closed event types record constitution binding, scope freeze, repository capture, authority recording, manifest creation, restore rehearsal, verification, and handoff preparation. Each event includes the previous digest and denies move, deletion, semantic-change, execution, and capital authority.
