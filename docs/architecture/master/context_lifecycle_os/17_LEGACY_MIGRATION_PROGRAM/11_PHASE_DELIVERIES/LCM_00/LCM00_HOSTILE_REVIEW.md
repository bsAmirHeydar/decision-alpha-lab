# LCM-00 Hostile Review

Review assumes the repository may omit host-local files, Git history, submodules, LFS objects, terminal-local assets, symlinks, binary dependencies, or emergency hotfix branches. It tests path traversal, undeclared additions, content tampering, role conflict, permit escalation, event tampering, and incomplete restore claims.
