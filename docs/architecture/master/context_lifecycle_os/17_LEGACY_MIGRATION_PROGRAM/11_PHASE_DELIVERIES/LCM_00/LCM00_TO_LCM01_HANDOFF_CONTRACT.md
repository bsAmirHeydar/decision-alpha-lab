# LCM-00 to LCM-01 Handoff Contract

LCM-01 may survey, register discovered artifacts, report scope drift, and propose ownership. It must consume the exact baseline manifest digest and preserve all blockers. It cannot move, delete, merge, refactor, cut over, quarantine, authorize runtime, submit orders, or activate capital.
