# LCM-00 External Asset Register

Artifacts not contained in the repository tree are recorded by class and remain unresolved until a verified locator, digest, retention owner, and restoration method exist. Host-local MQL5 files, terminal state, broker-local state, external model objects, and the Git object database cannot be assumed recoverable from the source archive.
