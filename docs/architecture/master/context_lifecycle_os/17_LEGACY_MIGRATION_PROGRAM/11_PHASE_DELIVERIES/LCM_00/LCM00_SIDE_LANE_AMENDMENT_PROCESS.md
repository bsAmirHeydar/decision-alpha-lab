# LCM-00 Side-Lane Amendment Process

Urgent fixes during migration must identify the baseline, path, old digest, new digest, semantic classification, affected identities, rationale, approvals, and re-characterization obligation. Semantic and security changes cannot be labelled documentation-only.

The original baseline manifest is never edited.
