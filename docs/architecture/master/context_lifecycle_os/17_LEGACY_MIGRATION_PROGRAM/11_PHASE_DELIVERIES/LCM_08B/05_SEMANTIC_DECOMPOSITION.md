# Semantic Decomposition

The legacy file contains data normalization, alignment, reference resolution, trigger evaluation, occurrence generation, research outcome calculation, CLI orchestration, and file output. LCM-08B places normalization through occurrence generation in the context core. Outcome statistics and exact legacy event projection remain adapter-only research behavior. CLI and output files are not context semantics.
