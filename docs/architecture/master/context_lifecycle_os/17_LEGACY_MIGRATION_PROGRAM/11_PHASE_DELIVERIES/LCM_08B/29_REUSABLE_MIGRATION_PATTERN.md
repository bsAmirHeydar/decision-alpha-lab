# Reusable Migration Pattern

Reusable process: bind immutable source, split context from projections, author contracts before implementation, freeze adversarial fixtures, compare every hard field, preserve UNKNOWNs, forbid consumer cutover, publish a digest-bound handoff. The process is reusable; EXP0015 domain semantics are not.
