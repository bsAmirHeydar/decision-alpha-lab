# Prohibited Domain Generalization

Do not infer that other intermarket engines share the same session, reference, trigger, alignment, lag, validity, bias, or outcome semantics. Do not merge the Python pilot with MQL5 EXP0015 identities based on naming. Each identity must be separately characterized.
