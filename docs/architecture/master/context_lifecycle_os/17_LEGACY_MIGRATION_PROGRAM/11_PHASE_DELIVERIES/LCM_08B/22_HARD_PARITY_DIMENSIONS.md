# Hard Parity Dimensions

Every legacy event field is hard: count, ordering, identity, timestamps, side, bias annotation, configuration echoes, reference values and indices, break values, validity, late confirmation, outcomes, bars-to-extreme, and note text. No tolerance is used because the canonical implementation executes the same floating-point operations.
