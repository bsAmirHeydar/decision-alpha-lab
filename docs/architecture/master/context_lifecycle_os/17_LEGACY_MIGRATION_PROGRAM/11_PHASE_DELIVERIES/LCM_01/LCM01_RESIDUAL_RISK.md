# LCM-01 Residual Risk

Residual risk includes dynamic registration not visible statically, MQL5 preprocessor aliases, generated code, binary semantics, inactive/commented capability tokens, external dependencies, files with Python parse failures, documentation links with ambiguous stems and runtime consumers outside the repository.

These risks are carried into LCM-02 and later characterization phases. They are not waived by survey completeness.
