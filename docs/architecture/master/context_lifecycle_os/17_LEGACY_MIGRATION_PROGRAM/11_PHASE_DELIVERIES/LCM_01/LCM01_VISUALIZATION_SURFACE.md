# LCM-01 Visualization Surface

Drawing and chart-callback indicators identify files that may own chart objects, synchronization or user-visible evidence. These are candidates for visualizer separation in LCM-11.

LCM-01 does not assume drawing is semantically passive. Hidden signal generation inside drawing code remains a specific hostile-review risk.
