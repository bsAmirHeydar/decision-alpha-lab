# LCM-01 Configuration Reference Survey

Path-like strings are extracted from JSON, JSONL, YAML, TOML, INI, PowerShell and MQL5 set files under frozen size limits. Candidate references are resolved against root-relative and source-relative paths.

The reference survey records 12,731 configuration-reference edges. Static strings may be examples, templates or inactive values; reachability is not inferred.
