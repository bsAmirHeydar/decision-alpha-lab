# LCM-01 Exact-File Duplicate Survey

The survey groups files by exact SHA-256 and size, producing 1,251 duplicate groups across the whole baseline.

Byte equality does not imply semantic identity, shared ownership, safe path removal or equivalent external references. Automatic merge and delete authority remain false.
