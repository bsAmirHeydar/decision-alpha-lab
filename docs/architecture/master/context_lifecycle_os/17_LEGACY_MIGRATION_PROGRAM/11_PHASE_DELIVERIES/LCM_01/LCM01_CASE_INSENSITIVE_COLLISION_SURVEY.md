# LCM-01 Case-Insensitive Collision Survey

Case-folded paths are grouped to detect repositories that are distinct on a case-sensitive filesystem but collide on Windows. The reference survey reports 0 collision groups.

A zero count applies only to the frozen baseline and does not authorize future renaming without re-running the check.
