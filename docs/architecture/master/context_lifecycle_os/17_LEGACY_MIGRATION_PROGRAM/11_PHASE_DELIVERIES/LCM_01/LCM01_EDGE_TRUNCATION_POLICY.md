# LCM-01 Edge-Truncation Policy

Per-file edge limits prevent pathological documents or configuration artifacts from exhausting survey resources. Every truncation records observed count, retained count and reason.

A truncated scan is not complete evidence. The affected file remains explicitly blocked from claims requiring exhaustive dependency coverage.
