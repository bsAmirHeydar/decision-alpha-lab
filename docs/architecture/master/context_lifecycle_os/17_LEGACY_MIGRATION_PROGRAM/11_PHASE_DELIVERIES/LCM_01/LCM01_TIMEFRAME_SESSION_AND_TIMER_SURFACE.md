# LCM-01 Timeframe, Session and Timer Surface

Timeframe access, session/DST terms and timer APIs are indexed because they can encode known-time, closed-bar, RTH, New York and periodic-refresh behavior.

Static terms do not identify the actual causal clock. LCM-04 must characterize bar selection, event ordering, session boundaries and restart behavior before any refactor.
