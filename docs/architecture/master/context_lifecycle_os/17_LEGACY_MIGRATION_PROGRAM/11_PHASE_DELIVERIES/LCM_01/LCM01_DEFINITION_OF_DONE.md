# LCM-01 Definition of Done

LCM-01 is done when every LCM-00 baseline path appears exactly once in inventory; all enabled scanner stages have valid receipts; dependency and capability views are published; unknowns are explicit; root/documentation/duplicate/path reports exist; package events and provenance verify; deterministic replay matches; no source file was moved or deleted; and the LCM-02 handoff forbids destructive actions.

Completion does not require resolving every edge or owner. It requires preserving those unknowns without overstating evidence.
