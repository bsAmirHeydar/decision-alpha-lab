# LCM-01 Semantic-Role Candidate

LCM-01 proposes coarse roles such as MQL5 compile unit, MQL5 include module, Python source, test source, documentation, configuration/data contract, binary package, root release metadata or unknown.

Context, Setup, Treatment, visualizer and adapter roles are deliberately not finalized from filename or extension alone. Those require LCM-02 classification and owner evidence.
