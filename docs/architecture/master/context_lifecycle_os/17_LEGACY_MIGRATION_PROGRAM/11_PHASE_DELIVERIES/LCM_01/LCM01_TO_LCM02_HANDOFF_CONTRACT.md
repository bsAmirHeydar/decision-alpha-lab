# LCM-01 to LCM-02 Handoff Contract

LCM-02 may classify surveyed artifacts, propose ownership, register canonical identities, register legacy aliases and resolve survey unknowns. It must use the exact Survey ID and summary digest.

LCM-02 may not move or delete sources, semantically refactor, merge implementations, cut over consumers, quarantine paths, authorize runtime, submit live orders or activate capital.
