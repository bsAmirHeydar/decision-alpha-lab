# LCM-01 Source-Layer Lineage

LCM-00 records the archive layer and source member from which each baseline file was restored. LCM-01 preserves that lineage in the inventory rather than treating the restored path as the only provenance.

Source-layer frequency is summarized in the survey. Lineage does not prove semantic authority, but it is required for rollback, duplicate analysis and later ownership resolution.
