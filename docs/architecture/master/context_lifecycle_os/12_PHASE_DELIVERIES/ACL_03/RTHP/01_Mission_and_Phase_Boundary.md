# Mission and Phase Boundary

The purpose of this phase is to transform the exact ACL-02 RTHP package into deterministic, closed, non-trading compiler artifacts consumable by later lifecycle phases.

## In scope

1. Freeze the exact Context source.
2. Bind ACL-00 compile authority to the exact artifact identity.
3. Bind semantic-owner and independent-review approval to the exact source snapshot.
4. Compile Detector IR, Occurrence IR, Known-Time Guard IR, and Feature-Binding IR.
5. Emit least-privilege adapter contracts.
6. Compile and replay all golden cases.
7. Publish onboarding state, lineage, receipt, schemas, and a bounded ACL-04 handoff.
8. Produce RTHP-specific SAED/UCEE binding contracts without granting training authority.

## Out of scope

- Runtime market-data acquisition and adapter qualification.
- Statistical evaluation, labels, outcomes, model training, or edge claims.
- Setup generation or Treatment search.
- Entry, Stop, Target, Risk, Position Sizing, Execution, order submission, or capital activation.

## Claim ceiling

`CONTEXT_COMPILATION_AND_ONBOARDING_REFERENCE_ONLY`
