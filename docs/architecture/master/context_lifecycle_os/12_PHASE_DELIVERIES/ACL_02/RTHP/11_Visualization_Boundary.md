# 11 Visualization Boundary

Visualization is downstream of Context truth. A historical line may remain visible after an event is resolved, but drawing persistence cannot keep the Context event active and cannot modify Context state.

Chart objects are never evidence authority. Context state must be rebuilt from the event ledger and canonical projections, not from drawings.
