# 01 Context Boundary

The package records only observable cross-symbol relationships, versioned cycles, corresponding levels, touch facts, synchronized evaluation time, state transitions, data sufficiency, and provenance.

The following are explicitly out of scope: Entry, Treatment, Execution, Stop, Target, Risk, Position Size, Trade Management, Win Rate, and any guarantee that a reversal will occur.
