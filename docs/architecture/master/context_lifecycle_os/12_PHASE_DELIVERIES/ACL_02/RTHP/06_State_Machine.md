# 06 State Machine

A corresponding level pair progresses through `UNTOUCHED_BOTH`, `ONE_SIDE_TOUCHED`, `DIVERGENCE_CONFIRMED`, `BOTH_SIDES_TOUCHED`, and `REFERENCE_EXHAUSTED` as applicable.

High and Low states are independent. Touch facts are shared observations, while relationship-family eligibility and occurrence identity remain separately scoped. A later protected-symbol touch resolves the historical divergence and exhausts that scoped reference for future occurrences.
