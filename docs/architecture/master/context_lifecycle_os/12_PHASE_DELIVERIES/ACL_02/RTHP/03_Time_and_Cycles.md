# 03 Time and Cycles

All canonical time is interpreted in `America/New_York`. Every interval is stored as half-open: start inclusive, end exclusive.

The cycle registry defines L, N, A, Daily, Weekly, FCR, PMI, PP, the overnight observation cycle, and the M15 cycle group. Human-readable inclusive-second descriptions are presentation only and do not control machine membership.
