# 07 Relationship Families

The canonical registry contains eleven Context relationship families: `WW`, `DD`, `NN`, `LN`, `AN`, `NL`, `NA`, `FCR`, `PMI`, `PP`, and `M15_CYCLE_GROUP`.

Each family produces an independent Context event identity. Simultaneous confirmation in multiple families is permitted and is not deduplicated across families.
