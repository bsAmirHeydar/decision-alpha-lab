# Synthetic Reference

## Definition

Within ACL-08, **Synthetic Reference** is a versioned reporting-and-experience concept. It is derived only from verified ACL-07 evidence and cannot create validation, promotion, execution or capital authority.

## Invariant

Its identity and source digests are deterministic; UNKNOWN remains explicit; generated projections do not become operational truth.

## Failure mode

Ambiguous identity, missing lineage, schema drift or authority escalation fails closed.
