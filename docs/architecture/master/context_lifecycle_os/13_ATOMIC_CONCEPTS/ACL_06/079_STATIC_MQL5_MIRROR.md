# Static Mql5 Mirror

## Definition

Non-executing cross-runtime contract mirror.

## Contract role

This concept is represented by canonical ACL-06 machine artifacts and must remain digest-bound, replayable and subordinate to the frozen ACL-05 Batch.

## Failure condition

Ambiguous identity, missing lineage, mutable interpretation or unauthorized capability causes fail-closed rejection.

## Claim boundary

The concept supports reference orchestration only and cannot independently establish alpha, promotion, live parity or capital authorization.
