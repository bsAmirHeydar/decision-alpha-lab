# ACL-13 — One-Hour Assessment Product

## Objective

Convert an immutable ACL-12 security-readiness package plus a minimum known-time-safe Context request into a deterministic, budget-bound research-triage product within a declared one-hour envelope.

## Implemented vertical slice

1. Exact ACL-12 manifest, receipt, decision, matrix, risk, event and provenance verification.
2. Action-bound ACL-13 authority permit with all execution and capital capabilities denied.
3. Closed Context input contract with owner, doctrine, time boundary and synthetic-data classification.
4. Frozen 3,600-second budget with bounded observations, setup families and random trials.
5. Deterministic fast data slice and support diagnostics.
6. Never/always and circular-shift constrained baselines.
7. Evaluation of predeclared setup families only.
8. Descriptive X-location, Y-state and optionality decomposition.
9. Explicit uncertainty, failure signatures and evidence-gap escalation.
10. Closed twelve-section report, executive brief, event ledger, provenance and ACL-14 handoff.

## Reference decision

`BOUNDED_TRIAGE_COMPLETE_PILOT_DESIGN_ELIGIBLE_NON_CAPITAL`

This permits ACL-14 to author a first-real-Context pilot contract. It does not permit execution of that pilot.

## Claim ceiling

`RESEARCH_TRIAGE_REFERENCE_ONLY`

## Forbidden interpretations

- Alpha proven.
- Strategy validated.
- Production security ready.
- Runtime ready.
- Live order authorized.
- Capital authorized.

## Handoff

The output `ACL13_TO_ACL14` requires a new approved real Context input and precommitted non-capital pilot contract.
