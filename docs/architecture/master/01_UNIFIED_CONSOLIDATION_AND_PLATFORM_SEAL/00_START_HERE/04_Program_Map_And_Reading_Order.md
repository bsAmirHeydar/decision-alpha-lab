## Seven-stage map

| Stage | Purpose | Irreversible action permitted? |
|---|---|---|
| UC-01 | Preserve and baseline | No |
| UC-02 | Standardize and assign authority | No |
| UC-03 | Reorganize physically | Controlled moves only |
| UC-04 | Unify semantics and logic | Duplicate retirement after parity |
| UC-05 | Mechanize the platform | Generated replacement of manual paths |
| UC-06 | Migrate and cut over | Consumer cutover and shim retirement |
| UC-07 | Delete and seal | Yes, after all gates pass |

## Reading principle

Architecture notes define the destination. Stage notes define executable work. Templates define required records. Status notes describe only the current accepted evidence and must never redefine architecture.
