# Executive Charter

## Decision

The repository will be consolidated into one platform without losing historical source, trading semantics, behavioral evidence, lineage or recoverability. The work is not a cosmetic folder cleanup. It is a controlled replacement of parallel implementations and duplicated authorities with one canonical implementation per capability.

## Why the program exists

The current repository is architecturally rich but operationally fragmented. It contains multiple generations of Strategy Factory, ACL-OS, UCEE, SAED, NDS, experiments, MQL5 implementations, migration packages and duplicated documentation projections. The previous migration program mapped and protected these assets but intentionally performed almost no destructive cleanup.

## Program promises

1. Every file and production symbol is classified before deletion.
2. Every important behavior is captured by characterization evidence before refactoring.
3. Every reusable capability receives one canonical owner and one implementation.
4. Context-specific logic remains a Context or Extension; it is not forced into the shared engine.
5. Every consumer is rewritten and verified before compatibility paths are removed.
6. Historical source remains recoverable through Git history, immutable tags, bundles and evidence archives.
7. The platform becomes usable through contracts, a wizard, one CLI, deterministic compilers and explicit lifecycle states.

## What success means

A new Context can be defined through governed inputs, compiled, materialized, trained, evaluated and moved toward paper eligibility without rewriting the platform or relying on a fragile sequence of free-form prompts. A developer may extend the system through explicit ports and manifests, but ordinary Context work does not require architecture changes.

## What success does not mean

The program does not promise profitable alpha, authorize capital, grant broker authority or eliminate the possibility of all future defects. It promises structural coherence, preserved behavior, reproducibility, clear failure modes and zero unresolved critical consolidation defects at seal time.
