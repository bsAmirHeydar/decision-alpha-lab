# Consumer Discovery, Rewrite and Cutover

## Consumer classes

Python imports, dynamic loading, MQL5 Includes, file-path reads, CI jobs, PowerShell scripts, terminal profiles, Strategy Tester configurations, scheduled tasks, external repositories, dashboards, docs and human runbooks.

## Discovery methods

Static graph, runtime telemetry, repository search, terminal survey, environment inventory, owner attestation and negative search evidence. No single method proves completeness.

## Cutover

Consumers move in bounded waves. Compatibility shims are versioned, observable and expiring. Every shim invocation records consumer identity and old interface usage.

## Completion

Cutover completes when all known consumers use canonical interfaces, external owners attest or evidence confirms transition, and compatibility telemetry remains zero across the required observation window.
