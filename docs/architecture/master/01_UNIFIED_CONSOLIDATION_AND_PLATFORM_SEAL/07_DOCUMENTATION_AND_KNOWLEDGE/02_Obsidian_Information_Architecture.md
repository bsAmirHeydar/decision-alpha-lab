# Obsidian Information Architecture

## Vault role

The Master Architecture vault is the human navigation layer for architecture, standards, Contexts, operations and decisions. It does not store runtime artifacts or duplicate every generated report.

## Navigation

Every major section has one MOC, explicit reading order and links to source contracts. The program Home is reachable from the master Home. Context documentation is generated or maintained in a stable Context area.

## Folder semantics

Folders represent information responsibility, not implementation phase history. Delivery phase notes are retained only while operationally needed and then archived.

## Search and graph quality

Stable IDs, full-path wiki links, unique note names where practical, consistent tags and explicit succession links prevent ambiguous graph navigation.
