# EXP0013 — Astro Excel / CSV Build Commands

This file is intentionally copy-paste friendly.

The runtime contract is:

```text
Python builds the full candle-by-candle astrological map.
Excel/XLSX is for human inspection.
CSV is the MQL5 runtime source.
MQL5 reads the CSV candle by candle inside Visual Tester or live execution.
```

MQL5 does **not** read the binary `.xlsx` file directly. It reads the CSV mirror generated by the same command. This keeps Strategy Tester deterministic, fast, and DLL/API-free.

---

## 1. Install dependencies

Run from repository root:

```powershell
python -m pip install -r tools/astro_feature_builder/requirements.txt
```

Dependencies:

```text
pyswisseph = Swiss Ephemeris wrapper, no API, no internet during generation
openpyxl   = optional Excel workbook export
```

---

## 2. Build one month of M1 astro data

Example for broker time `UTC+2`:

```powershell
python tools/astro_feature_builder/astro_feature_builder.py `
  --start-broker "2024-01-01 00:00:00" `
  --end-broker "2024-02-01 00:00:00" `
  --timeframe-minutes 1 `
  --broker-gmt-offset-hours 2 `
  --ephe-path "tools/astro_feature_builder/ephe" `
  --out-csv "data/astro/astro_XAUUSD_M1_202401_mql.csv" `
  --out-xlsx "data/astro/astro_XAUUSD_M1_202401_review.xlsx"
```

The CSV goes to MQL5.
The XLSX is for visual review and auditing.

## 3. Build with Iran-like broker offset UTC+3:30

```powershell
python tools/astro_feature_builder/astro_feature_builder.py `
  --start-broker "2024-01-01 00:00:00" `
  --end-broker "2024-02-01 00:00:00" `
  --timeframe-minutes 1 `
  --broker-gmt-offset-hours 3.5 `
  --ephe-path "tools/astro_feature_builder/ephe" `
  --out-csv "data/astro/astro_XAUUSD_M1_202401_gmt35_mql.csv" `
  --out-xlsx "data/astro/astro_XAUUSD_M1_202401_gmt35_review.xlsx"
```

Time contract:

```text
utc_time = broker_time - broker_gmt_offset_hours
```

So if broker candle time is:

```text
2024-01-01 10:00:00
```

and offset is `+3.5`, the sky map is computed for:

```text
2024-01-01 06:30:00 UTC
```

## 4. Copy runtime CSV to MetaTrader

Copy only the CSV mirror into the terminal data folder:

```powershell
$terminalFiles = "$env:APPDATA\MetaQuotes\Terminal\<YOUR_TERMINAL_ID>\MQL5\Files\astro"
New-Item -ItemType Directory -Force $terminalFiles
Copy-Item "data/astro/astro_XAUUSD_M1_202401_mql.csv" "$terminalFiles\astro_XAUUSD_M1_202401_mql.csv" -Force
```

Then set the MQL5 input:

```text
InpAstroCsvFile = astro\astro_XAUUSD_M1_202401_mql.csv
InpBrokerGmtOffsetHours = 2
InpRequireExactBarTime = true
```

## 6. Large ranges

CSV can be huge and is the correct format for MQL5 runtime.

Excel has a hard worksheet limit of 1,048,576 rows. M1 data for multiple years can exceed this. For large tests:

```text
Generate one CSV per year or month.
Generate XLSX only for audit chunks.
Use CSV for real Strategy Tester runs.
```

Example yearly CSV only:

```powershell
python tools/astro_feature_builder/astro_feature_builder.py `
  --start-broker "2023-01-01 00:00:00" `
  --end-broker "2024-01-01 00:00:00" `
  --timeframe-minutes 1 `
  --broker-gmt-offset-hours 2 `
  --ephe-path "tools/astro_feature_builder/ephe" `
  --out-csv "data/astro/astro_XAUUSD_M1_2023_mql.csv"
```

## 7. Causality rule

Each row must represent the sky state at candle open time.

```text
feature_time = candle_open_broker_time converted to UTC
```

Do not build features using candle close unless the execution itself only acts after close and the feature timestamp is explicitly aligned to that close.
