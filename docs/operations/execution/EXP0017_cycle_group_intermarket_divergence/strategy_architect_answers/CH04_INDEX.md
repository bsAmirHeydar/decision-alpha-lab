# CH04 — Reference Scope, Same-Day Cycle Memory, and Statistical Neutrality

این پوشه پاسخ‌های فصل چهارم پرسش‌نامه معمار استراتژی را به زبان داکیومنتی تبدیل می‌کند.

فصل چهارم درباره این است که در مدل واگرایی سایکل‌گروپی، «مرجع» از کجا می‌آید و یک سایکل فعلی باید با کدام سایکل‌های قبلی مقایسه شود.

## اصل فصل

در این مدل، مرجع واگرایی می‌تواند:

1. سایکل قبلی باشد.
2. یا هرکدام از سایکل‌های قبلی همان روز باشد.

اما فعلاً هیچ سلسله‌مراتب قطعی بین این مرجع‌ها تعریف نمی‌شود. همه‌ی آن‌ها به‌عنوان سیگنال‌های مستقل دیده می‌شوند تا بعداً از دل تست‌های آماری مشخص شود کدام خانواده مرجع‌ها و کدام فاصله‌ها واقعاً ارزشمندترند.
