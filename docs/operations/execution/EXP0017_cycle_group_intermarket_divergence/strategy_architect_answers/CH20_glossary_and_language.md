# CH20 — Glossary and Language

## Current version

The active stage of EXP0017 in which the strategy is fixed and the model only performs statistical testing, comparison, ranking, and reporting.

## Future version

A later stage that may allow controlled optimization or strategy changes after statistical evidence and strategy-architect approval.

## Strategy mutation

Any change to the strategy rules, including cycle groups, entry rules, exit rules, target logic, risk logic, daily boundary, confirmation rules, or signal permission.

## Non-mutation doctrine

The rule that the current model must not change the strategy.

## Statistical-only mode

A model mode where the model collects, measures, compares, and reports without changing execution or rules.

## Optimization gate

The future permission boundary that must be opened before the model may suggest or participate in strategy changes.

## Rule promotion

The process by which a statistical finding becomes a possible strategy rule after review, approval, and separate validation.

## Strategy architect approval

The required human decision before any recommendation becomes an official strategy change.

## CG overlap complexity

The complexity created when multiple cycle groups produce simultaneous, nearby, same-direction, or opposite-direction signals.

## Repeated question

A question that has already been answered in earlier doctrine and should be mapped back to that doctrine instead of creating a new rule.

## Future backlog

A list of ideas, uncertainties, and possible improvements that are not active in the current model but may be studied later.

## Doctrine drift

The risk that repeated or ambiguous questions gradually change the strategy without explicit approval.

## Base version

The fixed raw strategy version used to collect clean statistical evidence.

## Optimized version

A later modified version created only after statistics and explicit strategy-architect approval.
