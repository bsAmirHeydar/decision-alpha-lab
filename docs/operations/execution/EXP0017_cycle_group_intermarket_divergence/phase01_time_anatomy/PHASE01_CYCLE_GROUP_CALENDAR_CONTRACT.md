# EXP0017 Phase 01 — Cycle Group Calendar Contract

## هدف قرارداد

این سند قرارداد زمانی همه CGها را تعریف می‌کند. در فازهای بعدی، Reference Field، Hunt Anatomy و Divergence Anatomy باید از همین قرارداد استفاده کنند و حق ندارند تقویم جداگانه بسازند.

## قانون عمومی

همه CGها از ساعت 18:00 نیویورک شروع می‌شوند و تا 17:00 نیویورک ادامه دارند.

```text
Trading-day field = [18:00 NY, 17:00 NY next day)
Length = 1380 minutes
```

## نکته درباره تعداد سایکل

اگر ۱۳۸۰ بر طول CG بخش‌پذیر نباشد، آخرین سایکل ناقص است اما همچنان یک سایکل معتبر زمانی محسوب می‌شود.

## قرارداد نمایش

بازه‌ها برای انسان به‌صورت inclusive دقیقه‌ای نمایش داده می‌شوند:

```text
18:00-18:29
```

اما در منطق داخلی بازه‌ها exclusive هستند:

```text
18:00 <= time < 18:30
```

این قرارداد باید در کل پروژه ثابت بماند تا مرزهای کندلی و آماری دچار دوگانگی نشوند.

## قرارداد استقلال

هیچ CG در فاز ۱ برتر، ضعیف‌تر، معتبرتر یا قابل‌اعتمادتر نیست. همه فقط واحدهای زمانی مستقل‌اند.
