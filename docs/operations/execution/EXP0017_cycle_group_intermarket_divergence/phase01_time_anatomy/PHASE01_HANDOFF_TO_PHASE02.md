# EXP0017 Phase 01 — Handoff to Phase 02

## خروجی مفهومی فاز ۱

فاز ۱ این لایه‌ها را آماده می‌کند:

- روز معاملاتی جاری
- شروع روز معاملاتی نیویورک
- پایان روز معاملاتی نیویورک
- همه CGها
- سایکل جاری هر CG
- سایکل‌های قبلی همان روز
- تشخیص سایکل ناقص آخر روز

## فاز ۲ چه چیزی روی این می‌سازد؟

فاز ۲ باید **Reference Field Anatomy** باشد.

یعنی برای هر نماد، هر CG و هر سایکل پیشین همان روز:

```text
reference_high
reference_low
reference_cycle_start
reference_cycle_end
reference_state
```

## وابستگی فاز ۲ به فاز ۱

فاز ۲ نباید خودش تقویم بسازد. باید از قرارداد فاز ۱ استفاده کند.

اگر فاز ۲ زمان جدا بسازد، دو منبع حقیقت ایجاد می‌شود و کل پروژه در آینده خطای پنهان می‌گیرد.

## معیار شروع فاز ۲

وقتی فاز ۱ روی چارت نصب شد و چند نمونه دستی تأیید شد که CGها درست ساخته می‌شوند، می‌توانیم وارد فاز ۲ شویم.
