# Phase 10 — Limits and Non-Goals

Phase 10 does not:

- place orders;
- size risk;
- execute trades;
- optimize CGs;
- remove CGs;
- change target logic;
- create AI behavior;
- train a model inside MetaTrader;
- decide live signals.

Phase 10 only creates a dataset. It deliberately keeps labels and potentially leaky outcome columns visible so downstream research can make explicit train/test choices.
