# Phase 09 Limits and Non-Goals

Phase 09 does not:

- read market prices
- calculate references
- detect hunts
- detect divergence
- confirm signals
- calculate outcomes
- place trades
- size risk
- change targets
- disable cycle groups
- filter live signals
- optimize the strategy
- train AI

It is strictly a statistical ranking and dashboard layer.

## Important Limitation

The CSV reader is intentionally simple. It expects Phase 08 CSV files generated by this project. It is not a general-purpose CSV parser for arbitrary quoted CSV files.

## Report Interpretation Limit

Ranking can be distorted by sample size, volatility regime, incomplete historical coverage, and outcome-window choice. The rank is evidence for later review, not proof of execution quality.
