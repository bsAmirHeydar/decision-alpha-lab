# Phase 03 Limits and Non-Goals

Phase 03 is intentionally narrow.

## It does not detect divergence

It records one-symbol and both-symbol hunts, but it does not convert them into buy/sell divergence.

## It does not confirm signals

It does not use candle-close confirmation.

## It does not invalidate signals

It records both-symbol hunts, but it does not apply invalidation logic.

## It does not trade

No entry, exit, risk, target, stop, order placement, or position management exists in this phase.

## It does not rank hunts

No hunt is called strong, weak, good, bad, premium, discounted, early, late, valid, invalid, or higher quality.

## It does not filter by session

Cash session can be studied later. Phase 03 does not filter hunts based on session.

## It does not create AI features yet

The fields created here are future feature candidates, but no model is trained and no score is produced.
