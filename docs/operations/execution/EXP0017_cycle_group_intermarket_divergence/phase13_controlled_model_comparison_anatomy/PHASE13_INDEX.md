# Phase 13 — Controlled Model Comparison

Phase 13 compares simple, deterministic candidate models against the Phase 11 bucket baseline under the fixed walk-forward fold plan.

## Main components

- MQL5 terminal preflight bridge;
- Python standard-library comparison engine;
- bucket and threshold baselines;
- logistic win classifier;
- ridge R regression;
- constrained ensembles;
- calibration, error, stability, and leakage reports;
- model cards and experiment registry.

## Mandatory prerequisite

Phase 12.5 must report `READY_FOR_PHASE13` or an explicitly accepted `READY_WITH_WARNINGS` state.

## Boundary

Phase 13 is research-only. It grants no execution, filtering, risk, target, or strategy-mutation authority.
