# قرارداد جداسازی EXP0018 از EXP0017

## اصل

`EXP0018 Daye Trader` یک پروژه مستقل است. هیچ کد، نام، state، signal id، CSV، object prefix، input group یا سند EXP0017 نباید به‌طور ضمنی در EXP0018 reuse شود.

## شباهت مجاز

فقط می‌توان از الگوهای مهندسی عمومی استفاده کرد:

- تبدیل زمان نیویورک و DST
- خواندن داده دو نماد
- aggregate کردن high/low بر اساس بازه زمانی
- ساخت object امن روی چارت
- lifecycle registry
- logging و validation

## تفاوت‌های دامنه‌ای که نباید مخلوط شوند

| موضوع | EXP0017 | EXP0018 Daye |
|---|---|---|
| خانواده زمان | Cycle Groupهای دقیقه‌ای متعدد | Weekly, Daily, Session, 90m و خانواده‌های نام‌برده‌شده Daye |
| سیگنال | هر CG مستقل | 22 جفت ازپیش‌تعریف‌شده |
| محل رسم | زبان بصری دو نمادی در مسیر قبلی | در متن Daye فقط روی Hunter |
| متن روی خط | حالت قبلی مستقل | فقط شش سیگنال بزرگ |
| ماندگاری | تابع قرارداد EXP0017 | پس از تأیید حذف نشود |
| باکس‌ها | جزء هسته قبلی نیست | A/L/N/P جزء خروجی اصلی |
| TWO/TDO | وجود ندارد | جزء رسمی Daye |
| namespace | `EXP0017_*` | باید `EXP0018_*` باشد |

## قواعد فنی آینده

- Expert مستقل
- include folder مستقل یا prefix مستقل `DY_`
- object prefix مستقل `EXP0018_DAYE_`
- CSV مستقل
- magic number مستقل، در صورت ورود به execution در آینده
- هیچ include دامنه‌ای EXP0017 نباید مستقیماً import شود.
