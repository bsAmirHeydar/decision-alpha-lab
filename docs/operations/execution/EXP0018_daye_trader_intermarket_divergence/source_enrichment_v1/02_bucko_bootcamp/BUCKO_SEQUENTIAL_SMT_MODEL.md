# Bucko — مدل Sequential SMT

صفحات ۱۹ تا ۲۳ Sequential SMT را بین quarterهای متوالی تعریف می‌کنند. منبع بر Q2→Q3 و Q3→Q4 تأکید بیشتری دارد و Q1→Q3 را نامعتبر معرفی می‌کند. مکان نسبت به True Open و phase manipulation/distribution برای اعتبار مهم دانسته می‌شود.

این مدل با ۲۲ relationship Word هم‌خانواده است ولی یکسان نیست. ۲۲ relationship باید registry canonical بماند و Bucko SSMT به‌عنوان یک taxonomy توضیحی یا feature پژوهشی ثبت شود.
