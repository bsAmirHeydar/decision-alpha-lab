## هدف

این بسته سه PDF تکمیلی را به دانش ساختاریافته پروژه EXP0018 تبدیل می‌کند، بدون اینکه منطق اجرایی سند اصلی Daye را بی‌صدا تغییر دهد.

## اصل ۸۰/۲۰

- **۸۰٪ هسته اجرایی:** سند `06_Daye Trader-v1 (1).docx` و تصمیم‌های مستقیم معمار استراتژی.
- **۲۰٪ جزئیات و توسعه دیدگاه:** سه PDF حاضر.
- جزئیات PDF فقط در صورت سازگاری با هسته وارد قرارداد canonical می‌شوند.
- هر تعارض به‌جای انتخاب خودکار، در رجیستر تعارض ثبت می‌شود.
