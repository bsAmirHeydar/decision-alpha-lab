# سلسله‌مراتب اعتبار منابع و مدل ۸۰/۲۰

## 1. چرا وزن‌دهی لازم است؟

سه PDF جدید هم‌سطح سند اصلی نیستند. آن‌ها آموزش، خلاصه، ترجمه، برداشت مدرس و مثال‌های معاملاتی بیشتری دارند. اگر همه گزاره‌ها بدون سلسله‌مراتب وارد کد شوند، پروژه Daye به ترکیبی نامعلوم از چند سبک تبدیل می‌شود.

## 2. ترتیب authority

1. **S0 — تصمیم مستقیم معمار استراتژی:** بالاترین مرجع.
2. **S1 — Word اصلی Daye:** تعریف دقیق نمادها، زمان‌ها، ۲۲ رابطه، رسم و lifecycle.
3. **S2 — Trader Daye PDF:** نزدیک‌ترین منبع تکمیلی، اما شامل تفسیر، ترجمه و بعضی ادعاهای شخصی است.
4. **S3 — Bucko Bootcamp:** ساختار آموزشی فشرده، مناسب برای روشن‌کردن واژگان و مدل‌ها.
5. **S4 — QT Education:** دانشنامه وسیع، شامل مفاهیم فراوانی که لزوماً جزو اکسپرت اصلی EXP0018 نیستند.

## 3. معنی ۸۰/۲۰ در عمل

- هیچ مفهوم PDF به‌تنهایی نمی‌تواند ۲۲ سیگنال اصلی را تغییر دهد.
- PDFها می‌توانند ابهام سند اصلی را روشن کنند، اما فقط با ثبت traceability.
- مفاهیم جدید مانند DFR، SSMT، CSD، Golden Pocket یا Pi Range به‌طور پیش‌فرض **ماژول تحقیقاتی اختیاری** هستند.
- ادعاهای آماری مانند «۷۵٪» یا «هر ۶۰ روز» تا تست مستقل، قانون محسوب نمی‌شوند.

## 4. قانون تعارض

در تعارض S1 با S2/S3/S4، S1 حفظ می‌شود و مسئله در `EXP0018_CONFLICT_AND_AMBIGUITY_REGISTER_V2.md` ثبت می‌گردد. فقط S0 می‌تواند آن را حل و نسخه canonical جدید بسازد.
