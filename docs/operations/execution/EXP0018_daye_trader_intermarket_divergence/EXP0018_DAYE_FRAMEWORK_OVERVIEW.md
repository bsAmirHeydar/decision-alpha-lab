# نمای کلی چارچوب Daye Trader

## هویت

این چارچوب در منبع به‌عنوان یک زبان زمانی چندلایه ارائه شده است. هسته فعلی سند، واگرایی بین دو نماد هم‌بسته را در ساختارهای هفتگی، روزانه، سشنی و زیرسشنی بررسی می‌کند.

## لایه‌های نام‌برده‌شده

1. 22.5 دقیقه
2. 90 دقیقه
3. Session
4. Daily
5. Weekly
6. M1
7. 4Q
8. y
9. 4y

## دامنه مستندشده فعلی

جزئیات کافی فعلاً فقط برای موارد زیر وجود دارد:

- Weekly
- Daily
- Session: A/L/N/P
- 90m subcycles
- 22 signal relationships
- divergence drawing
- session boxes
- TWO/TDO

## دامنه‌ای که فعلاً نباید کدنویسی شود

- 22.5m
- M1
- 4Q
- y
- 4y

تا وقتی تعریف زمان، reference pair، confirmation و drawing آن‌ها داده نشود.

## فلسفه مشاهده

Daye در این منبع قیمت را فقط بر اساس یک تایم‌فریم ثابت نمی‌بیند؛ قیمت درون ظرف‌های زمانی تو‌در‌تو بررسی می‌شود و هر سیگنال از رابطه یک ظرف جاری با ظرف قبلی مشخص ساخته می‌شود.
