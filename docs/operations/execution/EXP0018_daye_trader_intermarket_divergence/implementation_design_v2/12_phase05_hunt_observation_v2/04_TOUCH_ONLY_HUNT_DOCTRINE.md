# Touch-Only Doctrine

High-side touch:

`current_high >= reference_high`

Low-side touch:

`current_low <= reference_low`

Exact equality counts. A close beyond the level is not required. The classifier records whether the touch was exact equality or strict penetration.

P05 does not interpret the side as bullish or bearish because DY-A01 remains a separate doctrine decision.
