# Definition of Done

P09 is complete when:

- A/L/N/P session snapshots are the only admitted sources;
- each symbol uses its own High/Low scale;
- complete and open policies behave as documented;
- partial/missing history fails explicitly;
- exact-symbol chart targeting works;
- deterministic OBJ_RECTANGLE ownership is idempotent;
- manual edits are repaired and stale owned objects are bounded by lookback;
- colors and style are input-driven;
- tests, docs, Obsidian, audit and MetaEditor gates pass;
- no signal or execution authority exists.
