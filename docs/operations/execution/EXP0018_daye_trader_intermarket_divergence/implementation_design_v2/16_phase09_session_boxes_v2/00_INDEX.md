# EXP0018 Phase 09 — Session Box Rendering v2

P09 projects the four canonical Daye session ranges—A, L, N and P—onto charts of each configured broker symbol. Every rectangle is derived from a P03 symbol-local period snapshot. P09 does not infer sessions from chart pixels, does not recompute signal logic, and does not possess trading authority.
