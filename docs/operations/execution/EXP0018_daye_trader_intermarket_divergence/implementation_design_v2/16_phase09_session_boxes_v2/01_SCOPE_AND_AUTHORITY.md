# Scope and Authority

P09 owns only the visual projection of A/L/N/P range rectangles. It may create, verify, update, repair and remove objects under `EXP0018_P09_BOX_`. It cannot detect hunts, resolve relationships, confirm divergence, retire references, map BUY/SELL, size risk, place orders, access the network or mutate doctrine.

The P09 renderer is downstream of the time, data and period layers. Its inputs are immutable or explicitly open P03 session snapshots. Its output is a chart object plus audit evidence. The rectangle is not domain truth.
