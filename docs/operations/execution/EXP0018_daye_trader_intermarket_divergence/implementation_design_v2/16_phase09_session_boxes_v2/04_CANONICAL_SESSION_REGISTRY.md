# Canonical Session Registry

P09 admits exactly four session codes:

| Code | New York wall-time interval | Default visual |
|---|---|---|
| A | 18:00–00:00 | sky blue |
| L | 00:00–06:00 | lime |
| N | 06:00–12:00 | orange |
| P | 12:00–17:00 | light red |

The intervals come from P01/P03. P09 contains no alternative session clock. The 17:00–18:00 gap is never boxed.
