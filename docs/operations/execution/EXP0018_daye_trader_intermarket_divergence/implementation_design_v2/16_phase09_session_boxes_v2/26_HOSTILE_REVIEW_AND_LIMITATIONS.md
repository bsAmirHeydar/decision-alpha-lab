# Hostile Review and Limitations

Known limitations:

- visual history cannot exceed available P03 source bars;
- full deterministic historical rebuild remains a P11 concern;
- auto-current broker offset is not historically replay-safe;
- alpha rendering can vary by terminal build and chart theme;
- closed boxes are visually immutable only while P03 source identity remains stable;
- partial sessions are rejected by default;
- P09 does not label boxes with extra text objects to preserve minimal geometry.
