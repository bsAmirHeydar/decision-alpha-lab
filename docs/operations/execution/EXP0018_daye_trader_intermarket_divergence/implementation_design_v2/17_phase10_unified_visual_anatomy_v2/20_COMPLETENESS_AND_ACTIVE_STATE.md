# Completeness and Active-State Rendering

## Purpose

Define what is admitted from P03.

## Default

Complete and open periods render. Partial periods do not.

## Open updates

Open boxes update only from closed source bars.

## No fabrication

Empty, unavailable, invalid, and missing-symbol periods produce no geometry.
