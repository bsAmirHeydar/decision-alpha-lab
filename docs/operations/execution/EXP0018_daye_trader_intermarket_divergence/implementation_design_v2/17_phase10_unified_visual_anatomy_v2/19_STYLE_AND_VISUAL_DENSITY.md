# Style and Visual Density

## Purpose

Create a hierarchy readable on multiple timeframes.

## Major

Daily and Session boundaries are solid and stronger.

## Minor

Subcycle boundaries are dashed; micro boundaries are dotted.

## Opacity

Daily fill is minimal, Session fill moderate, Subcycle fill light, gap fill gray. All values are inputs.
