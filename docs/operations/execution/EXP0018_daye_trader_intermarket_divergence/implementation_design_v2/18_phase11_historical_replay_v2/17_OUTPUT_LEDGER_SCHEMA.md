# Output ledger schema

Common Files outputs: summary, events, optional frames, confirmations, references, and uses. Confirmations contain immutable host geometry. References contain terminal state and retirement evidence. Uses contain accepted or rejected First-Sweep decisions. P12 consumes these files without reading chart objects.
