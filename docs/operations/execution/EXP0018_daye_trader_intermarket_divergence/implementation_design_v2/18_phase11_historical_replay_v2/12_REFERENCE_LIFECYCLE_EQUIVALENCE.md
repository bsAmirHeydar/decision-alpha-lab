# Reference lifecycle equivalence

Confirmed results enter the same P07 identity and policy model. Exact opportunities are deduplicated, later distinct opportunities may reuse a surviving reference, protected touch retires the reference, double hunt and role switch retire according to policy, and terminal references never reactivate.
