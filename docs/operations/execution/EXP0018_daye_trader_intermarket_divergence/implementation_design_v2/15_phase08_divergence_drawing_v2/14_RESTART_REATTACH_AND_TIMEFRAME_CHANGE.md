# Restart, Reattach, and Timeframe Change

P07 checkpoints restore accepted uses. On reattachment P08 re-resolves source provenance, finds existing owned objects, and verifies geometry. It neither duplicates nor clears lines.

A chart reopened after closure can be repopulated while its accepted use and reference-period provenance remain in source lookback. Full long-range reconstruction is delegated to P11 replay.
