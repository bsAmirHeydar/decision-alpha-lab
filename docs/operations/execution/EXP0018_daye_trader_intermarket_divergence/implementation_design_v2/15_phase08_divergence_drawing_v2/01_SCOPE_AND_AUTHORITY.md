# Scope and Authority

P08 owns only the projection of already accepted immutable P07 uses into chart objects. Detection, hunt facts, host-close confirmation, First-Sweep scope, reference retirement, direction, risk, entry, exit, and execution remain outside this phase.

### Allowed
- Find open charts belonging to the Hunter broker symbol.
- Resolve deterministic line geometry from upstream evidence.
- Create, verify, repair, and preserve objects with prefix `EXP0018_P08_`.
- Add the six major aliases as annotations.

### Forbidden
- Recompute divergence from chart prices.
- Draw rejected, duplicate, invalidated, or unavailable uses.
- Delete a historical confirmed line because the reference later retires.
- Compare SPX price to NDX price.
- Touch foreign chart objects.
