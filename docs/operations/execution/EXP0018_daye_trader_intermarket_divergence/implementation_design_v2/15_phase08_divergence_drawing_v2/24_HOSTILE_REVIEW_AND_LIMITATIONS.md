# Hostile Review and Limitations

Known limitations:
- accepted use older than current source lookback may lack reference extreme provenance after a full chart closure;
- full historical recovery waits for P11 replay;
- broker symbol must match open chart symbol exactly;
- midpoint text is a companion annotation object because MT5 trend descriptions are not reliably centered;
- automatic chart opening defaults off to avoid unexpected workspace mutation.

None of these limitations are hidden as success.
