# Input and Output

Inputs include P01/P02/P03 configuration, major/minor enable flags, current/reference eligibility policy, output limits, diagnostics, and optional audit settings.

Outputs are registry definitions, relationship resolutions, store summary, and transition events. No output includes hunt side, direction, hunter, protected, trade permission, or price comparison result.
