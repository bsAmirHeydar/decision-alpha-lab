# ADR-007 — Hard Budget Blocks Acceptance

## Decision

A hard resource overrun rejects the relevant release profile until resolved or formally rebaselined.

## Consequences

The decision is versioned in FP-I13, covered by tests, and included in the handoff to FP-I14. Any reversal requires a new ADR and replay rebaseline.
