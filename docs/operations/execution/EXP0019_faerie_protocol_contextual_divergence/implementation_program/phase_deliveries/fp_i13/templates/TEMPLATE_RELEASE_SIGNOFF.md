# Release Signoff

## Purpose

Record every source and local gate, manifest hash, open decision state, reviewer, and release disposition.

## Required evidence

- Release manifest ID and hash
- Configuration/context hash
- Source revision
- Fixture or chart identity
- Gate status and reason codes
- Attached log or artifact hash
- Reviewer and date
