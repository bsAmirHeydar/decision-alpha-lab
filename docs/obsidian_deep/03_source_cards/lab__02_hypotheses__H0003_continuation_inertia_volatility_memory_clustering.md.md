## Summary

Hypothesis: continuation exits from completed node-territory events create a stronger post-event volatility-memory state than reversal exits. Operationally, H0003 uses exact M0001 events and M0002 branch labels. It evaluates whether continuation has higher event RTV, stronger horizon deltas, better carry ratios, fatter tail behavior, and positive time-cluster… This hypothesis is a volatility-state classifier, not a directional trading strategy.
