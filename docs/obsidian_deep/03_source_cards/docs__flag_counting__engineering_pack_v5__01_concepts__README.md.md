## Summary

This package introduces the conceptual vocabulary of Flag Counting. It answers: What is a node? What is L? What is a flag? What are F1, F2, and F3? What is ND/Hook? What is a sequence? What does it mean for a structure to be candidate, confirmed, completed, locked, invalidated, or rejected? Why must the detector be sequence-based rather than sliding-window-based? `CONCEPT_GLOSSARY.md`: short but precise vocabulary. `CONCEPT_TAXONOMY.md`: hierarchy of objects in the system. `INVARIANTS_AND_ASSUMPTIONS.md`: rules that must never be violated. The model is not looking for decorative shapes. It is building a sequence of owned structural phases. A drawn line must answer all of these questions: If those questions cannot be answered, the object must not be drawn as a flag.
