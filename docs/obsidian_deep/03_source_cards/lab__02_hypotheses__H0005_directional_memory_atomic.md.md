## Summary

If the latest known structural regime is reversal or continuation, does it improve the next structural decision in a way that can become executable alpha? The old H5 report built paths from completed branch samples. It could show useful structural behavior, but it mixed several ideas: regime label sequence, reversal touch path, continuation break path, structural path R, regime-change exit. This made continuation look strong, but code review showed that continuation R was not necessarily a real execution R because continuation had no real initial stop in the classic path report. The official H0005 formulation is atomic and no-sample: replay candles using only the current prefix, build raw M0001 events, create known-time regime batches, activate reversal or continuation candidates only after regime is knowable, enter only after live-style touch or break, measure only after entry, use expl
