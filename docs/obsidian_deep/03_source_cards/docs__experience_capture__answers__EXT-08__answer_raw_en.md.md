## Summary

Node freshness, correct trade zone, reward-first logic, and win-rate improvement limits. We said that we do not create a separation here. But first, we must find the correct zone. That means the correct trading region. After that, we think about the entry point. So first comes context. Then comes the zone or trading region. Then comes the entry point and the Extremes. We risk very small amounts, but we seek very high reward. So even if there are many stop-outs, it is not a problem, but only up to a limit. For example, even if the win rate is twenty percent or ten percent, it is not a problem. But in the end, reward comes first and win rate comes after. If we can increase win rate without sacrificing reward, then we should do that.
