# CH16 — Strategy Architect Review Checklist

## مرز مدل

- [ ] مدل فقط گزارش‌گر آماری تعریف شده است؟
- [ ] ورود و خروج از محدوده مدل حذف شده است؟
- [ ] تصمیم نهایی برای معمار استراتژی باقی مانده است؟
- [ ] خروجی مدل به‌عنوان پیشنهاد غیرخودکار تعریف شده است؟

## داده

- [ ] فقط سیگنال‌های معتبر و تأییدشده وارد نمونه اصلی می‌شوند؟
- [ ] سیگنال‌های خام و تأییدنشده از نمونه اصلی جدا هستند؟
- [ ] داده‌های احساسی، خبری و روایی حذف شده‌اند؟
- [ ] مدل فعلاً فقط روی گذشته کار می‌کند؟

## مولفه‌ها

- [ ] نوع CG به‌عنوان مولفه اصلی ثبت شده است؟
- [ ] جایگاه CG ثبت شده است؟
- [ ] وین‌ریت ثبت شده است؟
- [ ] برآیند ثبت شده است؟
- [ ] R outcome ثبت شده است؟
- [ ] pip outcome ثبت شده است؟
- [ ] daily-range-normalized outcome ثبت شده است؟
- [ ] CG overlap ثبت شده است؟
- [ ] signal density ثبت شده است؟

## خروجی مدل

- [ ] مدل کیفیت خانواده‌ها را گزارش می‌کند؟
- [ ] مدل خانواده‌های خطرناک را مشخص می‌کند؟
- [ ] مدل نیاز به نمونه بیشتر را مشخص می‌کند؟
- [ ] مدل rule promotion را فقط پیشنهاد می‌دهد؟
- [ ] هیچ rule خودکار از مدل خارج نمی‌شود؟

## آینده AI

- [ ] مسیر AI بعد از آمار تعریف شده است؟
- [ ] AI به‌عنوان decision support تعریف شده است؟
- [ ] AI در مرحله پایه execution authority ندارد؟
