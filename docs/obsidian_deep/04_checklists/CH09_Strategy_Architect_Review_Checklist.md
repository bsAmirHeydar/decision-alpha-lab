# CH09 Strategy Architect Review Checklist

## پاکی doctrine

- [ ] آیا trade vehicle همان نماد clean تعریف شده است؟
- [ ] آیا clean symbol به‌عنوان نماد دارای مرجع سالم تعریف شده است؟
- [ ] آیا hunter symbol از clean symbol جدا شده است؟
- [ ] آیا فشار خرید در بای به حفظ low clean symbol وصل شده است؟
- [ ] آیا فشار فروش در سل به حفظ high clean symbol وصل شده است؟

## بی‌طرفی پایه

- [ ] آیا بای و سل هر دو معتبرند؟
- [ ] آیا SPXUSD و NDXUSD هر دو می‌توانند clean باشند؟
- [ ] آیا هیچ جهت یا نماد یا CG قبل از آمار برتر نشده است؟
- [ ] آیا همه سیگنال‌های واگرایی معتبر نمایش داده می‌شوند؟
- [ ] آیا استاندارد برای همه یکسان مانده است؟

## پژوهش آینده

- [ ] آیا امکان سنجش clean-symbol superiority وجود دارد؟
- [ ] آیا امکان مقایسه hunter trade و clean trade به‌صورت فرضی وجود دارد؟
- [ ] آیا invalidation بعد از ورود باید ثبت شود؟
- [ ] آیا سلامت مرجع به‌عنوان متغیر پژوهشی مشخص شده است؟
- [ ] آیا مسیر مدل‌سازی آینده حفظ شده است؟
