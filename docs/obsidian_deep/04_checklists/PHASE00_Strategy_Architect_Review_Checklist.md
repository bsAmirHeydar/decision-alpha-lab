# PHASE00 Strategy Architect Review Checklist

## قانون مادر

- [ ] آیا تعریف واگرایی روشن است؟
- [ ] آیا تعریف هانت روشن است؟
- [ ] آیا تایید با کلوز به‌درستی جدا شده است؟
- [ ] آیا ابطال double hunt مشخص است؟
- [ ] آیا معامله روی clean symbol به‌عنوان قانون خام ثبت شده است؟

## بی‌طرفی قبل از آمار

- [ ] آیا هیچ CG قبل از آمار برتر نشده است؟
- [ ] آیا هیچ سشن قبل از آمار فیلتر نشده است؟
- [ ] آیا هیچ نماد قبل از آمار برتر نشده است؟
- [ ] آیا هیچ direction قبل از آمار برتر نشده است؟
- [ ] آیا هیچ overlap قبل از آمار حذف نشده است؟

## مرز مدل

- [ ] آیا AI فقط تحلیلگر، رتبه‌دهنده و مقایسه‌گر است؟
- [ ] آیا AI از تغییر strategy منع شده است؟
- [ ] آیا rule promotion فقط با تایید معمار انجام می‌شود؟

## آماری

- [ ] آیا نمونه آماری اصلی فقط سیگنال‌های تاییدشده و قابل معامله است؟
- [ ] آیا metricهای اصلی ثبت شده‌اند؟
- [ ] آیا fieldهای لازم برای مدل آینده حذف نشده‌اند؟

## اجرای آینده

- [ ] آیا نسخه خام و نسخه filtered از هم جدا شده‌اند؟
- [ ] آیا محدودیت‌های آینده فقط hypothesis هستند؟
- [ ] آیا اجرای واقعی به بعد از آناتومی و آمار موکول شده است؟
