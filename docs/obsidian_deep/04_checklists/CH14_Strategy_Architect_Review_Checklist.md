# CH14 Strategy Architect Review Checklist

## قبل از بستن فصل ۱۴

- [ ] آیا همه معیارهای مهم حفظ شده‌اند؟
- [ ] آیا win rate به‌عنوان معیار سلامت اولیه ثبت شده است؟
- [ ] آیا expectancy و dollar outcome هم جدا ثبت شده‌اند؟
- [ ] آیا همه خانواده‌ها مستقل بررسی می‌شوند؟
- [ ] آیا خروج فقط به انتهای سایکل محدود نشده است؟
- [ ] آیا پنجره‌های بعدی بررسی می‌شوند؟
- [ ] آیا max intraday reward تعریف شده است؟
- [ ] آیا حرکت پیپی و حرکت نسبت به نوسان روز ثبت شده است؟
- [ ] آیا حداقل ۴۰۰ روز به‌عنوان نمونه اولیه ثبت شده است؟
- [ ] آیا استاپ‌های پشت هم و win rate بد به‌عنوان red flag ثبت شده‌اند؟
- [ ] آیا هیچ آستانه عددی قبل از تست قطعی نشده است؟
- [ ] آیا فصل با اصل بی‌طرفی قبل از آمار تناقض ندارد؟
