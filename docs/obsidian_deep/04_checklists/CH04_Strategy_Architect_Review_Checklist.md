# CH04 Strategy Architect Review Checklist

## Reference Scope

- [ ] آیا پذیرفته‌ایم که مرجع فقط سایکل قبلی نیست؟
- [ ] آیا همه سایکل‌های پیشین همان روز به‌عنوان مرجع دیده می‌شوند؟
- [ ] آیا روز قبل فعلاً از تحلیل ورود حذف شده است؟

## Signal Independence

- [ ] آیا هر current-reference relationship به‌عنوان سیگنال مستقل ثبت می‌شود؟
- [ ] آیا چند مرجع همزمان با هم یکی نشده‌اند؟
- [ ] آیا مرجع نزدیک و دور جدا دیده می‌شوند؟

## Statistical Neutrality

- [ ] آیا از قبل هیچ hierarchy برای مرجع‌ها تعریف نشده است؟
- [ ] آیا اولویت سایکل‌ها به آمار واگذار شده است؟
- [ ] آیا هیچ reference family قبل از تست حذف نشده است؟

## Reference Lifecycle

- [ ] آیا بین هانت یک‌نمادی و هانت دو‌نمادی فرق گذاشته شده است؟
- [ ] آیا واگرایی فقط وقتی باطل می‌شود که clean symbol هم هانت کند؟
- [ ] آیا مفهوم بازنشستگی مرجع با ابطال واگرایی قاطی نشده است؟

## Future Research

- [ ] آیا reference distance قابل مطالعه نگه داشته شده است؟
- [ ] آیا cash/pre-cash reference جدا قابل بررسی است؟
- [ ] آیا multi-reference cluster قابل مطالعه است؟
- [ ] آیا امکان ساخت hierarchy بعد از آمار باز گذاشته شده است؟
