# Phase 01 Strategy Architect Review Checklist

## زمان

- [ ] زمان بروکر درست نمایش داده می‌شود.
- [ ] UTC درست از زمان بروکر ساخته می‌شود.
- [ ] زمان نیویورک درست نمایش داده می‌شود.
- [ ] DST نیویورک در صورت فعال بودن درست اعمال می‌شود.

## روز معاملاتی

- [ ] شروع روز 18:00 نیویورک است.
- [ ] پایان روز 17:00 نیویورک است.
- [ ] ساعت 17:00 تا 17:59 خارج از میدان فعال نمایش داده می‌شود.

## CGها

- [ ] همه CGهای موردنیاز وجود دارند.
- [ ] خاموش/روشن کردن نمایش هر CG درست کار می‌کند.
- [ ] سایکل جاری هر CG درست است.
- [ ] تعداد سایکل‌های قبلی همان روز درست است.
- [ ] سایکل ناقص آخر روز درست علامت‌گذاری می‌شود.

## مرز فاز

- [ ] هیچ معامله‌ای باز نمی‌شود.
- [ ] هیچ واگرایی تشخیص داده نمی‌شود.
- [ ] هیچ مرجع قیمتی ساخته نمی‌شود.
- [ ] اکسپرت فقط Time Anatomy را نشان می‌دهد.
