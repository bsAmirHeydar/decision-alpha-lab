# CH17 Strategy Architect Review Checklist

## مرز AI

- [ ] آیا AI فقط تحلیلگر، رتبه‌دهنده و مقایسه‌گر تعریف شده است؟
- [ ] آیا AI از معامله‌گر مستقل بودن منع شده است؟
- [ ] آیا AI از تغییر شروط ورود و خروج منع شده است؟
- [ ] آیا AI از تغییر تارگت زمانی منع شده است؟
- [ ] آیا AI از تغییر بازه روزانه معاملاتی منع شده است؟

## ثابت‌های استراتژی

- [ ] آیا سایکل‌گروپ‌ها به‌عنوان ثابت پایه حفظ شده‌اند؟
- [ ] آیا تعریف واگرایی ثابت مانده است؟
- [ ] آیا تعریف هانت ثابت مانده است؟
- [ ] آیا شرط کلوز کندل ثابت مانده است؟
- [ ] آیا قانون clean symbol ثابت مانده است؟

## یادگیری زبان

- [ ] آیا یادگیری زبان معمار مجاز اما محدود شده است؟
- [ ] آیا مشخص است زبان فقط برای گزارش بهتر استفاده می‌شود؟
- [ ] آیا زبان به قانون اجرایی تبدیل نمی‌شود؟

## تحلیل مولفه‌ها

- [ ] آیا وین‌ریت بررسی می‌شود؟
- [ ] آیا برآیند بررسی می‌شود؟
- [ ] آیا R بررسی می‌شود؟
- [ ] آیا pip outcome بررسی می‌شود؟
- [ ] آیا normalized movement بررسی می‌شود؟
- [ ] آیا CG type و CG position بررسی می‌شوند؟
- [ ] آیا overlap بررسی می‌شود؟
- [ ] آیا signal frequency بررسی می‌شود؟

## حکمرانی خروجی مدل

- [ ] آیا پیشنهاد مدل قانون تلقی نمی‌شود؟
- [ ] آیا rule promotion نیازمند تایید معمار است؟
- [ ] آیا تغییرات آینده باید نسخه‌بندی شوند؟
- [ ] آیا مدل باید همه سیگنال‌ها را تحلیل کند؟
- [ ] آیا حذف انتخابی قبل از تحلیل ممنوع است؟
