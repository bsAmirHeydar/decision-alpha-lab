# CH15 Strategy Architect Review Checklist

## Sample boundary

- [ ] Does the primary sample include only confirmed, tradeable signals?
- [ ] Are raw hunts excluded from the main performance sample?
- [ ] Are unconfirmed divergences kept out of primary expectancy?

## Mandatory report fields

- [ ] Is cycle-group type always recorded?
- [ ] Is direction always recorded?
- [ ] Is hunter symbol always recorded?
- [ ] Is clean symbol always recorded?
- [ ] Is confirmation time always recorded?
- [ ] Is reference relationship preserved?

## Metrics

- [ ] Is win rate reported?
- [ ] Is R:R reported?
- [ ] Is dollar outcome reported?
- [ ] Is pip or point movement reported?
- [ ] Is movement divided by daily range reported?
- [ ] Is cycle-end result reported?
- [ ] Is maximum favorable movement reported?
- [ ] Is maximum adverse movement reported?

## Frequency and overlap

- [ ] Are signals counted per day?
- [ ] Are signals counted per week?
- [ ] Are signals counted per month?
- [ ] Is CG overlap recorded?
- [ ] Is same-direction and opposite-direction overlap separated?

## Language

- [ ] Are emotional labels removed?
- [ ] Are measurable terms used instead?
- [ ] Are recommended fields descriptive rather than filters?

## Statistical readiness

- [ ] Can the report later classify CG families?
- [ ] Can it later classify direction families?
- [ ] Can it later classify symbol-role families?
- [ ] Can it later support AI scoring?
