# CH11 Strategy Architect Review Checklist

## استقلال CGها

- [ ] آیا هر CG به‌عنوان خانواده مستقل دیده شده است؟
- [ ] آیا از انتقال اعتبار بین CGها جلوگیری شده است؟
- [ ] آیا از انتقال ضعف بین CGها جلوگیری شده است؟
- [ ] آیا هیچ CG قبل از آمار وزن یا اولویت نگرفته است؟

## جهت‌ها

- [ ] آیا buy و sell هر دو در میدان باقی مانده‌اند؟
- [ ] آیا هیچ جهت قبل از آمار حذف نشده است؟
- [ ] آیا buy و sell جداگانه ثبت می‌شوند؟

## روز معاملاتی

- [ ] آیا روز جاری مستقل از روزهای قبلی دیده شده است؟
- [ ] آیا reference روز قبل وارد تصمیم امروز نشده است؟
- [ ] آیا نتیجه روز قبل bias تصمیم امروز نشده است؟

## پژوهش

- [ ] آیا استقلال CGها باعث تمیزی آمار شده است؟
- [ ] آیا confluence فقط ثبت شده و نه اعتباردهی؟
- [ ] آیا روابط احتمالی بین CGها به‌عنوان فرضیه نگه داشته شده‌اند؟

## نتیجه

فصل ۱۱ وقتی کامل رعایت شده که هیچ CG و هیچ روزی قبل از آمار به دیگری معنا، اعتبار یا وزن ندهد.
