# Alpha Lab Philosophy

## هسته فلسفی

Alpha Lab برای پیدا کردن «سیگنال جادویی» نیست؛ برای ساختن یک لابراتوار است که ایده، تجربه، کد، تست، شکست و اجرا را در یک زنجیره قابل audit قرار می‌دهد.

## گزاره مادر

بازار به عنوان یک آناتومی دیده می‌شود. این آناتومی باید به زبان داخلی پروژه تعریف شود و سپس با آزمایش و validation سنجیده شود.

## ضدالگوها

- تکیه روی کلمات مبهم مثل «فرکتال» بدون metric.
- تکیه روی بک‌تست مثبت بدون baseline.
- تغییر کد execution بدون trace.
- استفاده از AI برای تصمیم پول واقعی بدون guardrail.
- رها کردن ایده‌های ردشده بدون archive و درس.

این ایده از کجا آمد؟

کدام کد آن را اجرا می‌کند؟
کدام ریسک آن را محدود می‌کند؟
