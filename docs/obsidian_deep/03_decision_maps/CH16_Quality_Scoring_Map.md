# CH16 Quality Scoring Map

## مولفه‌های score

```text
Win Rate
+ Expectancy
+ R Outcome
+ Pip Outcome
+ Daily Range Normalization
+ Sample Size
- Stop Streak Risk
- Bad Winrate Risk
- Invalidation Risk
+/- CG Overlap Effect
```

## تفسیر

Score بالا یعنی خانواده ارزش بررسی دارد.

Score پایین یعنی خانواده ممکن است نیازمند حذف، کاهش وزن، یا نمونه بیشتر باشد.

## ممنوعیت

Score به معنی ورود خودکار نیست.
