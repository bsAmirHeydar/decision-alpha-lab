# CG Chapter 03 Decision Map

## هدف نقشه

این نقشه تصمیم نشان می‌دهد معمار استراتژی در فصل سوم چه قوانین پایه‌ای را قفل کرده است.

## نقشه

### آیا قیمت به مرجع رسیده یا از آن عبور کرده است؟

اگر بله، هانت رخ داده است.

اگر خیر، مرجع هنوز تازه است.

### آیا کلوز پشت مرجع داریم؟

در تعریف هانت مهم نیست.

### آیا کندل بررسی بسته شده است؟

اگر خیر، واگرایی هنوز قطعی نیست.

اگر بله، وضعیت عدم تقارن بررسی می‌شود.

### آیا فقط یکی از دو نماد هانت کرده است؟

اگر بله، واگرایی زنده است.

اگر هر دو هانت کرده‌اند، واگرایی باطل است.

### آیا مرجع قبلاً هانت شده بود؟

اگر بله، مرجع مصرف‌شده است و نباید سیگنال تازه بسازد.

اگر خیر، می‌تواند مرجع معتبر باشد.

## نتیجه نهایی

فصل سوم تصمیم را به سه محور کاهش می‌دهد:

- آیا مرجع لمس یا عبور شده؟
- آیا فقط یک نماد این کار را کرده؟
- آیا مرجع تازه بوده؟
