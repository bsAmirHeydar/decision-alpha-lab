# CH19 — Post-Confirmation Invalidation Map

## مرحله‌ها

1. واگرایی بالقوه؛
2. کلوز کندل؛
3. تأیید نهایی؛
4. ورود؛
5. بعد از چند کندل:
   - اگر clean symbol مرجع را هانت کند → ابطال بعد از تأیید؛
   - اگر استاپ بخورد → outcome stop؛
   - اگر هر دو رخ دهند → هر دو ثبت شوند.

## تفاوت‌ها

- invalidation before trade permission → سیگنال قابل معامله نیست.
- invalidation after trade permission → نمونه آماری معتبر با نتیجه شکست/ابطال.
