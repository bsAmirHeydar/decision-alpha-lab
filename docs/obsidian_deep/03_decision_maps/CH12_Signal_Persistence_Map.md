# CH12 — Signal Persistence Map

```text
Hunt in one symbol
↓
Candle close confirms asymmetry
↓
Clean symbol remains unhunted
↓
Signal persists
↓
Either cycle result is reached OR clean reference gets hunted
↓
If both hunted → divergence invalidated
```

## استفاده

این نقشه برای تمایز بین سیگنال زنده، سیگنال باطل و سیگنال تمام‌شده از نظر نتیجه استفاده می‌شود.
