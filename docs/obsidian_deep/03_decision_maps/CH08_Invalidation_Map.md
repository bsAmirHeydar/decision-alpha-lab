# CH08 Invalidation Map

## Valid Asymmetry

```text
Symbol A hunts
Symbol B does not hunt
Candle closes
Divergence valid
```

## Invalid Double Hunt

```text
Symbol A hunts
Symbol B hunts
No asymmetry
No divergence
```

## Invalidation After Potential Divergence

```text
Symbol A hunts
Symbol B initially clean
Symbol B later hunts before close
Candle closes
Divergence invalid
```

## Law

Divergence requires one-sided behavior. Two-sided hunt cancels it.
