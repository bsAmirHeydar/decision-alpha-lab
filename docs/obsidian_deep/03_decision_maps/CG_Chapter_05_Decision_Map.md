# CG Chapter 05 Decision Map

```text
آیا رویداد داخل یک CG مشخص رخ داده؟
  ↓
بله → CG به‌عنوان واحد رفتاری مستقل ثبت شود
  ↓
آیا CG از قبل برتری دارد؟
  ↓
خیر → همه CGها برابرند
  ↓
آیا همه CGها اجازه معامله دارند؟
  ↓
بله → همه وارد آمار می‌شوند
  ↓
آیا تفاوت رفتاری دیده شد؟
  ↓
فقط بعد از تست آماری معتبر است
```

## قفل تصمیم

هیچ تصمیمی برای حذف، اولویت یا وزن‌دهی CG قبل از داده کافی گرفته نمی‌شود.
