# CH04 Statistical Hierarchy Discovery Map

## هدف

ساخت hierarchy بعد از آمار، نه قبل از آن.

## مسیر کشف

```text
Collect all reference families
↓
Separate by CG
↓
Separate by reference distance
↓
Separate by hunter / clean symbol
↓
Separate by direction
↓
Separate by time of day
↓
Measure win rate, expectancy, invalidation, movement quality
↓
Discover reference hierarchy
```

## خروجی آینده

ممکن است بعداً بعضی reference familyها:

- حذف شوند
- وزن کمتر بگیرند
- وزن بیشتر بگیرند
- فقط در بعضی ساعت‌ها معتبر باشند
- فقط با بعضی CGها معامله شوند
