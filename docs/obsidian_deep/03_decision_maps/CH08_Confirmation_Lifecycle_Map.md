# CH08 Confirmation Lifecycle Map

## Lifecycle

```text
Fresh reference
↓
Hunter touches/passes reference
↓
Potential divergence
↓
Active candle still open
↓
Clean symbol remains clean
↓
Candle closes
↓
Confirmed divergence
↓
Trade permission
```

## Alternate Path

```text
Fresh reference
↓
Hunter touches/passes reference
↓
Potential divergence
↓
Clean symbol also hunts
↓
Divergence cancelled
```

## Meaning

Confirmation is the survival of asymmetry until the candle close.
