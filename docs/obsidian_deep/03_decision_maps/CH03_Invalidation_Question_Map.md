# CH03 Invalidation Question Map

## سؤال مرکزی

واگرایی چه زمانی از بین می‌رود؟

## پاسخ پایه

وقتی نماد clean هم هانت کند.

## مسیر پرسش

### آیا یک نماد هانت کرده و دیگری نه؟

اگر بله، واگرایی وجود دارد.

### آیا نماد clean بعداً همان رفتار را تأیید کرده است؟

اگر بله، واگرایی باطل است.

### آیا مرجع قبلاً مصرف شده بوده؟

اگر بله، اصلاً نباید واگرایی تازه ساخته می‌شد.

### آیا تفاوت نوع هانت مهم است؟

در لایه پایه، خیر.

## دسته‌های آینده برای مطالعه

- ابطال سریع
- ابطال دیرهنگام
- ابطال قبل از ورود
- ابطال بعد از ورود
- ابطال داخل همان سایکل
- ابطال نزدیک انتهای سایکل
