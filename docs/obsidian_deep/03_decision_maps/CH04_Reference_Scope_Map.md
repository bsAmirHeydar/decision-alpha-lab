# CH04 Reference Scope Map

```text
Trading Day starts 18:00 NY
↓
Cycle 1 builds references
↓
Cycle 2 can compare with Cycle 1
↓
Cycle 3 can compare with Cycle 1 and Cycle 2
↓
Cycle N can compare with Cycle 1 ... Cycle N-1
↓
Trading Day ends 17:00 NY
↓
Previous-day references are removed from entry analysis
```

## مفهوم

هرچه روز جلوتر می‌رود، حافظه مرجع روز گسترده‌تر می‌شود. اما با شروع روز جدید، حافظه ورود reset می‌شود.
