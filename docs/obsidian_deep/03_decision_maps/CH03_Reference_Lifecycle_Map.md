# CH03 Reference Lifecycle Map

## هدف

این نقشه عمر مرجع را از تازگی تا مرگ نشان می‌دهد.

## مرحله ۱ — مرجع تازه

سطح هنوز دست‌نخورده است.

## مرحله ۲ — اولین هانت

قیمت به سطح می‌رسد یا از آن عبور می‌کند.

## مرحله ۳ — مصرف نقدینگی

مرجع کیفیت اولیه خود را از دست می‌دهد.

## مرحله ۴ — واگرایی احتمالی

اگر فقط یکی از دو نماد هانت کرده باشد، واگرایی شکل می‌گیرد.

## مرحله ۵ — انتظار برای عدم تأیید یا ابطال

اگر طرف مقابل هانت نکند، عدم تقارن باقی می‌ماند.

اگر طرف مقابل هم هانت کند، واگرایی باطل می‌شود.

## مرحله ۶ — پایان اعتبار

مرجع مصرف‌شده یا باطل‌شده دیگر نباید برای تولید سیگنال تازه استفاده شود.
