## خوانش رخداد

وقتی reference در یکی از دو نماد هانت می‌شود:

1. بررسی کن آیا نماد مقابل هم همان سمت را هانت کرده است یا نه.
2. اگر هر دو هانت کرده‌اند، واگرایی نداریم.
3. اگر فقط یکی هانت کرده، واگرایی داریم.
4. نمادی که هانت کرده = hunter
5. نمادی که هانت نکرده = clean
6. معامله روی clean symbol است.

## وزن زمانی

اگر رخداد بین 09:30 تا 16:00 نیویورک باشد:

- رابطه وزن تفسیری بالاتری دارد.
- اما هنوز باید با آمار اثبات شود که خروجی بهتری دارد.

اگر بیرون این بازه باشد:

- رابطه همچنان وجود دارد.
- اما ممکن است کیفیت و نقدینگی متفاوت باشد.
