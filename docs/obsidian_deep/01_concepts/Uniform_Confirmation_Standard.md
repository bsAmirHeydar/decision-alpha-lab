# Uniform Confirmation Standard

## Definition

The same confirmation rule applies to all cycle groups, both symbols, both directions, and all reference families.

## Rule

The active candle must close and the divergence must still exist.

## What It Prevents

- one CG receiving a stricter rule before testing,
- one time window receiving special confirmation before evidence,
- one symbol receiving special treatment,
- manual narrative-based filtering.

## Future

Statistics may later justify specialized confirmation families. Until then, confirmation remains uniform.
