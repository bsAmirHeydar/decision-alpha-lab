# Multi-Reference Divergence Cluster

## تعریف

وقتی سایکل فعلی نسبت به چند مرجع قبلی همزمان یا نزدیک به هم واگرایی می‌دهد، یک cluster از مراجع شکل می‌گیرد.

## دو احتمال

1. این تراکم می‌تواند قدرت سیگنال را بیشتر کند.
2. یا می‌تواند فقط تکرار noise باشد.

## وضعیت فعلی

هیچ قضاوتی نداریم. باید ثبت و تست شود.

## اهمیت آینده

اگر clusterها ارزشمند باشند، می‌توانند تبدیل به یک معیار کیفیت مهم شوند.
