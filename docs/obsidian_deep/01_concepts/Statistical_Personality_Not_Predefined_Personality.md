# Statistical Personality, Not Predefined Personality

## تعریف

شخصیت یک CG نباید از قبل ساخته شود. شخصیت اگر وجود داشته باشد، باید بعداً از آمار بیرون بیاید.

## شخصیت‌های ممنوع قبل از آمار

- CG کوچک = نویز
- CG بزرگ = قدرت
- CG میانی = تعادل
- CG رند = اعتبار
- CG غیررند = ضعف
- CG بلند = حرکت بزرگ
- CG کوتاه = حرکت کوچک

## شخصیت آماری

شخصیت آماری یعنی بعد از مشاهده کافی بتوانیم بگوییم:

- این CG در این شرایط بهتر عمل کرده است.
- این CG در این session ضعیف‌تر بوده است.
- این CG در این جهت نرخ ابطال بیشتری داشته است.
- این CG در این hunter/clean combination برآیند بهتری داده است.

## اصل

اول داده، بعد شخصیت.
