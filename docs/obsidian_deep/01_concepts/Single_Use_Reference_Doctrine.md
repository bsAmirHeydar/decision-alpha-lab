# Single Use Reference Doctrine

## اصل مرکزی

هر مرجع فقط یک‌بار برای هانت معتبر است.

## دلیل

مرجع تازه ناحیه‌ای است که نقدینگی اصلی آن هنوز مصرف نشده. با اولین هانت، آن نقدینگی مصرف می‌شود و مرجع کیفیت اولیه خود را از دست می‌دهد.

## ممنوعیت

نباید از یک مرجع مصرف‌شده دوباره برای تولید واگرایی تازه استفاده کرد.

## خطاهایی که این اصل جلوگیری می‌کند

- تولید سیگنال‌های تکراری
- شمارش چندباره یک سطح
- معاملات پشت‌سرهم روی یک نقدینگی مصرف‌شده
- آلودگی آمار
- اشتباه گرفتن re-test با واگرایی تازه
