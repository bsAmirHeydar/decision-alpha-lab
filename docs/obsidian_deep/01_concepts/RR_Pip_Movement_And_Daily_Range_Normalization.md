# R:R, Pip Movement, and Daily Range Normalization

## تعریف

این نوت سه معیار را کنار هم می‌گذارد:

1. ریسک به ریوارد
2. مقدار پیپ یا پوینت حرکت
3. مقدار حرکت نسبت به نوسان کل روز

## چرا نسبت به نوسان روز مهم است؟

حرکت مطلق بدون context گمراه‌کننده است. ۲۰ پیپ در یک روز ۳۰ پیپی معنی دیگری دارد نسبت به ۲۰ پیپ در یک روز ۳۰۰ پیپی.

## نتیجه

کیفیت واقعی حرکت باید هم مطلق و هم نسبی سنجیده شود.
