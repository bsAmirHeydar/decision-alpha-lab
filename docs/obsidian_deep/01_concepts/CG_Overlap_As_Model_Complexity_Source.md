# CG Overlap as Model Complexity Source

Cycle-group overlap can make the model complex because many CG families may produce same-direction or opposite-direction signals around the same market moment.

This is not a reason to remove overlap.
It is a reason to measure it carefully.

## Track

- overlap count;
- same-direction overlap;
- opposite-direction overlap;
- hedge clusters;
- same-symbol exposure;
- simultaneous confirmation;
- nearby confirmation;
- result compared to non-overlap signals.
