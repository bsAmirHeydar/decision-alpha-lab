# Reference Invalidation Versus Retirement

## مسئله

مرجع بعد از هانت شدن چه وضعیتی دارد؟

## پاسخ فصل چهارم

مرجع فقط با هانت شدن توسط یک نماد کاملاً بازنشسته نمی‌شود. بازنشستگی واقعی برای واگرایی وقتی است که هر دو نماد آن را هانت کنند و اختلاف رفتاری از بین برود.

## تفکیک مهم

### Hunter-only touch

یک نماد سطح را زده و دیگری نزده است. این وضعیت برای واگرایی مهم است.

### Both-symbol touch

هر دو نماد سطح متناظر خود را زده‌اند. واگرایی باطل شده است.

## قانون

```text
یک نماد هانت کند = امکان واگرایی
دو نماد هانت کنند = ابطال واگرایی
```
