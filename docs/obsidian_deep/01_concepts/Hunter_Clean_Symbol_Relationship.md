# Hunter / Clean Symbol Relationship

## تعریف رابطه

واگرایی وقتی معنی پیدا می‌کند که یکی hunter و دیگری clean باشد.

## حالت‌های اصلی

1. SPXUSD hunter / NDXUSD clean
2. NDXUSD hunter / SPXUSD clean

هر حالت باید جداگانه بررسی شود؛ چون ممکن است نتایج آن‌ها متفاوت باشد.

## در واگرایی نزولی

- hunter: نمادی که high را hunt کرده؛
- clean: نمادی که high را hunt نکرده؛
- معامله پایه: sell روی clean.

## در واگرایی صعودی

- hunter: نمادی که low را hunt کرده؛
- clean: نمادی که low را hunt نکرده؛
- معامله پایه: buy روی clean.
