# Independent Reference Signals

## تعریف

اگر سایکل فعلی نسبت به چند مرجع قبلی واگرایی بدهد، هرکدام یک سیگنال مستقل است.

## چرا مستقل؟

چون هر مرجع شخصیت زمانی، فاصله، جایگاه روز و کیفیت متفاوتی دارد.

## مثال

یک کندل ممکن است همزمان نسبت به:

- سایکل قبلی
- سه سایکل قبل
- اولین سایکل روز

واگرایی بدهد. این‌ها نباید یکی فرض شوند.

## نتیجه آینده

بعداً می‌توان فهمید کدام نوع مرجع واقعاً ارزشمندتر است.
