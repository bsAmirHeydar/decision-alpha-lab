# Double Hunt as Only Invalidation Boundary

## تعریف

Double hunt یعنی هر دو نماد سطح مرجع متناظر خود را هانت کرده باشند.

## پیام رفتاری

وقتی هر دو نماد هانت کنند، اختلاف رفتار اولیه از بین می‌رود. دیگر clean symbol وجود ندارد و واگرایی مرده است.

## قانون

> تنها ابطال قطعی سیگنال در فصل ۱۲، هانت شدن مرجع توسط هر دو نماد است.
