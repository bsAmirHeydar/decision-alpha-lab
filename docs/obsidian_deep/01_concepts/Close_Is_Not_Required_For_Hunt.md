# Close Is Not Required For Hunt

## اصل

برای هانت، کلوز پشت سطح لازم نیست.

## تفکیک مهم

- هانت با لمس یا عبور high/low تشخیص داده می‌شود.
- واگرایی بعد از بسته شدن کندل بررسی قطعی می‌شود.

## خطر اشتباه

اگر کلوز پشت سطح را شرط هانت کنیم، مدل به‌جای شکار نقدینگی، تبدیل به مدل شکست تأییدشده می‌شود. این با روح استراتژی فعلی هماهنگ نیست.

## نتیجه

کلوز برای «زمان قطعی شدن بررسی» لازم است، نه برای «خود هانت».
