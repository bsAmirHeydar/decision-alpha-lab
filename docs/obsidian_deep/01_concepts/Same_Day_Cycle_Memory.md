# Same-Day Cycle Memory

## تعریف

حافظه روز یعنی تمام سطوحی که از ابتدای روز معاملاتی فعلی تا قبل از سایکل فعلی ساخته شده‌اند.

روز معاملاتی در این مدل از 18:00 نیویورک شروع و تا 17:00 نیویورک ادامه دارد.

## چرا مهم است؟

بازار فقط به آخرین سایکل واکنش نشان نمی‌دهد. گاهی high یا low چند ساعت قبل، هنوز محل نقدینگی و اختلاف رفتار بین SPXUSD و NDXUSD است.

## قانون

فقط حافظه همان روز استفاده می‌شود. روز قبل برای ورود جدید وارد تحلیل نمی‌شود.

## پیام استراتژیک

حافظه روز یک محدوده زنده است، اما حافظه روزهای قبل فعلاً برای مدل خام حذف می‌شود تا تحلیل سبک، تمیز و قابل تست بماند.
