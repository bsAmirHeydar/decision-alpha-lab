# All Hunts Matter Doctrine

## اصل

همه هانت‌های معتبر مهم‌اند.

## معنای اصل

در لایه پایه هیچ هانتی حذف نمی‌شود. هر لمس یا عبور معتبر، داده رفتاری است.

## چرا مهم است؟

اگر از ابتدا بعضی هانت‌ها حذف شوند، پژوهش نمی‌تواند بفهمد کدام خانواده هانت واقعاً بهتر یا بدتر است.

## بعداً چه می‌شود؟

بعداً می‌توان هانت‌ها را طبقه‌بندی کرد:

- high hunt / low hunt
- SPX hunter / NDX hunter
- cash session / outside cash session
- exact touch / shallow break / deep break
- early-cycle / mid-cycle / late-cycle

اما این‌ها فیلتر اولیه نیستند.
