# CG Position and Type as Primary Features

## اصل

در فصل ۱۶، نوع سایکل‌گروپ و جایگاه آن مهم‌ترین مولفه‌های مدل هستند.

## نوع سایکل‌گروپ

مثل:

- cg_30m
- cg_180m
- cg_720m

نوع CG نشان می‌دهد سیگنال به کدام خانواده زمانی تعلق دارد.

## جایگاه

جایگاه یعنی سیگنال در کجای زمان رخ داده است:

- کجای روز؛
- کجای سایکل؛
- داخل cash session یا خارج آن؛
- نزدیک شروع یا پایان؛
- در فضای stop pressure زیاد یا کم.

## دلیل اهمیت

چون استراتژی از اساس حول سایکل ساخته شده است، پس مدل باید بیشترین توجه را به ساختار زمانی داشته باشد.
