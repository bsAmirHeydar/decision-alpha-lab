# No CG Behavioral Difference Before Testing — Expanded

## اصل

هیچ سایکل‌گروپی با دیگری از لحاظ نوع رفتار فعلاً تفاوتی ندارد مگر اینکه آمار خلاف آن را نشان دهد.

## دامنه اصل

این اصل شامل تمام ابعاد رفتار می‌شود:

- قدرت سیگنال
- اعتبار سیگنال
- جهت buy
- جهت sell
- نرخ ابطال
- کیفیت حرکت
- تعداد سیگنال
- سودآوری
- برآیند
- session dependency
- نماد hunter
- نماد clean
- reference distance
- چندمرجعی بودن

## تفسیر درست

فصل ششم نمی‌گوید تفاوتی در واقعیت نیست؛ فقط می‌گوید تفاوت هنوز حق تبدیل شدن به قانون ندارد.

## ارزش این اصل

این اصل باعث می‌شود پروژه از ابتدا بر پایه discovery ساخته شود، نه بر پایه روایت ذهنی.
