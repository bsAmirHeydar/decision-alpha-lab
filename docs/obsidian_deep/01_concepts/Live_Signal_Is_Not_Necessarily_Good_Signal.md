# Live Signal Is Not Necessarily Good Signal

## اصل تفکیک

زنده بودن سیگنال فقط یعنی هنوز باطل نشده است. این به‌تنهایی اثبات نمی‌کند که سیگنال سودآور، قوی، تمیز یا قابل‌اولویت است.

## چرا مهم است؟

برای جلوگیری از overconfidence. یک سیگنال زنده باید ثبت شود، اما کیفیت آن باید با آمار مشخص شود.
