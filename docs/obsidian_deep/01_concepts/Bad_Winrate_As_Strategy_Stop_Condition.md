# Bad Win Rate As Strategy Stop Condition

## تعریف

وین‌ریت خیلی بد می‌تواند شرط توقف، حذف یا downgrade یک خانواده سیگنال باشد.

## نکته

این شرط قبل از آمار فعال نیست. بعد از نمونه کافی، اگر یک خانواده به‌صورت پایدار win rate بسیار ضعیف داشته باشد، دیگر نباید با بی‌طرفی خام معامله شود.
