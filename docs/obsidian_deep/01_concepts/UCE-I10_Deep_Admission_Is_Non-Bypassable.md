# UCE-I10 Deep Admission Is Non-Bypassable

A deep candidate is not merely “discouraged” before support and classical gates; the Trainer SDK must reject it. Admission evidence is immutable, dataset-bound, and consumed by qualification and UCE-I11 scheduling.

## Consequence

Violating this rule invalidates the affected artifact and blocks promotion. The rule is represented in Python contracts/tests, closed JSON schemas, and the UCE-I10 acceptance evidence.
