# No Dominance Before Testing

## اصل

تا قبل از آزمون، هیچ نمادی در نقش hunter یا clean برتر فرض نمی‌شود.

## معنی این اصل

نباید بگوییم:

- SPXUSD همیشه بهتر است؛
- NDXUSD همیشه بهتر است؛
- hunter بودن یک نماد همیشه قوی‌تر است؛
- clean بودن یک نماد همیشه سودآورتر است.

## راه درست

برتری‌ها باید از خانواده‌های رفتاری بیرون بیایند:

- نماد hunter؛
- نماد clean؛
- جهت؛
- cash یا non-cash؛
- CG؛
- نتیجه معامله.
