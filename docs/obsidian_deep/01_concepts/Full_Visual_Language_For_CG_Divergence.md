# Full Visual Language For CG Divergence

The visual layer must not merely mark that a signal exists. It must reveal the structure of the divergence.

A complete drawing answers:

- Which CG produced the state?
- Was the state buy-side or sell-side?
- Which symbol hunted?
- Which symbol stayed clean?
- What was the origin reference?
- What was the destination extreme?
- Where was the confirmation boundary?
- Which levels are guides only and which line is the actual divergence leg?
