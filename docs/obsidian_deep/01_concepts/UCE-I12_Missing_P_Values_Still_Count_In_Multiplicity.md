# Missing P Values Still Count In Multiplicity

A trial without a valid p-value contributes p=1 to the family denominator when complete-universe accounting is enabled. Absence is not a free deletion.

## Operational consequence

This concept is enforced by executable contracts, negative fixtures, closed schemas, and the non-compensatory promotion gate. A consumer may not weaken it through undocumented interpretation.
