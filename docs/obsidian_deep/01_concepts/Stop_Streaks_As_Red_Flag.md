# Stop Streaks As Red Flag

## تعریف

استاپ‌های پشت هم زیاد، علامت خطر برای یک خانواده سیگنال است.

## چرا مهم است؟

حتی اگر برآیند بلندمدت مثبت باشد، توالی شدید ضرر می‌تواند مدل را از نظر روانی و سرمایه‌ای غیرقابل اجرا کند.

## تصمیم‌های ممکن

- کاهش وزن
- حذف موقت
- نیاز به فیلتر بعدی
- بررسی پنجره خروج متفاوت
- انتقال به research-only
