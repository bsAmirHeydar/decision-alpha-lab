# Research Memory Versus Decision Memory

## تعریف

فصل ۱۱ بین حافظه پژوهشی و حافظه تصمیم‌گیری فرق می‌گذارد.

## حافظه پژوهشی

همه روزها و سیگنال‌ها ذخیره می‌شوند تا آمار ساخته شود.

## حافظه تصمیم‌گیری

برای تصمیم امروز، روز قبل وارد مدل خام نمی‌شود.

## اصل

گذشته برای یادگیری تاریخی مهم است، اما برای سیگنال خام امروز نباید bias بسازد.
