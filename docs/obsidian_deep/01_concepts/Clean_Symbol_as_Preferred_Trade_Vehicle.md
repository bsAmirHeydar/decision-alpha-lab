# نماد تمیز به‌عنوان نماد ترجیحی معامله

## تعریف

در واگرایی EXP0017، نماد معامله همان نمادی است که هانت نکرده است.

## منطق

وقتی یک نماد reference را هانت می‌کند و نماد دیگر نمی‌کند، نماد hunter واکنش نقدینگی خود را نشان داده است. نماد clean هنوز وارد همان رفتار نشده است و همین اختلاف، فرصت معامله را در نماد clean تعریف می‌کند.

## قانون پایه

- low hunt فقط روی یک نماد → واگرایی صعودی → buy روی clean symbol
- high hunt فقط روی یک نماد → واگرایی نزولی → sell روی clean symbol

## هشدار تحقیقاتی

این قانون پایه است، اما بعداً باید در آمار سنجیده شود. ممکن است داده نشان دهد در بعضی خانواده‌ها hunter continuation نیز معنا دارد. تا قبل از آن، قانون رسمی معامله روی clean symbol است.

## داکترین

clean symbol نماد اجرایی اصلی است؛ چون استراتژی روی اختلاف رفتار و عقب‌ماندگی/امتناع نماد clean بنا شده است.
