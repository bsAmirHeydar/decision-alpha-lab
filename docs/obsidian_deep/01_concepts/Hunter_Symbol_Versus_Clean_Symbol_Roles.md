# Hunter Symbol versus Clean Symbol Roles

## Hunter Symbol

نمادی است که سطح مرجع را هانت کرده است.

زبان رفتاری آن:

- جمع‌آوری نقدینگی
- شکست یا لمس سطح
- مصرف مرجع

## Clean Symbol

نمادی است که سطح مرجع خود را هانت نکرده است.

زبان رفتاری آن:

- سالم‌ماندن مرجع
- مقاومت در برابر حرکت نماد مقابل
- محل اصلی معامله

## تفاوت نقش‌ها

Hunter اتفاق را آشکار می‌کند.  
Clean محل معامله را مشخص می‌کند.
