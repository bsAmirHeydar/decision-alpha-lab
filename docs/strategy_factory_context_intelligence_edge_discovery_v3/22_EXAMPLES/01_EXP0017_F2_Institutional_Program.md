# Purpose

Use the EXP0017/F2 family as the first reference program for SAED V3 without claiming fixture performance as alpha.

## Frozen context

- Exact EXP0017/F2 context package and known-time lifecycle
- Higher-timeframe phase and reference views
- No outcome-informed context relabeling
- Every occurrence, including incomplete and expired cases, retained

## Initial candidate lattice

```text
P1 × {Market, Pullback Limit}
P2 × {Breakout, Market, Pullback Limit}
P3 × {Breakout, Pullback Limit} × {Structural Trail, Volatility Trail}
P4 × {Breakout, Market, Pullback Limit} × {Structural Trail}
P5 × {Pullback Limit, Confirmed Market}
+ Skip
```

Stop, exit, and management atoms remain deliberately narrow in the first tournament. Expansion requires a new universe version.

## Learning ladder

1. Manual EXP0017 policy.
2. Unconditional treatment means by profile.
3. Context-only regularized models.
4. Calibrated tree and ranking baselines.
5. Survival models for fill/stop/target/expiry.
6. Distributional outcomes.
7. Causal/orthogonal treatment ranking where support permits.
8. Patch/state-space/graph challengers.
9. Foundation-model adapters as features.
10. World-model/offline-policy research only after baseline evidence.

## Anti-overfit challenge

- Occurrence-clustered nested purged walk-forward
- Complete candidate and trial ledgers
- P1–P5 profile-specific attacks
- Cross-feed and broker replay
- Best-trade, best-period, and best-cluster removal
- Delays, spreads, slippage, fill and path ambiguity
- Locked prospective paper
- UCEE I12–I18 handoff

## Decision

The reference program may validate infrastructure using fixtures. It cannot produce a promoted alpha claim until real immutable data, actual MetaEditor parity, and untouched prospective evidence exist.
