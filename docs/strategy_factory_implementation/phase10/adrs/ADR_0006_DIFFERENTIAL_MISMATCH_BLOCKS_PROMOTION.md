# Differential Mismatch Blocks Promotion

## Decision

Material mismatch between virtual and tester semantics blocks promotion and creates a regression obligation.

## Consequences

The rule is enforced by the MQL5 research harness, schemas, tests and operating runbook. Any exception requires a new ADR and a versioned contract change.
