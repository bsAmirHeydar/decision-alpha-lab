# MQL5 Owns Outcome Semantics

## Decision

Historical, tester, paper and future live paths must consume the same candidate and outcome semantics defined first in MQL5.

## Consequences

The decision is enforced through contracts, engine behavior, run manifests, replay requirements, conformance tests and promotion gates.
