# Definition of Done

Done requires deterministic graph compile, causal snapshot creation, fixed vector compilation, stable frame identity, bounded memory, telemetry, Python parity, static policy pass, local MetaEditor compile, self-test pass and no legacy coupling.

- MQL5 owns runtime truth.

- Memory and work are bounded.
- No previous strategy is integrated.
