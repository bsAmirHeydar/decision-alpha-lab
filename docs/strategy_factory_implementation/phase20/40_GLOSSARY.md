# Glossary

- **Hunter symbol:** instrument that breached the reference.
- **Clean symbol:** paired instrument that did not breach and becomes canonical event symbol.
- **Raw divergence:** one-sided hunt observation without trade confirmation.
- **Known time:** first UTC time at which the adapter can state the observation.
- **Cluster:** stable market-event family across repeated pulses.
- **Differential replay:** legacy versus canonical comparison under identical evidence.
- **Pilot shadow:** full routing evidence without execution authority.
