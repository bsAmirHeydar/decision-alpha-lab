# Scope and Non-Goals

## In scope
- EXP0017 raw divergence candidate adapter
- exact static plugin registration
- candidate-to-event mapping
- deduplication and lifecycle retirement
- differential replay
- shared context, candidate, monitoring binding
- explicit gates for outcome, inference, decision, paper/shadow, and live

## Non-goals
- changing EXP0017 anatomy
- inventing confirmation permission
- training an EXP0017 model
- sending broker orders
- integrating NDS, Daye, structural nodes, ICT, astro, or manual setups in this patch
