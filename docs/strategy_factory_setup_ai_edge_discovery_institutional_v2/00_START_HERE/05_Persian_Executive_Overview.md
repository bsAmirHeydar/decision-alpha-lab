# هدف واقعی

این سیستم قرار نیست فقط یک مدل بسازد که بگوید خرید یا فروش. هدف آن ساخت یک کارخانه تحقیقاتی است که برای هر رخداد Context، تمام روش‌های اجرایی معتبر را به‌صورت کنترل‌شده تولید کند، پیامد اقتصادی هرکدام را با مسیر واقعی قیمت و هزینه واقعی بازسازی کند، و سپس یاد بگیرد در چه شرایطی کدام Treatment ارزش دارد یا باید معامله را رد کرد.

# معماری تصمیم

```text
کانتکس معتبر
→ فرضیه ستاپ
→ پروفایل سود و زیان
→ مکانیزم ورود
→ استاپ، خروج و مدیریت
→ نامزدهای محدود و رسمی
→ بازسازی نتیجه همه نامزدها
→ یادگیری چندوظیفه‌ای و علّی
→ عدم‌قطعیت و تشخیص خارج از دامنه
→ انتخاب / رد / Abstain
→ Policy امضاشده UCEE
```

# معنی «سطح میلیارد دلاری»

سطح مؤسسه‌ای با پیچیده‌ترین مدل تعریف نمی‌شود. با این موارد تعریف می‌شود:

- حقیقت داده و Known-Time غیرقابل دست‌کاری؛
- Trial Ledger کامل، حتی برای شکست‌ها؛
- جداسازی کامل Research و Production؛
- کنترل Multiple Testing و Selection Bias؛
- سنجش Capacity، Costs و Market Impact؛
- مدل ریسک مستقل؛
- قابلیت بازتولید کامل؛
- Promotion امضاشده؛
- Shadow و Prospective Evidence؛
- امکان Pause، Quarantine و Rollback فوری؛
- عدم وابستگی به یک مدل یا یک Regime.

# فلسفه استفاده از AI پیشرفته

Foundation Model، Graph Model، World Model و Offline RL در این معماری ابزار تحقیقاتی و Challenger هستند، نه Oracle. هر مدل پیشرفته باید ثابت کند نسبت به Manual Policy، مدل‌های ساده و Baselineهای کلاسیک، ارزش افزوده پایدار و اقتصادی دارد.
