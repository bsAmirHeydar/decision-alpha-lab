# Institutional objective

SAED V2 is the post-Context intelligence layer of Alpha Lab. It converts immutable UCEE context occurrences into a bounded lattice of complete treatment candidates, learns where each candidate has stable economic utility, and hands only support-audited, uncertainty-aware policies to the existing UCEE promotion, runtime, portfolio, and production-qualification layers.

This is not a single model and not an automated trading bot. It is an **institutional research operating system** with explicit separation between discovery, causal estimation, counterfactual replay, model selection, adversarial validation, promotion, and execution authority.

## Canonical system equation

```text
Immutable Context Evidence
× Setup Archetype
× Payoff Profile
× Entry Mechanism
× Trigger Philosophy
× Stop / Exit / Management Atoms
→ Finite Candidate Treatment Lattice
→ Counterfactual Economic Outcome Cube
→ Multi-task / Causal / Sequence / Graph Learning
→ Calibrated Lower-Confidence-Bound Utility
→ Trade / Skip / Abstain / Manual Fallback
```

## Technology doctrine

Every technology belongs to exactly one capability tier:

1. **Core Production** — interpretable, calibrated, reproducible, runtime-parity capable.
2. **Governed Challenger** — advanced models allowed only behind stronger evidence and shadow gates.
3. **Research-Only** — useful for representation, simulation, or stress generation but prohibited from direct live decisions.
4. **Prohibited-to-Live** — unbounded online learning, self-modification, direct LLM order authority, silent retraining, and unsigned promotion.

## Definition of institutional success

The system succeeds only when it can demonstrate, under locked prospective evidence, that a treatment policy produces incremental cost-adjusted utility beyond manual and simple baselines, remains stable under time, symbol, feed, broker, regime, and path perturbations, knows when it is outside support, and can be compiled into an immutable UCEE runtime generation without changing the meaning of the original context.
