# Strategy Overlap and Portfolio Dependence

Different names do not guarantee diversified PnL. Portfolio analysis uses event, exposure, and loss mechanisms.

## Overlap measures

Shared market-event clusters, concurrent direction, symbol beta, holding overlap, loss-day overlap, tail-loss correlation, and model-feature similarity. Evaluate both return correlation and conditional crisis behavior.

## Duplicate alpha

If Daye, SMT, NDS, and ICT all enter the same NQ expansion, treat them as one thesis unless one provides independent timing or payoff. Portfolio capital is assigned to exposure groups, not repository folders.

## Netting and conflict

Define priority, netting, hedge, or skip behavior when strategies disagree. Conflict rules are frozen and simulated; the live risk gate enforces aggregate exposure.
