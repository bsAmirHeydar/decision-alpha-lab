# Example — Structural Node and Optionality Mapping

Structural nodes provide a simpler control anatomy between raw price action and full NDS.

## Event

Confirmed node, territory, touch/revisit, survival or break state, direction, known time, and node lifecycle.

## Candidates

Touch limit, close-confirmed reversal, close-break continuation, node-extreme stop, ATR stop, opposing node target, fixed R, or regime exit.

## Tests

Matched random price levels, node-age buckets, survival duration, causal atomic replay, path versus execution R, and cross-timeframe duplication clusters.
