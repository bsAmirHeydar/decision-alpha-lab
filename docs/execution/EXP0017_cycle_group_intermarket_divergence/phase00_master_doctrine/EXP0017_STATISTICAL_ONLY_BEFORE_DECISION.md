# EXP0017 — Statistical Only Before Decision

## تعریف مرحله آماری

در نسخه پایه، آمار ابزار شناخت است، نه ابزار تغییر فوری استراتژی. هر سیگنال معتبر باید ثبت شود، نتیجه‌اش سنجیده شود، و سپس خانواده‌های آماری از دل آن استخراج شوند.

## نمونه آماری اصلی

نمونه آماری اصلی فقط شامل سیگنال‌هایی است که:

1. واگرایی معتبر داشته‌اند.
2. کندل تایید بسته شده است.
3. سیگنال قابل معامله شده است.
4. در لحظه تایید نهایی باطل نشده‌اند.

هانت خام و واگرایی بالقوه برای مطالعه جانبی قابل ثبت‌اند، اما وارد نمونه expectancy اصلی نمی‌شوند.

## معیارهای اصلی

### سلامت اولیه

- win rate
- stop rate
- consecutive stop streak

برای معمار استراتژی، win rate و کمتر استاپ خوردن اهمیت اولیه دارد.

### برآیند

- dollar outcome
- R outcome
- pip/point outcome
- expectancy

### کیفیت حرکت

- maximum favorable movement
- maximum adverse movement
- movement until cycle end
- maximum intraday reward
- day-end result
- giveback after maximum favorable movement

### شاخص نرمال‌شده

```text
pip outcome / total daily movement in pips
```

این شاخص کمک می‌کند بفهمیم سیگنال چه نسبتی از ظرفیت حرکتی روز را گرفته است.

## پنجره‌های نتیجه

فقط خروج در انتهای همان سایکل کافی نیست. باید چند پنجره بررسی شود:

- انتهای سایکل فعلی
- یک سایکل بعد
- دو سایکل بعد
- چند پنجره بعدی
- بیشترین ریوارد همان روز
- پایان روز معاملاتی

## حداقل نمونه اولیه

حداقل ۴۰۰ روز برای مطالعه اولیه پیشنهاد شده است.

این عدد تضمین نهایی نیست، اما کف اولیه مناسبی برای شروع شناخت خانواده‌های آماری است.

## خانواده‌های مستقل آمار

باید جداگانه بررسی شوند:

- CG
- direction
- hunter symbol
- clean symbol
- reference distance
- cash session status
- cycle position
- overlap state
- signal frequency
- stop size
- time to cycle end
- invalidation timing

## خروجی آماری نباید چه کند؟

آمار نباید به صورت خودکار:

- CG حذف کند.
- ورود را تغییر دهد.
- target را تغییر دهد.
- risk را تغییر دهد.
- hedge را ممنوع کند.
- محدودیت پوزیشن بسازد.

این‌ها فقط بعد از تصمیم معمار استراتژی وارد نسخه بعدی می‌شوند.
