# EXP0017 — Forbidden Assumptions Before Statistics

## هدف سند

این سند مشخص می‌کند در نسخه پایه چه فرض‌هایی ممنوع‌اند. این ممنوعیت‌ها برای جلوگیری از آلوده شدن داده خام و جلوگیری از پیش‌داوری طراحی شده‌اند.

## اصل مادر

```text
هر چیزی که هنوز با آمار ثابت نشده، نباید تبدیل به قانون، فیلتر، وزن، حذف، یا ترجیح اجرایی شود.
```

## فرض‌های ممنوع درباره CG

فعلاً ممنوع است بگوییم:

- CG بزرگ‌تر قوی‌تر است.
- CG کوچک‌تر نویزی‌تر است.
- CG خاصی معتبرتر است.
- CG خاصی فقط برای buy خوب است.
- CG خاصی فقط برای sell خوب است.
- CG خاصی نباید معامله شود.
- overlap چند CG حتماً قوی‌تر است.
- overlap خلاف‌جهت حتماً خطرناک است.

همه این‌ها فقط فرضیه‌اند.

## فرض‌های ممنوع درباره زمان

فعلاً ممنوع است بگوییم:

- فقط 09:30 تا 16:00 معتبر است.
- خارج از cash session بی‌ارزش است.
- اول بازار همیشه بهتر است.
- آخر بازار همیشه بدتر است.
- روز خبری باید حذف شود.
- نوع روز باید از ابتدا وارد تصمیم شود.

فرضیه قوی وجود دارد که cash session ممکن است بهتر باشد، اما هنوز قانون نیست.

## فرض‌های ممنوع درباره نمادها

فعلاً ممنوع است بگوییم:

- SPXUSD همیشه معتبرتر است.
- NDXUSD همیشه رهبر است.
- اگر SPX hunter باشد بهتر است.
- اگر NDX clean باشد بهتر است.
- یک نماد باید همیشه trade vehicle باشد.

SPXUSD جریان عمومی‌تر بازار است، اما این نقش تفسیری به معنی اعتبار اجرایی بیشتر نیست.

## فرض‌های ممنوع درباره هانت

فعلاً ممنوع است بگوییم:

- هانت عمیق‌تر معتبرتر است.
- لمس ضعیف‌تر از عبور است.
- wick بلند بهتر است.
- close پشت سطح لازم است.
- exact touch باید جداگانه اعتبار بیشتری داشته باشد.

این‌ها می‌توانند بعداً مطالعه شوند، اما در نسخه پایه فیلتر نیستند.

## فرض‌های ممنوع درباره سیگنال

فعلاً ممنوع است بگوییم:

- تعداد زیاد سیگنال اعتبار را کم می‌کند.
- چند سیگنال پشت‌سرهم باید حذف شوند.
- بعد از استاپ نباید سیگنال بعدی گرفته شود.
- سیگنال دیرهنگام بد است.
- استاپ بزرگ باعث حذف سیگنال است.
- سیگنال خلاف‌جهت باید سرکوب شود.

همه سیگنال‌های تاییدشده و باطل‌نشده وارد میدان آماری می‌شوند.

## فرض‌های ممنوع درباره مدل

مدل فعلاً حق ندارد:

- strategy را optimize کند.
- قوانین ورود و خروج را تغییر دهد.
- CGها را حذف کند.
- stop و target را عوض کند.
- ریسک را تغییر دهد.
- سیگنال‌ها را live فیلتر کند.

مدل فقط تحلیلگر است.

## دلیل این سخت‌گیری

اگر قبل از آمار فیلتر بسازیم، دیگر نمی‌فهمیم edge واقعی از کجا آمده است. نسخه خام باید میدان بی‌طرفی باشد.
