# Phase 09 Obsidian Guide

Use Phase 09 notes to navigate the ranking doctrine:

- Ranking is comparison, not execution.
- Quality score is a report, not a rule.
- Sample confidence prevents overtrusting tiny samples.
- Shortlist means review later, not trade now.
- Dashboard outputs are evidence surfaces.

Recommended review path:

1. Read the Phase 09 MOC.
2. Review the score formula contract.
3. Review dashboard outputs.
4. Check red flag and shortlist logic.
5. Only then discuss Phase 10 model-ready dataset design.
