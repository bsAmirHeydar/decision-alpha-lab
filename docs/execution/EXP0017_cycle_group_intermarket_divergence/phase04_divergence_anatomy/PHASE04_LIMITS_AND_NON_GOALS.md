# Phase 04 Limits And Non-Goals

Phase 04 does not provide:

```text
candle-close confirmation
trade permission
order placement
risk calculation
target calculation
time exit
post-confirmation invalidation
visual line drawing
signal ledger
statistical reports
model scoring
AI ranking
CG filtering
session filtering
position limits
```

## Why these are excluded

The strategy architecture requires the robot to see before it decides. Phase 04 teaches the robot what a raw divergence candidate is. It does not yet decide whether that candidate is confirmed, tradeable, statistically valuable, or executable.
