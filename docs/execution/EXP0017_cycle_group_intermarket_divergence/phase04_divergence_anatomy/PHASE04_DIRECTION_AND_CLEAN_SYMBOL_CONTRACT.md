# Phase 04 Direction And Clean Symbol Contract

## High-side doctrine

One-sided high hunt means sell-side divergence anatomy.

```text
one-sided high hunt => SELL candidate
```

## Low-side doctrine

One-sided low hunt means buy-side divergence anatomy.

```text
one-sided low hunt => BUY candidate
```

## Hunter symbol

The hunter symbol is the symbol that touched or broke its own reference.

## Clean symbol

The clean symbol is the symbol that did not touch or break its own corresponding reference.

## Future trade candidate

The clean symbol is recorded as the future trade candidate, but Phase 04 does not open orders.

## Stop reference preview

The clean symbol's un-hunted reference is recorded as the future stop reference preview:

```text
SELL candidate => clean symbol reference high
BUY candidate  => clean symbol reference low
```

This is a data field only. It is not an order-level stop yet.
