# Phase 04 Index — Divergence Anatomy

Phase 04 is the first EXP0017 layer that translates raw one-sided hunts into intermarket divergence candidates.

It does **not** create trade permission. It does **not** execute. It does **not** apply risk, targets, AI, ranking, filtering, or statistical preference.
