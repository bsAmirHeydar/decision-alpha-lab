# EXP0017 Phase 01 — Validation and Test Plan

## هدف تست

هدف تست این نیست که سودآوری بررسی شود. هدف فقط این است که مطمئن شویم ربات زمان را درست می‌بیند.

## تست ۱ — تبدیل زمان بروکر به نیویورک

با Broker UTC Offset پیش‌فرض +3، اکسپرت باید بتواند زمان بروکر را به UTC و سپس به New York تبدیل کند.

موارد بررسی:

- زمان UTC منطقی است.
- زمان New York با اختلاف DST درست نمایش داده می‌شود.
- در DST آمریکا، offset نیویورک باید -4 شود.
- خارج از DST، offset باید -5 شود.

## تست ۲ — مرز 18:00 نیویورک

در حوالی 18:00 نیویورک:

- 17:59 باید خارج از روز معاملاتی جدید باشد.
- 18:00 باید آغاز روز جدید باشد.
- cycle number همه CGها باید 1 شود.

## تست ۳ — مرز 17:00 نیویورک

در حوالی پایان روز:

- 16:59 باید هنوز داخل میدان روز معاملاتی باشد.
- 17:00 باید خارج از میدان فعال باشد.
- هیچ CG نباید سایکل جاری فعال داشته باشد.

## تست ۴ — cg_30m

نمونه‌های مورد انتظار:

| زمان NY | سایکل cg_30m |
|---|---|
| 18:00 | C01 |
| 18:29 | C01 |
| 18:30 | C02 |
| 18:59 | C02 |
| 19:00 | C03 |

## تست ۵ — cg_180m

نمونه‌های مورد انتظار:

| زمان NY | سایکل cg_180m |
|---|---|
| 18:00 | C01: 18:00-20:59 |
| 21:00 | C02: 21:00-23:59 |
| 00:00 | C03: 00:00-02:59 |

## تست ۶ — سایکل‌های ناقص

برای CGهایی که ۱۳۸۰ بر طولشان بخش‌پذیر نیست، آخرین سایکل باید `partial-last` بخورد.

نمونه:

- `cg_180m`
- `cg_720m`
- `cg_300m`

## تست ۷ — خاموش/روشن کردن CGها

هر input از نوع `InpShow_cg_Xm` باید فقط نمایش همان CG را کنترل کند.

## تست ۸ — عدم ترید

در ژورنال و History نباید هیچ معامله‌ای باز شود. این فاز باید 100٪ observer باشد.

## معیار قبولی فاز

فاز ۱ وقتی قبول است که برای چند روز معاملاتی مختلف، چند ساعت مختلف و چند CG متفاوت، سایکل جاری و previous cycle count دقیق باشد.
