# CH16 — Historical-Only Model Boundary

## اصل پایه

مدل فصل ۱۶ فعلاً فقط روی گذشته کار می‌کند.

این یعنی مدل برای مرحله اول قرار نیست روی بازار زنده تصمیم بگیرد. قرار است روی داده‌های ثبت‌شده، سیگنال‌های تأییدشده، نتایج معاملات، و رفتار پس از سیگنال مطالعه کند.

## چرا فقط گذشته؟

چون قبل از اینکه مدل بتواند در زمان حال یا آینده کمک کند، باید روشن شود که در گذشته چه چیزی واقعاً کار کرده است.

اگر مدل بدون شناخت آماری وارد زمان حال شود، فقط یک لایه پیچیده روی یک ابهام خام ساخته‌ایم.

## داده‌ای که مدل باید ببیند

مدل باید فقط سیگنال‌هایی را ببیند که:

- واگرایی معتبر داشته‌اند؛
- candle close تأیید داده است؛
- قابل معامله شده‌اند؛
- وضعیت hunter/clean مشخص بوده؛
- CG مشخص داشته‌اند؛
- reference مشخص داشته‌اند؛
- نتیجه نهایی یا پنجره‌های بعدی قابل اندازه‌گیری بوده؛
- invalidation یا عدم invalidation ثبت شده؛
- خروج زمانی یا حرکت بعدی قابل مطالعه بوده.

## داده‌ای که مدل نباید در نمونه اصلی ببیند

در نمونه اصلی مدل نباید موارد زیر وارد شود:

- hunt خام بدون تأیید؛
- واگرایی احتمالی قبل از close؛
- سیگنال باطل‌شده قبل از تبدیل شدن به فرصت قابل معامله؛
- برداشت بصری بدون نتیجه آماری؛
- احساس تریدر نسبت به چارت؛
- خبر؛
- روایت بیرونی بازار؛
- روزهای قبل به‌عنوان bias اجرایی روز بعد.

## مدل گذشته‌نگر چه می‌سازد؟

مدل گذشته‌نگر می‌تواند بسازد:

- جدول کیفیت خانواده‌ها؛
- رتبه‌بندی آماری پس از تست؛
- شناسایی CGهای پرخطر؛
- شناسایی CGهای امیدوارکننده؛
- کشف زمان‌های بهتر؛
- کشف hunter/clean بهتر؛
- کشف overlapهای مفید یا مضر؛
- کشف stop streakهای خطرناک؛
- کشف اینکه کدام معیار واقعاً بهتر توضیح می‌دهد.

## مرز بین گذشته و اجرا

نتیجه مدل گذشته‌نگر به‌تنهایی قانون اجرا نیست.

خروجی مدل باید به معمار استراتژی برسد و بعد تصمیم گرفته شود که:

- آیا این یافته تبدیل به rule شود؟
- آیا فقط برای observation بماند؟
- آیا نیاز به نمونه بیشتر دارد؟
- آیا باید paper test جداگانه شود؟
- آیا باید حذف شود؟
- آیا باید در مدل بعدی وزن بگیرد؟

## مسیر آینده

بعد از اینکه مدل گذشته‌نگر به اندازه کافی بالغ شد، می‌توان مسیرهای بعدی را بررسی کرد:

1. مدل گزارش‌گر زنده بدون دخالت در معامله؛
2. مدل هشداردهنده برای خانواده‌های باکیفیت؛
3. مدل امتیازدهنده قبل از ورود؛
4. مدل پیشنهاددهنده فیلتر؛
5. مدل کمک‌تصمیم برای تخصیص ریسک؛
6. مدل AI برای طبقه‌بندی خانواده‌های واگرایی.

اما مرحله اول فقط historical analysis است.
