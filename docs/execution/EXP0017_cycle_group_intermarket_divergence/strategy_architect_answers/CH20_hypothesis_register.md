# CH20 — Hypothesis Register

## H20-01 — Future optimization may improve the strategy

**Hypothesis:** after enough statistics, a future version may improve the strategy by changing selected rules.  
**Current status:** not active.  
**Current action:** collect statistics only.

## H20-02 — Premature optimization damages the research sample

**Hypothesis:** if the model changes the strategy before the raw base is measured, the research becomes contaminated.  
**Current status:** active governance principle.  
**Test later:** compare raw base model vs optimized model only after enough samples.

## H20-03 — CG overlap creates useful but complex information

**Hypothesis:** CG overlap may contain important information, but may also increase model complexity.  
**Current status:** track and measure.  
**No current rule:** do not filter, strengthen, weaken, or block signals based on overlap before statistics.

## H20-04 — Statistical-only mode protects strategy identity

**Hypothesis:** forcing the model to remain statistical-only in the first stage prevents doctrine drift and overfitting.  
**Current status:** active doctrine.

## H20-05 — Strategy architect approval improves rule governance

**Hypothesis:** human review before rule promotion prevents the model from turning noisy correlations into strategy changes.  
**Current status:** active governance doctrine.

## H20-06 — Repeated questions should not create duplicate rules

**Hypothesis:** mapping repeated questions back to existing doctrine reduces contradiction and keeps the system coherent.  
**Current status:** documentation rule.

## H20-07 — Future optimization needs version separation

**Hypothesis:** optimized versions should be tested separately from the fixed base version.  
**Current status:** future design principle.

## H20-08 — Some unresolved recommendations can become report fields

**Hypothesis:** when the strategy architect is unsure, a recommendation can safely become a report field if it does not mutate strategy behavior.  
**Current status:** allowed.

## H20-09 — Some unresolved recommendations can become future backlog

**Hypothesis:** unresolved ideas should be preserved for future review rather than ignored or prematurely activated.  
**Current status:** allowed.

## H20-10 — Future model authority must be staged

**Hypothesis:** AI authority should grow in stages: observer, reporter, ranker, recommender, and only later possibly optimizer.  
**Current status:** current stage is observer/reporter/ranker only.
