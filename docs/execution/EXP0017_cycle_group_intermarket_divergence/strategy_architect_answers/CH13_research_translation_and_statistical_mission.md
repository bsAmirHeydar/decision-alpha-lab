# CH13 — Research Translation and Statistical Mission

## 1. Purpose

Chapter 13 converts strategic uncertainty into a research program.

Instead of forcing the architect to answer unknowns through opinion, this chapter defines how each unknown becomes a measurable field.

## 2. Statistical mission

The mission is to discover whether any proposed difference has measurable edge.

The project must eventually compare raw divergence outcomes across:

- cycle group;
- symbol pair role;
- hunter symbol;
- clean symbol;
- buy direction;
- sell direction;
- time window;
- cash session versus outside cash session;
- reference distance;
- reference age;
- single-reference versus multi-reference environment;
- signal survival;
- signal invalidation;
- time-to-invalidation;
- time-to-profit;
- dollar result;
- movement quality;
- stop pressure environment;
- overlapping CG context.

## 3. Research baseline

The baseline must be neutral.

A neutral baseline means the first research layer should not remove signals because of:

- perceived weak timing;
- perceived weak CG;
- perceived weak reference;
- perceived low-quality divergence;
- perceived poor symbol role;
- perceived poor direction;
- visual discomfort;
- previous anecdotal experience.

Every raw confirmed and non-invalidated divergence should enter the dataset.

## 4. Required classification outputs

For every category, the future research layer should eventually be able to answer:

1. How often does this family occur?
2. What is its win rate?
3. What is its average dollar outcome?
4. What is its expectancy?
5. What is its median outcome?
6. What is its worst-case profile?
7. What is its invalidation rate?
8. How fast does it invalidate?
9. How often does it move before invalidation?
10. How often does it reach meaningful profit before cycle end?
11. Does it behave differently during cash session?
12. Does it behave differently outside cash session?
13. Does hunter symbol matter?
14. Does clean symbol matter?
15. Does direction matter?
16. Does reference distance matter?
17. Does CG size matter?
18. Does overlapping CG context matter?
19. Does stop pressure matter?
20. Does the idea deserve to become a rule?

## 5. Difference between descriptive and decision variables

Before testing, a field is descriptive.

After testing, it may become decision-relevant.

Example:

```text
cg_30m = descriptive field before testing
cg_30m = possible decision family after statistical evidence
```

Same for:

- time window;
- direction;
- clean symbol;
- hunter symbol;
- reference distance;
- cycle position;
- invalidation speed;
- stop pressure.

## 6. Statistical authority

In this chapter, the only authority that can upgrade a descriptive field into a decision rule is statistical evidence.

The architect's current answer is not:

> It does not matter forever.

The answer is:

> It does not matter now, before testing.

This distinction must be preserved.

## 7. Future model-building mission

This chapter prepares the path for model building.

A future model should not be trained on a dataset already distorted by manual filters. The model needs to see the raw field first.

The AI layer should eventually learn:

- which CGs carry edge;
- which time windows carry edge;
- which hunter-clean roles carry edge;
- which reference distances carry edge;
- which invalidation patterns matter;
- which signals are statistically poor;
- which signals are statistically convex;
- which signals should be traded, ignored, reduced, or increased.

## 8. Research doctrine

> The strategy must collect first, classify second, decide third, and automate last.

This is the core research order.
