# CH20 — Current Model Statistical-Only Boundary

## 1. Boundary definition

The current model has one job: produce statistical understanding.

It does not trade.  
It does not block trades.  
It does not change the entry.  
It does not change the exit.  
It does not change the cycle map.  
It does not change the base doctrine.

## 2. Allowed current actions

Allowed actions:

- analyze historical confirmed signals;
- compare CG families;
- compare symbol roles;
- compare directions;
- compare time windows;
- compare overlap states;
- identify red flags;
- rank signal families;
- show weak families;
- show promising families;
- produce research questions;
- recommend future tests.

## 3. Forbidden current actions

Forbidden current actions:

- disabling a CG;
- adding a filter;
- changing the target;
- changing stop placement;
- changing risk;
- rejecting large stops;
- rejecting late entries;
- suppressing overlapping CGs;
- forbidding hedge positions;
- changing daily boundary;
- changing reference scope;
- changing clean-symbol execution;
- changing candle-close confirmation;
- live autonomous trade selection.

## 4. Why this boundary matters

Without this boundary, the model may optimize too early and destroy the raw statistical sample.

If the model filters signals before the base behavior is understood, the research becomes contaminated. You no longer know what the strategy does by itself. You only know what the model allowed you to see.

Therefore the current model must first preserve and measure the base strategy exactly as defined.

## 5. Current boundary statement

The current model is statistical-only. It may measure everything and change nothing.
