# CH08 — Signal Visibility, Equality, and Uniform Treatment

## 1. All Confirmed Divergences Are Displayed

The strategy architect states:

> Show all of them; all are valid and there is no difference.

This is a continuation of the neutrality doctrine from previous chapters.

No confirmed divergence should be hidden simply because:

- it comes from a smaller or larger cycle group,
- it appears outside the cash session,
- it happens near another divergence,
- it uses a far reference,
- it uses a near reference,
- it comes from SPXUSD as hunter,
- it comes from NDXUSD as hunter,
- it appears after another signal,
- it has a different visual shape.

Before statistical study, every confirmed divergence remains valid and visible.

## 2. Equal Confirmation Standard

The confirmation standard must be the same across all signals.

The answer to Q8 states:

> It should be the same.

This means there should not be one confirmation rule for one CG and another confirmation rule for another CG at the base layer.

The same confirmation law applies to:

- all cycle groups,
- both symbols,
- both directions,
- all same-day references,
- cash-session and non-cash-session conditions,
- previous-cycle and farther same-day-cycle references.

## 3. No Early Ranking

Confirmed signals should not be ranked manually before statistics.

The base view is:

```text
Confirmed divergence = valid divergence
```

Later, statistics may discover that some families perform better. Until then, the display layer and research layer should preserve everything.

## 4. Signal Multiplicity

Multiple signals can occur:

- in different cycle groups,
- against different references,
- at similar times,
- in the same direction,
- in opposite directions,
- with different hunter/clean roles.

Chapter 08 says these should be shown and treated as valid.

This does not mean the final trading layer must overexpose the account. It means the strategy research layer must not erase information before it is studied.

## 5. Distinction Between Validity and Allocation

There is a difference between:

```text
A signal is valid.
```

and:

```text
The portfolio should allocate risk to every valid signal.
```

Chapter 08 answers the first question, not the second.

Validity belongs to the strategy language.
Allocation belongs to future risk governance.

## 6. Why Display All Signals

Displaying all confirmed divergences has several strategic benefits:

1. It prevents selective memory.
2. It allows unbiased review.
3. It reveals clusters.
4. It exposes conflict between cycle groups.
5. It shows whether many signals point to the same clean symbol.
6. It allows later statistical classification.
7. It prevents premature filtering.
8. It builds the full language of intermarket behavior.

## 7. Future Statistical Use

When all confirmed divergences are preserved, later study can ask:

- Which confirmed signals worked?
- Which failed?
- Which invalidated fastest?
- Which produced movement after confirmation?
- Which were crowded by other signals?
- Which cycle groups confirmed together?
- Which references repeated across signals?
- Which hunter-clean relationships produced stronger movement?

These questions require complete signal visibility.

## 8. Strategic Law

> Before statistics, every confirmed divergence is valid, visible, and equal in base status.
