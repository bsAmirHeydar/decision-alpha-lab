# CH14 — Statistical Testing, Metric Families, and Research Gates

## جایگاه فصل ۱۴

فصل ۱۴ اولین فصلی است که به‌صورت مستقیم وارد «روش سنجش» استراتژی می‌شود. تا فصل‌های قبل، منطق خام واگرایی، سایکل‌گروپ، هانت، مرجع، کلوز، نماد سالم، استقلال CGها و ابطال تعریف شد. فصل ۱۴ می‌گوید این منطق خام باید چگونه ارزیابی شود تا قبل از اجرا، از دل داده‌ها بفهمیم کدام خانواده‌ها واقعاً ارزش دارند.

این فصل یک اصل مرکزی دارد:

> هیچ خانواده‌ای قبل از آمار حذف یا برتر نمی‌شود؛ اما بعد از آمار، حق داریم خانواده‌ها را بر اساس وین‌ریت، برآیند، استاپ‌خوردن، R:R، حرکت پیپی و کیفیت حرکت روزانه طبقه‌بندی کنیم.
