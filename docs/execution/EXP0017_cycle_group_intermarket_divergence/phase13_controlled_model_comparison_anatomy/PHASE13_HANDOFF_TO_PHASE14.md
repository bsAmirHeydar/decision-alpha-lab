# Phase 13 Handoff to Phase 14

Phase 14 is the Decision Promotion Gate.

Phase 13 may hand forward only a versioned evidence package:

- Phase 12.5 readiness status;
- model leaderboard;
- fold-level metrics;
- calibration report;
- fold-stability report;
- leakage audit;
- model cards;
- run configuration and hash;
- explicit limitations.

Phase 14 must decide whether a finding is:

- rejected;
- retained as a research hypothesis;
- sent for more data;
- promoted to a paper-trading rule candidate;
- promoted to a versioned execution candidate after human architect approval.

No Phase 13 winner is promoted automatically.
