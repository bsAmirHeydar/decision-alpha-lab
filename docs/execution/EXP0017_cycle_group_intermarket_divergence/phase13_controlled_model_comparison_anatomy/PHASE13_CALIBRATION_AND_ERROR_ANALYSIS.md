# Phase 13 Calibration and Error Analysis

Classification quality is not reduced to accuracy.

Required evidence:

- probability calibration bins;
- Brier score;
- log loss;
- expected calibration error;
- calibration intercept and slope;
- precision, recall, specificity, and balanced accuracy.

Regression quality is not reduced to average R.

Required evidence:

- MAE and RMSE;
- R-squared;
- correlation;
- sign accuracy;
- fold dispersion;
- worst-fold behavior.

A model with a strong mean and unstable folds remains fragile.
