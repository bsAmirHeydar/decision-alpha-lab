# Phase 07 Limits and Non-Goals

Phase 07 does not:

- place orders
- size positions
- set risk
- set targets
- close positions
- rank CGs
- filter signals
- decide which CG is better
- create AI behavior
- optimize the strategy

Phase 07 only measures forward behavior after confirmed tradeable signals.

## Known research approximation

Entry is currently a study estimate at confirmation close or next M1 open. This is not a live fill model.

Spread, slippage, commission, contract-size normalization, and broker execution constraints are intentionally deferred.
