# Phase 12 Experiment Registry Contract

Phase 12 introduces a registry template:

`EXP0017_Phase12_Experiment_Registry_Template.csv`

The registry exists to stop research from becoming vague memory.

Every experiment should state:

- research question
- dataset file
- walk-forward file
- label window
- train/test/embargo settings
- bucket key
- features used
- exclusions
- primary and secondary metrics
- result summary
- research decision
- notes

The registry is not a live strategy configuration file.
