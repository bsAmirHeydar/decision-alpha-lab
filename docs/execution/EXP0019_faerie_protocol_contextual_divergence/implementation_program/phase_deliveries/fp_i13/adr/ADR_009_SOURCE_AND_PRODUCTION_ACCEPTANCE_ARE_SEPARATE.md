# ADR-009 — Source and Production Acceptance Are Separate

## Decision

No environment without MetaEditor may claim compiled production readiness.

## Consequences

The decision is versioned in FP-I13, covered by tests, and included in the handoff to FP-I14. Any reversal requires a new ADR and replay rebaseline.
