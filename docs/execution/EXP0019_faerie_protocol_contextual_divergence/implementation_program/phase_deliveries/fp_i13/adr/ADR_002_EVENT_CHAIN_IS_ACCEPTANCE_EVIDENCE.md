# ADR-002 — Event Chain Is Acceptance Evidence

## Decision

The event-chain hash binds accepted ordering and content; telemetry cannot substitute for it.

## Consequences

The decision is versioned in FP-I13, covered by tests, and included in the handoff to FP-I14. Any reversal requires a new ADR and replay rebaseline.
