# EXP0019 — Faerie Protocol Contextual Divergence — Master MOC

## تعریف پروژه

`EXP0019` بسته دانشی و معماری مستقل **Faerie Protocol Contextual Divergence** است. این پروژه، واگرایی را دوباره از صفر اختراع نمی‌کند. هسته عمومی واگرایی بین دو نماد ثابت می‌ماند و Faerie Protocol فقط سیاست زمانی، رابطه‌ای، سطحی، هفتگی و اجرایی خود را روی آن سوار می‌کند.

> اصل معماری: **Shared Divergence Kernel ثابت؛ Faerie Context قابل تعویض؛ Execution Policy جدا.**

## چرا مستقل از EXP0017 است؟

EXP0017 بر Cycle Groupهای 3 تا 720 دقیقه و reference field همان روز بنا شده است. Faerie Protocol بر سه میدان A/L/N، روابط نام‌دار `AL/AN/LN/NA/NL/NN` و کانتکس هفتگی `WW` بنا می‌شود. ادغام مستقیم این دو، time policy و reference policy را در هسته عمومی قفل می‌کند. بنابراین EXP0019 یک context adapter مستقل است و فقط primitiveهای معتبر EXP0017 را مصرف می‌کند.

## سطح اختیار این سند

این سند چهار سطح حقیقت را از هم جدا می‌کند:

| سطح | معنی |
|---|---|
| `OWNER_CONFIRMED` | در فایل Word یا درخواست صریح مالک آمده است. |
| `LEGACY_IMPLEMENTED` | در `FP 101.mq5` وجود دارد، حتی اگر قرارداد نهایی نباشد. |
| `ARCHITECTURAL_DERIVATION` | برای ماژولارکردن و حفظ هسته‌های مشترک از منبع استنتاج شده است. |
| `OPEN_DECISION` | قبل از کدنویسی نهایی نیازمند تصمیم مالک است. |

قاعده: رفتار Legacy فقط وقتی canonical است که با Owner Intent و قرارداد این پکیج تعارض نداشته باشد.
