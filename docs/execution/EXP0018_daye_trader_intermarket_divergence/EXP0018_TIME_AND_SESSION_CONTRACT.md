# قرارداد زمان و سشن EXP0018

## مرجع زمانی

تمام تعریف‌ها با ساعت محلی نیویورک بیان می‌شوند.

## روز معاملاتی

- شروع: 18:00:00 نیویورک
- پایان: 16:59:59 روز تقویمی بعد
- فاصله 17:00 تا 17:59:59 در متن به‌عنوان session تعریف نشده است.

## سشن‌ها

| ID | شروع | پایان | مدت |
|---|---:|---:|---:|
| A | 18:00 | 23:59:59 | 6h |
| L | 00:00 | 05:59:59 | 6h |
| N | 06:00 | 11:59:59 | 6h |
| P | 12:00 | 16:59:59 | 5h |

## DST

دو mode لازم است:

- Auto New York DST
- Manual Offset Override

Auto باید بر اساس قوانین منطقه زمانی آمریکا و تاریخ رخداد محاسبه شود، نه offset ثابت سالانه.

## تبدیل broker time

هر timestamp باید این مسیر را طی کند:

`broker server time -> UTC -> New York local time -> Daye trading day/session/subcycle`

## ممنوعیت‌ها

- استفاده از تعداد کندل ثابت برای تعریف سشن
- فرض اینکه هر روز دقیقاً تعداد یکسان M1 bar دارد
- محاسبه بر اساس local PC time
- استفاده از offset ثابت نیویورک برای تمام سال

## ابهام باز

عبارت 20–4، 4–9 و 9–16 در بخش DST با جدول اصلی 18–0، 0–6، 6–12، 12–17 سازگار نیست و تا تأیید، نباید جایگزین جدول اصلی شود.
