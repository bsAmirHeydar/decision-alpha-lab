# قرارداد باکس‌های سشن

## چهار باکس

A، L، N و P برای هر روز معاملاتی قابل‌دسترسی رسم می‌شوند.

## هندسه

- Time1 = شروع سشن
- Time2 = پایان سشن
- Price Top = بیشترین high تمام داده موجود داخل سشن
- Price Bottom = کمترین low تمام داده موجود داخل سشن
- Fill = رنگ سشن

## رنگ‌های پیش‌فرض

| Session | Default |
|---|---|
| A | Sky Blue |
| L | Fluorescent Green |
| N | Orange |
| P | Light Red |

## رفتار با سشن ناقص

- اگر بخشی از تاریخچه موجود نباشد، باکس فقط در صورت وجود حداقل داده معتبر ساخته شود.
- باکس ناقص باید در metadata مشخص شود یا اصلاً رسم نشود؛ policy نهایی نیازمند تصمیم است.
- تعداد bar ثابت ممنوع است.
