# Bucko — SMT، Hunter و Protected

صفحات ۱۷ و ۱۸ SMT را crack میان correlated assets معرفی می‌کنند. در مثال bullish، یک نماد lower low می‌زند و دیگری higher low. نمادی که extreme را می‌زند Hunter و نماد دیگر Protected تلقی می‌شود. این نزدیک‌ترین بخش Bucko به core doctrine Word است، اما شروط Bucko شامل bias، swing point و زمان مناسب نیز هست که در core فعلی شرط نیستند.
