# Bucko — True Opens و Stacking

صفحات ۱۰ تا ۱۶ True Open را open اولین candle در Q2 معرفی می‌کنند. True Openهای سال، ماه، هفته، روز، سشن و میکروسشن با timeframe پیشنهادی نمایش داده شده‌اند. صفحه ۱۴ stacking را به‌صورت مقایسه HTF/LTF True Open بیان می‌کند:

- bearish premium: LTF True Open بالاتر از HTF True Open؛
- bullish discount: LTF True Open پایین‌تر از HTF True Open.

برای EXP0018، TWO/TDO canonical هستند؛ بقیه anchorها candidate ماژول آینده‌اند.
