# Bucko — چرخه‌ها و Phaseها

Bucko از چرخه چهار‌ساله تا nano را در یک hierarchy فرکتال قرار می‌دهد. چرخه‌های اصلی برای EXP0018، Daily/Session/90m هستند؛ چرخه‌های بزرگ‌تر context و چرخه‌های کوچک‌تر precision محسوب می‌شوند. صفحات ۳ تا ۹ مدل‌های AMDX/XAMD را توضیح می‌دهند و تأکید دارند Q1 اطلاعات cycle و Q2/Q3 بخش‌های اصلی معامله‌اند.

این منبع نقش‌های phase را ثابت و قطعی نمی‌داند؛ Q4 بسته به برخورد با HTF level می‌تواند continuation یا reversal باشد. بنابراین classification باید probabilistic/research metadata باشد، نه state قطعی detector.
