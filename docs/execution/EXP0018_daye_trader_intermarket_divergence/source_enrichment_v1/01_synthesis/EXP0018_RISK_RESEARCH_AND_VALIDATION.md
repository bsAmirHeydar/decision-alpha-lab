# ریسک، Research و اعتبارسنجی

در Trader Daye توصیه‌هایی مانند ریسک نیم‌درصد، کاهش overtrading، عدم چند معامله هم‌زمان و backtest زیاد دیده می‌شود. این‌ها توصیه آموزشی‌اند و قرارداد رسمی EXP0018 نیستند.

برای تبدیل هر enrichment به rule باید:

1. تعریف مکانیکی شود؛
2. availability time مشخص شود؛
3. dataset و primary key داشته باشد؛
4. in-sample و out-of-sample جدا باشد؛
5. baseline خام حفظ شود؛
6. effect size، sample size و stability گزارش شود؛
7. promotion انسانی انجام شود.
