# سلسله‌مراتب چرخه و زمان فرکتال

- ماهانه

- میکرو ۲۲٫۵ دقیقه‌ای
- نانو و زیرتقسیم‌های کوچک‌تر

## اصل تطابق تایم‌فریم

منابع تأکید می‌کنند هر cycle باید در timeframe متناسب دیده شود. مثال‌های رایج:

- Weekly context → 4H entry
- Daily context → 1H
- 4H → 15m
- 1H → 5m
- 15m → 1m

این mapping یک قرارداد پیشنهادی است و باید برای هر broker/data source آزمایش شود.
