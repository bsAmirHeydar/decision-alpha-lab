# Taxonomy خانواده SMT در منابع

## 1. Core Hunt Divergence

قانون Word: یکی از دو نماد سطح متناظر را لمس/هانت می‌کند و دیگری نمی‌کند. این هسته canonical است.

## 2. Regular SMT

شکاف رفتار میان بازارهای همبسته روی high/low. تعریف گسترده‌تر از core و در PDFها غالباً همراه با structure یا liquidity context است.

## 3. Sequential SMT / SSMT

واگرایی میان quarterهای متوالی یا رابطه‌های زمان‌مند. Bucko و QT آن را به روابط Q1↔Q2، Q2↔Q3، Q3↔Q4 و گاهی Q4↔Q1 گسترش می‌دهند.

## 4. Hidden SSMT

مقایسه candle body/close یا highest body به‌جای صرفاً wick extreme.

## 5. Closure SSMT

ترکیب normal و hidden relationship.

## 6. SMT Fill

یک بازار gap/FVG را پر می‌کند و بازار دیگر نه.

## 7. Intermarket SSMT

رابطه میان triadهای بزرگ‌تر مانند rates، DXY، FX و indices.

## 8. SMT MSS / State-of-Delivery

SMT به‌جای reversal می‌تواند نشانه continuation یا تغییر state باشد.

## مرز طراحی

هیچ‌یک از انواع ۲ تا ۸ نباید بی‌صدا داخل Hunt Detector اصلی قرار گیرد. هر نوع نیازمند event contract، reference contract، confirmation و lifecycle مستقل است.
