# واژه‌نامه توسعه‌یافته EXP0018

- **Quarter:** یک‌چهارم cycle زمانی.
- **A/M/D/X:** Accumulation، Manipulation، Distribution، Extension/Continuation/Reversal.
- **True Open:** open ابتدای Q2 cycle.
- **DFR:** range دو‌سوم انتهایی Q1 پس از حذف یک‌سوم اول.
- **SMT:** divergence میان دارایی‌های همبسته.
- **SSMT:** SMT زمان‌مند/ترتیبی میان quarterها.
- **Hunter:** نمادی که سطح reference را هانت کرده است.
- **Protected:** نمادی که سطح متناظر را هنوز هانت نکرده است.
- **CSD:** Change in State of Delivery.
- **PSP/PC:** Precision Swing Point / Precision Candle.
- **NWOG/NDOG:** New Week/New Day Opening Gap.
- **Stacked True Opens:** هم‌ترازی چند True Open در hierarchy.
- **Golden Pocket:** nesting چند Q3، در منابع عمدتاً چهارشنبه ۹ تا ۱۰:۳۰.
- **SMT Fill:** پرشدن gap در یک بازار و عدم پرشدن در دیگری.
- **Magneto:** استفاده از SSMT قدیمی به‌عنوان magnet/target در منبع QT.
- **Pi Range:** lookback تقریبی 3.14 candles برای liquidity در منبع QT.
