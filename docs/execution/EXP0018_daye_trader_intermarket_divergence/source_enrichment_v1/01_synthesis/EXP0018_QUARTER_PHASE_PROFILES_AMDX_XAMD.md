# Profileهای AMDX و XAMD

## AMDX

- Q1: Accumulation / range
- Q2: Manipulation / Judas swing
- Q3: Distribution / حرکت اصلی
- Q4: Continuation یا Reversal

## XAMD

- Q1: Extension/Continuation/Reversal از cycle قبلی
- Q2: Accumulation
- Q3: Manipulation
- Q4: Distribution

## نکته مرکزی

Q1 وضعیت cycle را دیکته می‌کند: expansion شدید Q1 می‌تواند احتمال consolidation بعدی را بالا ببرد و range کوچک Q1 می‌تواند زمینه expansion بعدی باشد. این گزاره در منابع آموزشی تکرار شده، اما برای کد باید تعریف کمی expansion/consolidation، sample و threshold مشخص شود.

## اثر بر EXP0018

فعلاً profile detection نباید در سیگنال‌های ۲۲گانه دخالت کند. یک ماژول پژوهشی آینده می‌تواند برای هر signal، profile context را ثبت کند و بعد بررسی کند آیا نرخ موفقیت یا هندسه حرکت فرق دارد.
