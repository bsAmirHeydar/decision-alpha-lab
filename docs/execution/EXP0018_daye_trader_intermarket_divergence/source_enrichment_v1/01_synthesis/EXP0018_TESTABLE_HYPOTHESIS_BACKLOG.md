# Backlog فرضیه‌های قابل تست

1. آیا signalهای زیر/بالای True Open رفتار متفاوت دارند؟
2. آیا nested Q3 در چهارشنبه ۹–۱۰:۳۰ نتیجه متفاوتی دارد؟
3. آیا DFR ±1 محل MFE/MAE را بهتر توضیح می‌دهد؟
4. آیا SSMT متوالی از SMT معمولی قوی‌تر است؟
5. آیا triad confirmation نسبت به pair-only false positive را کم می‌کند؟
6. آیا news-density روزانه frequency یا magnitude را تغییر می‌دهد؟
7. آیا first sweep constraint کیفیت را بالا می‌برد؟
8. آیا Hunter یا Protected symbol حرکت بعدی بزرگ‌تری دارد؟
9. آیا Q4 نسبت به Q2 extension رفتار continuation/reversal مشخص دارد؟
10. آیا stacked True Opens با stop distance یا outcome مرتبط‌اند؟
11. آیا 60-day window اثر پایدار out-of-sample دارد؟
12. آیا HTF SSMT واقعاً LTF SSMT را بی‌نیاز می‌کند؟

هر hypothesis باید قبل از تست، label، window، sample inclusion و failure criterion داشته باشد.
