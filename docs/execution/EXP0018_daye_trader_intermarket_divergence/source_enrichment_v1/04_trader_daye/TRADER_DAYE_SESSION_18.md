## اثر احتمالی بر EXP0018

- اگر مطلب با Word اصلی سازگار باشد، نقش `corroborating` دارد.
- اگر event type تازه‌ای مانند SMT Fill یا body divergence بسازد، `research_candidate` است.
- اگر timezone، direction یا lifecycle را تغییر دهد، تا تصمیم معمار `conflict` است.
