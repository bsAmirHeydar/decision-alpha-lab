# QT — انواع SSMT و شکست

صفحات ۳۱–۳۸ سه نوع normal، hidden و closure SSMT و مدل دو‌مرحله‌ای را معرفی می‌کنند. همچنین bullish SSMT بالای True Open و bearish SSMT پایین True Open به‌عنوان failure-prone مطرح می‌شود. این taxonomy باید engine مستقل داشته باشد چون body/close semantics با touch-only core متفاوت است.
