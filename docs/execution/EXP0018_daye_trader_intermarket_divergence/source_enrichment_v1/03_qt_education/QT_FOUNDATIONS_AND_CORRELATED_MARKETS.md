# QT — پایه‌ها و بازارهای همبسته

صفحات ۲ تا ۴ Q1..Q4، A/M/D/X و دو profile اصلی را معرفی می‌کنند. سپس triadهای FX، indices، crypto، energies، metals و stocks فهرست می‌شوند. این فهرست یک registry پژوهشی از correlation candidateهاست؛ correlation ثابت یا همیشگی فرض نمی‌شود.

برای EXP0018، pair ورودی اصلی باقی می‌ماند. triadها فقط وقتی اضافه می‌شوند که symbol mapping، session overlap و missing-data contract جدا داشته باشند.
