# QT — DFR و Projection

صفحات ۱۰ تا ۱۴ DFR را از دو‌سوم انتهایی Q1 می‌سازند و high/low/equilibrium آن را anchor قرار می‌دهند. projectionهای ±1 مهم‌ترین و ±2/±2.5/±4 ثانویه معرفی شده‌اند. مثال‌ها crack correlation نزدیک projection را برجسته می‌کنند.

نیازهای تست: cycle-specific normalization، tick size، partial Q1، outlier handling و جلوگیری از lookahead.
