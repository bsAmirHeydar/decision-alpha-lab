# پروتکل حل تعارض منابع

1. تعارض به‌صورت یک رکورد مستقل ثبت می‌شود.
2. عبارت‌های دو طرف بدون تحریف خلاصه می‌شوند.
3. authority tier هر منبع تعیین می‌شود.
4. اثر تعارض بر زمان، سیگنال، state، drawing یا execution مشخص می‌شود.
5. تا تصمیم S0، رفتار فعلی ثابت می‌ماند.
6. تصمیم نهایی باید version، تاریخ، rationale، tests و migration note داشته باشد.
7. هیچ AI agent حق ندارد با رأی اکثریت منابع تعارض را حل کند.
