# Hunt observation reuse

Every P04 resolution is classified by the P05 touch-only classifier. Each symbol is compared only with its own reference price. Equality remains a hunt. Pair states NONE, A_ONLY, B_ONLY, BOTH, and UNAVAILABLE evolve as source bars become available.
