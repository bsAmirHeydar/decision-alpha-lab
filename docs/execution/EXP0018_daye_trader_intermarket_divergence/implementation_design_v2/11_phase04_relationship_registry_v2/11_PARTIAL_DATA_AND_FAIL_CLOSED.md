# Partial Data and Fail Closed

Missing reference link, missing referenced pair, code mismatch, partial reference, partial current, blocked doctrine, or empty P03 store each has a distinct status and reason code. None are converted to a valid relationship context.

`No relationship context` does not mean `no hunt`. P04 does not own hunt truth. Downstream must not infer market behavior from missing topology.
