# Definition of Done

P04 is done when:

- MetaEditor reports 0 errors and 0 warnings;
- embedded self-tests pass;
- machine validator and pytest pass;
- registry cardinality and mappings match the canonical CSV;
- WW and NP remain blocked;
- exact selector resolution is demonstrated;
- unavailable/partial states remain explicit;
- audit and replay identities are deterministic;
- documentation and Obsidian artifacts are complete;
- no hunt, drawing, risk, or execution authority is present.
