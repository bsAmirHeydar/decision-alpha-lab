# Canonical policy resolution

The operational policy is:

1. A confirmed one-sided use activates the reference side.
2. The exact opportunity may produce only one accepted use.
3. A later, distinct opportunity may reuse the same reference while the **same protected symbol** remains unhunted.
4. When that protected symbol touches its own reference, the reference side retires.
5. Double hunt retires the reference side.
6. A role switch on the same reference is evidence that the previous protected symbol has hunted; it retires the reference and is not a fresh valid use.
7. A retired reference never returns.
8. Historical accepted uses remain immutable after retirement.

This resolves “only the first sweep matters” at the exact-opportunity level without incorrectly suppressing later Daye relationships while protection is still structurally intact.
