# Reference and use identities

## Reference identity

```text
reference period instance
+ HIGH or LOW side
+ canonical symbol pair
```

Relationship and current period are deliberately excluded. Multiple relationships may legally refer to the same underlying reference side.

## Exact-opportunity use identity

```text
opportunity id
+ side
+ hunter
+ protected
```

This is the First-Sweep deduplication key.

## Use identity

```text
EXP0018|P07|USE|<P06 result id>
```

Prices, random values, chart object names, and bar indexes are not identity inputs.
