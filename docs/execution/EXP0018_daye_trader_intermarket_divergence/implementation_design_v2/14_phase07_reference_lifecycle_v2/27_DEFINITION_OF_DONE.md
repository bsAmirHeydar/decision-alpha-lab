# Definition of Done

P07 is done when:

- MetaEditor compiles with 0 errors and 0 warnings;
- embedded tests pass;
- contract validator and pytest pass;
- exact-opportunity duplicates are suppressed;
- later distinct opportunities are accepted while protection survives;
- protected touch, double hunt, and role switch retire terminally;
- accepted uses survive retirement and restart;
- checkpoint prevents duplicate recovery;
- no drawing, direction, risk, or execution authority exists.
