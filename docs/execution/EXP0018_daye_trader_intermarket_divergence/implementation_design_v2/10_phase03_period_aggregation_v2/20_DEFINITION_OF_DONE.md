# Definition of Done

P03 وقتی Done است که:

- Expert با 0 error و ترجیحاً 0 warning compile شود.
- embedded tests پاس شوند.
- fixtureهای Python پاس شوند.
- Daily/Session/Subcycle روی چند روز واقعی ساخته شوند.
- p4 ۳۰ دقیقه بماند.
- partial first period و open latest period درست دیده شوند.
- Weekly فعال نشده باشد.
- Audit، docs، Obsidian و rollback موجود باشند.

صرف compile شدن کافی نیست.
