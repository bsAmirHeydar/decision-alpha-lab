# Session Boxes and Q1-Q4 Labels

## Purpose

Define the canonical A/L/N/P session range boxes and phase labels.

## Windows

A 18:00-00:00, L 00:00-06:00, N 06:00-12:00, P 12:00-17:00 New York. Geometry comes from P03; P10 does not rescan chart candles.

## Visual language

A sky blue, L lime, N orange, P light red. Labels expose both the quarter and source code.

## Completeness

Complete and open sessions render by default. Partial sessions are rejected unless the user explicitly enables them.

This document and the corresponding implementation do not authorize entries, exits, risk sizing, order placement, strategy mutation, model promotion, network access, or execution. Chart objects are projections of upstream immutable evidence and time contracts.
