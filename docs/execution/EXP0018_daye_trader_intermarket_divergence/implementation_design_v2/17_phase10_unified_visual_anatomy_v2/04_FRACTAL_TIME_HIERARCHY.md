# Fractal Time Hierarchy

## Purpose

Define the visible nesting from Day to Session to 90-minute subcycle to 22.5-minute micro quarter.

## Hierarchy

`D -> A/L/N/P -> a1..p4 -> q1..q4`. Every child is visually subordinate to its parent. Session color, box opacity, line style, width, and label size create the hierarchy.

## Quarter language

A/L/N/P are displayed as `Q1 A`, `Q2 L`, `Q3 N`, and `Q4 P`. Each numbered subcycle is displayed as its local quarter, for example `Q3 n3`.

## No fabricated symmetry

p4 is a 30-minute tail and is not divided into four 22.5-minute quarters.
