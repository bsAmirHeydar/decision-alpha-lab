# قرارداد تأیید و ماندگاری

## تایم‌فریم تأیید

تایم‌فریم چارت، تایم‌فریم confirmation است.

مثال: اگر EA روی M30 اجرا شده باشد، snapshot نهایی در بسته‌شدن هر M30 گرفته می‌شود.

## فرایند

1. درون کندل ممکن است یک‌طرفه hunt رخ دهد.
2. تا پایان کندل هیچ خط قطعی ساخته نمی‌شود.
3. در close کندل، وضعیت دو نماد دوباره ارزیابی می‌شود.
4. اگر فقط یک نماد hunter باقی مانده باشد، signal confirmed است.
5. اگر هر دو هانت کرده باشند، همان signal type تأیید نمی‌شود.
6. signal typeهای دیگر همان کندل مستقل ارزیابی می‌شوند.

## اولین کندل تأیید

نقطه مقصد خط باید high یا low اولین کندل بسته‌شده‌ای باشد که شرایط را تأیید کرده است.

## ماندگاری

پس از تأیید و رسم، خط حذف نمی‌شود؛ حتی اگر بعداً وضعیت بازار تغییر کند. این خط یک رکورد تاریخی است، نه وضعیت live قابل‌حذف.

## پیامد معماری

سیستم نیازمند دو state جداست:

- candidate state داخل کندل جاری
- immutable confirmed drawing record پس از close
