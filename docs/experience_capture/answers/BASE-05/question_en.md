# BASE-05 — How Far Is Uncertainty Allowed?

## Question

When you say that no absolute judgment can be made, how far is that uncertainty allowed to go?

## Why This Matters

If everything remains ambiguous forever, execution becomes impossible.

We need to know how the system moves from ambiguity toward a decision.

## Required Clarifications

Please clarify:

- When is ambiguity natural and useful?
- When is ambiguity dangerous and should become no-trade?
- Should AI score ambiguity, or convert it into classes?
