# Quant Lab Experience Capture Questionnaire

This folder is the Markdown version of the full experience-capture questionnaire.

The questionnaire is written in English and split into separate section README files so answers can be stored beside the question codes under:

- `docs/experience_capture/answers/<QUESTION_CODE>/`

Every answer should preserve:

- the raw human explanation
- the chart examples
- the normalized interpretation
- the open questions
- the future field/label/model/execution implications

## Answer Storage Convention

For each code, use this structure:

- `docs/experience_capture/answers/<QUESTION_CODE>/answer_raw_en.md`
- `docs/experience_capture/answers/<QUESTION_CODE>/answer_normalized_en.md`
- `docs/experience_capture/answers/<QUESTION_CODE>/notes_en.md`
- `docs/experience_capture/answers/<QUESTION_CODE>/images/`
- `docs/experience_capture/answers/<QUESTION_CODE>/manifest.json`

## Image Convention

When you provide chart screenshots, name or tag them with the related question code:

- `EXT-03-good-L2-example.png`
- `F-07-parent-override-example.png`
- `FR-05-parent-continuation-energy.png`

The image should mark, whenever relevant:

- symbol and timeframe or structural scale
- direction hypothesis
- Hook/Rally interpretation
- parent/current/child relationship
- anchor node
- extreme zone
- entry
- stop
- destination
- invalidation
- outcome
