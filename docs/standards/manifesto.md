# Manifesto

Markets are not machines to be predicted.

They are collective decision systems.

Price does not reveal certainty about the future. Instead, it exposes the consequences of countless interacting decisions.

This project assumes that market behavior emerges from the interaction between two fundamental forces:

- Self-reinforcing dynamics (Momentum)
- Self-correcting dynamics (Mean Reversion)

The task of the trader is not prediction.

The task is to recognize transitions between these forces and construct convex structures around them.
