# UCEE-I03 — Treatment Atom Registries

This patch implements the third UCEE execution phase: 50 exact-version treatment atoms across entry, stop, target, trailing, management, and preliminary sizing registries. It adds Python and MQL5 SDKs, immutable descriptor/invocation/plan contracts, side-aware executable quote semantics, conformance tests, schemas, golden vectors, English Obsidian documentation, delivery metadata, and the UCE-I04 handoff.

## Boundaries

The phase produces declarative plans only. It cannot submit orders. Complete treatment compilation is UCE-I04. Final spread, commission, slippage, broker, margin, currency, and maximum-loss normalization is UCE-I05.
