# INSTALL — EXP0017 Chapter 11 CG Independence Patch

این patch فصل ۱۱ پاسخ‌های معمار استراتژی را به لایه‌ی داکیومنت و آبسیدین پروژه EXP0017 اضافه می‌کند.

موضوع فصل ۱۱:

- استقلال کامل سایکل‌گروپ‌ها از یکدیگر
- استقلال کامل هر روز معاملاتی از روزهای قبلی
- پذیرش هم‌زمان جهت خرید و فروش برای مطالعه
- عدم انتقال اعتبار، ضعف، شخصیت، برآیند یا تجربه از یک CG به CG دیگر
- عدم ایجاد حافظه‌ی روزانه بین امروز و روزهای گذشته
- حفظ همه CGها به‌عنوان خانواده‌های مستقل تا زمان کشف آماری

این patch فقط داکیومنت و آبسیدین اضافه می‌کند و هیچ کدی تغییر نمی‌دهد.
