# INSTALL — EXP0017 Chapter 04 Reference Scope Doctrine Patch

این پچ فصل چهارم پاسخ‌های معمار استراتژی را برای پروژه `EXP0017_cycle_group_intermarket_divergence` اضافه می‌کند.

موضوع فصل چهارم:

- مرجع واگرایی چیست؟
- سایکل فعلی با کدام سایکل‌های قبلی مقایسه می‌شود؟
- آیا فقط سایکل قبلی مهم است یا همه سایکل‌های قبلی همان روز؟
- آیا مرجع بعد از هانت بازنشسته می‌شود؟
- آیا داده روز قبل وارد تحلیل می‌شود؟
- آیا می‌توان بعداً hierarchy مرجع‌ها را از آمار استخراج کرد؟

اصل مرکزی فصل:

> تمام سایکل‌های پیشین همان روز می‌توانند مرجع واگرایی باشند. فعلاً هیچ مرجع، هیچ سایکل و هیچ فاصله زمانی نسبت به دیگری برتری ذاتی ندارد. همه باید مستقل ثبت، تست و طبقه‌بندی شوند.

این پچ فقط داکیومنت و آبسیدین است و هیچ کد اجرایی اضافه نمی‌کند.
