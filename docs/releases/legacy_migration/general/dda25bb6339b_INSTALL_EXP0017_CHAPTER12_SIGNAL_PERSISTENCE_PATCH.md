# INSTALL — EXP0017 Chapter 12 Signal Persistence Patch

این پچ فصل ۱۲ پاسخ‌های معمار استراتژی را به لایه داکیومنت و آبسیدین پروژه `EXP0017_cycle_group_intermarket_divergence` اضافه می‌کند.

موضوع فصل ۱۲:

- استقلال کامل سایکل‌گروپ‌ها از یکدیگر
- نبود تفاوت اعتباری بین CGها قبل از تست آماری
- عدم نیاز به حذف، خاموش‌کردن، فیلترکردن یا بازنشسته‌کردن سیگنال‌ها در لایه پایه
- تنها شرط حذف/ابطال سیگنال: از بین رفتن واگرایی با هانت شدن مرجع در هر دو نماد
- ماندگاری سیگنال تا وقتی که ساختار اصلی واگرایی هنوز زنده است
- تفکیک «عدم ابطال» از «کیفیت بالا»؛ یعنی سیگنال زنده الزاماً سیگنال بهتر نیست، فقط هنوز باطل نشده است

این پچ هیچ کد اجرایی اضافه نمی‌کند.
