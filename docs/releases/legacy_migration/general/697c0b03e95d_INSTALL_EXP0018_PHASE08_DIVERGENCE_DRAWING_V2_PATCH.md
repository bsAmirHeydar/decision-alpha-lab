1. Expand the patch at repository root.
2. Run the Phase08 PowerShell validator.
3. Compile the corrected P07 Expert and the new P08 Expert in MetaEditor.
4. Open both configured broker-symbol charts.
5. Attach P08 and verify object prefix, Hunter-only targeting, major/minor labels, and persistence.
