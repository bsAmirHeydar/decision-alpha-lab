# SAED-04 to SAED-06 — Outcome, Dataset, and Baselines

## SAED-04

Extend the shared Outcome engine for each profile and mechanism, especially non-fill/adverse selection and trail path replay.

## SAED-05

Produce candidate-level clustered datasets with decision-time features, maturity/censoring, lineage, purged walk-forward and protected roles.

## SAED-06

Run descriptive studies and baselines before AI: unconditional profile/entry results, Manual policy, always/never trade, cost and stability maps.

## Golden Gate

Outcome and dataset rebuilds are deterministic; future perturbation cannot alter prior features; all sibling candidates remain clustered; baseline reports are complete even when no model is trained.
