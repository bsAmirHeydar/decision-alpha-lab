# Setup Archetype and Falsifiable Hypothesis

## Setup Archetype

An archetype describes the economic mechanism expected to exploit a Context, before a specific Treatment is chosen. Examples:

- immediate continuation;
- pullback continuation;
- breakout expansion;
- reclaim/retest;
- liquidity rejection;
- reversal after failed continuation;
- trend participation;
- mean reversion.

## Hypothesis Contract

Each archetype declares:

- target Context versions;
- causal mechanism;
- decision timestamp;
- compatible payoff profiles;
- compatible entry mechanisms;
- expected favorable and adverse paths;
- falsification criteria;
- nulls and matched controls;
- minimum evidence and sample requirements;
- known failure regimes.

The hypothesis is frozen before protected testing. “It worked because the model found it” is not a mechanism statement.
