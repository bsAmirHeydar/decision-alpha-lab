# Edge and Evidence Lifecycle States

## Candidate Lifecycle

```text
Proposed
→ Context-Conformant
→ Treatment-Complete
→ Dataset-Ready
→ Research Candidate
→ Selection-Validated
→ Statistically Supported
→ Prospective Challenge
→ Paper Validated
→ Runtime Qualified
→ Portfolio Eligible
→ Production Qualified
```

At any point it may move to:

```text
Rejected | Quarantined | Superseded | Retired
```

## Non-Monotonic Reality

Evidence states can regress when assumptions fail, drift appears, cost changes, parity breaks or a stronger null explanation emerges. Promotion is not permanent truth.

## Separation

Statistical promotion does not grant execution authority. Portfolio eligibility does not guarantee allocation. Production qualification does not guarantee continued health.
