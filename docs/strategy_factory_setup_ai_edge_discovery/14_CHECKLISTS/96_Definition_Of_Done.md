# Definition of Done — Setup AI Candidate

A candidate is not done because training completed or a backtest is profitable. Done requires:

- complete immutable lineage;
- causal Context/feature evidence;
- executable Treatment and economics;
- reproducible dataset/folds/trials;
- baseline and manual comparison;
- calibrated OOF/test outputs;
- complete selection universe;
- anti-overfit/null/stress dossier;
- signed promotion decision;
- policy graph with abstention/fallback;
- runtime parity and test vectors;
- paper/shadow evidence for production use;
- monitoring and rollback contract;
- retained rejection/failure memory.
