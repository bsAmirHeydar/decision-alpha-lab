# Failure Memory and Edge Genome

## Failure Memory

Store rejected Context/Treatment/model combinations, failure reason, evidence, affected regimes, cost sensitivities, null explanations and whether retry is permitted under new data or architecture.

## Edge Genome

For promoted or challenged candidates store Context family, payoff profile, entry mechanism, horizon, return/tail distribution, cost sensitivity, regime dependence, capacity, shared-event structure, correlation, evidence level and decay state.

## Reuse

Future searches may use this memory as a prior, but prior knowledge does not replace independent validation. Negative memory prevents repeated expensive dead ends.
