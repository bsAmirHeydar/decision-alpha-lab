# Deflated Performance, Reality Check, and SPA

## Deflated Performance

Adjust observed performance for non-normality, sample size and the number/correlation of tried strategies. Use net, cluster-aware returns.

## Reality Check / SPA

Compare the best candidate against a benchmark while accounting for data snooping across the candidate family.

## Scope

These tests supplement, not replace, nested walk-forward, nulls, stability and prospective evidence.

## Reporting

Store assumptions, bootstrap method, block length, benchmark, full candidate universe and sensitivity to choices.
