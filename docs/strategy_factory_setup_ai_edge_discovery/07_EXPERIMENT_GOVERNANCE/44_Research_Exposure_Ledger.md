# Protected Data and Research Exposure Ledger

## Exposure Events

Record actor/process, lineage, dataset role, fields, timestamp, purpose, prompt/report, outputs and whether the role remains pristine.

## AI Exposure

An LLM summarizing final-test failures and proposing model changes is exposure. A dashboard viewed by a researcher is exposure. Exporting test predictions into a feature notebook is exposure.

## Role Downgrade

Once used for selection, a dataset cannot remain a locked final test for that lineage. Create a new future period or new lineage.

## Operational Rule

Access control and logging must be technical, not only procedural.
