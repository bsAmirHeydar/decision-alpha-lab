# Experiment Compiler and Immutable Freeze

## Frozen Inputs

- falsifiable hypothesis;
- Context package/version and data cutoff;
- candidate Treatment universe;
- payoff/entry/objective registries;
- features and known-time policy;
- labels/maturity/censoring;
- fold/cluster/purge/embargo plan;
- trainer ladder and capabilities;
- search spaces and budgets;
- metrics, nulls, stresses and promotion criteria;
- stopping rules and protected data roles.

## Output

An immutable experiment declaration, DAG, reproduction command and expected artifact inventory.

## Gate

If a behavior-changing choice is made after protected outcomes are seen, it creates a new lineage and consumes the exposed role.
