# Hierarchical Style and Treatment Tournament

## Stage A — Context and Manual Baselines

Validate Context occurrence integrity and measure unconditional/manual policies.

## Stage B — Entry Mechanism Study

Hold stop/exit architecture controlled and compare Breakout, Market and Limit variants.

## Stage C — Payoff Profile Study

Compare P1–P5 for shortlisted entry mechanisms with profile-specific objectives.

## Stage D — Exit and Management Study

Compare fixed destination, trail, partial/runner, expiry and re-entry policies.

## Stage E — Model Ladder

Run baseline through advanced models on the frozen candidate universe.

## Stage F — Bounded Joint Tournament

Only shortlisted combinations enter joint search. All prior attempts remain in multiplicity evidence.

## Stage G — Prospective Challenge

Freeze one or few policies before observing new outcomes.
