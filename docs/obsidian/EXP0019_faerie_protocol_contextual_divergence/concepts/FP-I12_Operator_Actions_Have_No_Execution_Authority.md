# Operator actions have no execution authority

Operator actions have no execution authority. The rule is implemented by FP-I12 contracts, tests, MQL5 operator UX modules, and reason-coded diagnostics. It is part of the handoff to FP-I13 and may not be changed by a visual-only configuration.
