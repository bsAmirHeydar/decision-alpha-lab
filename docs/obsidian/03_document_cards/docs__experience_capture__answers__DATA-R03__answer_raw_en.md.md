## خلاصه

Layered training, context-zone-entry learning sequence, knowledge consolidation, reusable trained infrastructure, human inspectability, and training as capital. I will say the important things very simply. I want to make the training layered, in the same way that we once built the anatomy and it became our infrastructure. We should train layer by layer and then use the knowledge from each layer for the next layers. But the issue is that I want this trained knowledge to remain and become stabilized, so that we do not start the game from zero every time. Some issues should become finished and solved forever. Therefore, the system should go experience the market in three layers: Context. Zone.
