## خلاصه

The Python builder may generate a CSV using a broker GMT offset, for example `--broker-gmt-offset-hours 3`. That means the CSV already contains two separate timestamps: MQL5 must not shift the candle time again. Runtime lookup contract: Therefore, if the chart candle is `2026.01.02 10:50`, MQL searches for `broker_time=2026.01.02 10:50` exactly. It does not subtract 3 hours. It does not add 3 hours. The `utc_time` column is read from the CSV row and displayed as data generated by Python. It is not recalculated by MQL during lookup.
