## خلاصه

L2 is the minimum valid node level for Extreme because L1 is not structurally meaningful. L2 gives the system the smallest valid anchor that still has a minimum amount of left/right confirmation. This allows the system to detect more Extreme opportunities and preserve very small stop geometry. However, L2 is a default, not a dogma. Node level should remain testable and context-sensitive. The user's current definition: This means L-level expresses local isolation of a price node. The higher the L value, the more structurally isolated or broader the node may be. L1 is considered meaningless. Reason: Therefore: Suggested hard rule: unless a future manual NDS revision explicitly redefines it. L2
