## خلاصه

Scenario ranking in NDS is not a truth-selection problem. The system should not force one scenario to become dominant unless the structure itself requires it. The correct model is: Multiple scenarios can remain alive at the same time if each has its own NDS evidence and offers a convex opportunity. The goal is not to predict which scenario is correct. The goal is to find which scenario offers: A scenario does not need to become the only dominant scenario. Instead: A bullish scenario and bearish scenario may both remain alive as conditional plans if both have valid NDS constraints and both offer favorable convexity at their own zones.
