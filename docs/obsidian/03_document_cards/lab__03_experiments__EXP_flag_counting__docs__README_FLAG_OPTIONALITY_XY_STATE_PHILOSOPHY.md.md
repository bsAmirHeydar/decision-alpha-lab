## خلاصه

This document records the second layer of the Flag Project philosophy. The first layer of the Flag Project defines the market as an objective anatomy of price and liquidity. It rejects the attempt to begin from hidden causes, narratives, or after-the-fact explanations, and instead starts from the final observable result of all hidden forces: price. This second layer extends that philosophy into execution logic: the market is not always trending; the market is not always mean-reverting; the same structural location can mean reversal in one state and expansion in another; a valid system must therefore read both location and live state; the best trades are not necessarily the ones with the high
