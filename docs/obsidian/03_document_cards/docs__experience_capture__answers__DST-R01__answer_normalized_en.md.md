## خلاصه

Destination logic in NDS is not fully frozen yet. Destinations can emerge or become clearer through later structure, especially: The current objective is not to close profits too early. The system should attempt to keep more of the profit open when structural potential remains. Destination logic should therefore be treated as a trainable policy, not a fully hard-coded rule. A Destination should initially be modeled as a candidate set, not as one fixed target. Recommended canonical object: Because the user explicitly says that destinations may become clear through later F-countings, the system should allow destinations to be updated, expanded, repriced, or reweighted as new structure forms.
