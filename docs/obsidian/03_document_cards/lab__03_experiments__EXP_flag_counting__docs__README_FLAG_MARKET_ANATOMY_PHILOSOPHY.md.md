## خلاصه

This document defines the philosophical and engineering foundation of the Flag Project. The Flag Project is not meant to be treated as a classical chart-pattern strategy. It is a research program for building a correct viewing angle toward market structure. The central claim is simple: the market often looks chaotic because it is being viewed from the wrong angle. When the correct angle is found, many decisions that previously felt subjective, noisy, or overfitted become simpler, more constrained, and more operational.
