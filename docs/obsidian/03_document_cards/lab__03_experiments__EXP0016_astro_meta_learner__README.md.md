## خلاصه

EXP0016 is the machine-learning research layer for the mechanical astrology system in Decision Alpha Lab. Its purpose is to learn how astro states actually map to market behavior instead of forcing fixed symbolic rules such as `Jupiter = buy` or `Saturn = sell`. The experiment asks a more serious question: The system is designed as a skeptical learning machine. It fetches or builds its own data, creates causal labels, trains multiple models, evaluates them chronologically, stores reusable memory, and then reduces what it learned into stable principles.
