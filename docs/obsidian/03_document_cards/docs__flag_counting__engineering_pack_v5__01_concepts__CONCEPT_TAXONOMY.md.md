## خلاصه

This file organizes the model into object layers. Only high and low are structurally consumed. Other bar fields may exist in platform data but are irrelevant to this model. Nodes come from the existing project node module. The Flag Counting engine must reuse that logic instead of redefining it. The system may build several node views by L. These views are not arbitrary smoothing. They are structural node sets under the project L rule. A body candidate is the first complete two-leg geometry.
