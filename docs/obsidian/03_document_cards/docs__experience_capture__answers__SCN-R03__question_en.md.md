## خلاصه

When several scenarios, contexts, or zones are alive at the same time, how should the system rank, keep, reject, or plan them together? NDS allows multiple interpretations, multiple zones, multiple destinations, multiple entry points, and different risk allocations. The system needs a policy for scenario ranking without forcing one scenario to become the only dominant truth. Please clarify: If both bullish and bearish scenarios exist, should both remain alive?
