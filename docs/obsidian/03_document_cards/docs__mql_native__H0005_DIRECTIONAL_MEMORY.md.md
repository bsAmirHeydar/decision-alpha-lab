## خلاصه

H0005 asks whether branch-regime memory becomes usable directional/path memory. The market is not measured by fixed time windows. Direction is tested structurally: **Reversal regime:** the path has an X-axis destination. Entry starts at the next structural zone touch. Success means the opposite node/zone destination is touched before structural stop invalidation. The default stop model is the original zone-edge stop to avoid future hunt-extreme lookahead. The optional adaptive hunt-extreme stop remains available as an input-controlled research mode. **Continuation regime:** the path has no fixed X-axis target because structural levels are being broken.
