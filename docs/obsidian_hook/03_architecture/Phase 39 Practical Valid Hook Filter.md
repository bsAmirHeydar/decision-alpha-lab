# Phase 39 Practical Valid Hook Filter

The Phase 39 filter relaxes accidental over-filtering while preserving the core doctrine.

Changes:

- F3 immediate search uses structural Hook validity, not `render_eligible` only.
- Same-scale F3 matching is configurable.
- Near-death requirement in valid-only view is configurable.
- Hook-after-Hook scans all structurally prior candidates, not only earlier array rows.
- Valid-only labels are limited to selected valid sequences and required parent companions.
