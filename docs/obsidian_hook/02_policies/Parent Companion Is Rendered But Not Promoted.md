# Parent Companion Is Rendered But Not Promoted

When Hook-2 is valid by Hook-after-Hook, Hook-1 must be displayed with details so the chain can be read.

However, Hook-1 is not promoted into an independently valid Hook merely because it is displayed.

## Doctrine

```text
Hook-2 = valid Hook
Hook-1 = parent companion
```

The parent companion receives the label prefix:

```text
PARENT
```
