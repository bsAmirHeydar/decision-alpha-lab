# NDS Authority Boundary

## Authority chain

```text
Hook Canon
→ Zone Canon
→ Entry/Stop/Target Canon
→ Setup policy
→ Risk policy
→ Broker policy
→ Deployment authorization
```

Each downstream layer may narrow, reject, expire, or suspend an opportunity. It may not rewrite upstream anatomy.

## Ownership rules

| Object | Owns | Must not own |
|---|---|---|
| Structure | origin, crown, terminal, death, family, lineage | entry, volume, broker request |
| Zone | price boundaries and lifecycle | Hook reclassification, account sizing |
| Setup | direction policy and entry model selection | broker volume, trade send |
| Trade Plan | entry/stop/target geometry and RR | capital authorization |
| Risk Authorization | exposure and size permission | structure interpretation |
| Command | normalized operational intent | unrestricted broker access |
| Broker Adapter | platform validation and submission | strategy decisions |

## Failure policy

Unknown doctrine is represented as an explicit blocked state, never as a guessed default.
