# Valid Hook

A valid hook is a hook-like structure that passes the Alpha Lab Hook Validity Layer.

Only two families are valid by default:

1. [[Hook_After_Hook|Hook After Hook]]
2. [[Hook_After_Opposing_F3|Hook After Opposing F3]]

A valid hook may create a [[Hook_Zone|Hook Zone]]. An invalid hook may not create a primary tradable hook zone.

## Principle

> A hook becomes valuable only when it has structural lineage and can generate a measurable zone-based risk contract.
