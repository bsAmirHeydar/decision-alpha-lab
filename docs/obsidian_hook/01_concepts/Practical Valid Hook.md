# Practical Valid Hook

A Practical Valid Hook is a Hook sequence that belongs to one of the accepted production families without requiring unrelated display strictness.

Accepted families:

1. Immediate Hook After Opposing F3
2. Hook After Hook

The Hook may be structurally valid even if it is not yet a strict near-death semantic arc. Near-death can be enabled as an audit gate, but it is not part of the core validity definition.
