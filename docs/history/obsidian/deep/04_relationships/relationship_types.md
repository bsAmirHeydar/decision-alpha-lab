# Relationship Types

این فایل schema رابطه‌ها در Knowledge OS پروژه است.

| Relation | معنی |
|---|---|
| `defines` | یک فایل/مفهوم تعریف رسمی یا canonical مفهوم دیگر را ارائه می‌دهد. |
| `implements` | یک فایل کد یا ماژول اجرایی مفهوم را پیاده‌سازی می‌کند. |
| `tests` | یک experiment یا validation فرضیه/مفهوم را می‌آزماید. |
| `depends_on` | یک مفهوم یا ماژول برای معنا یا اجرا به مفهوم دیگر وابسته است. |
| `produces` | یک مرحله خروجی قابل مصرف برای مرحله بعد می‌سازد. |
| `audits` | یک سند یا ماژول صحت، causal بودن، یا robustness را بررسی می‌کند. |
| `documents` | یک فایل توضیح، راهنما، playbook یا روش استفاده می‌دهد. |
| `labels` | یک داده انسانی/ژورنالی را به فرم قابل یادگیری تبدیل می‌کند. |
| `guards` | یک قانون یا سیاست، ریسک یا تغییر غیرمجاز را محدود می‌کند. |
