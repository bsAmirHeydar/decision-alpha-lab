# CG Chapter 09 Decision Map

## مسیر تصمیم

1. آیا واگرایی تأیید شده است؟
2. آیا فقط یک نماد هانت کرده است؟
3. آیا نماد دیگر مرجع سالم دارد؟
4. آیا clean symbol مشخص است؟
5. آیا واگرایی بای است یا سل؟
6. معامله روی clean symbol انجام می‌شود.
7. همه حالت‌ها قبل از آمار با استاندارد یکسان معتبرند.

## خروجی

سیگنال معتبر + نماد معامله + جهت معامله + مرجع سالم.
