# CH05 — نقشه کشف آماری رفتار CGها

```text
همه CGها فعال
  ↓
ثبت سیگنال‌ها به تفکیک CG
  ↓
اندازه‌گیری نتیجه هر CG
  ↓
مقایسه CGها
  ↓
کشف خانواده‌ها
  ↓
تصمیم درباره حذف / محدودیت / وزن‌دهی / اولویت
```

## خروجی‌های لازم

- win rate
- expectancy
- invalidation rate
- movement quality
- time-window dependency
- hunter-clean dependency
- direction dependency
- reference-distance dependency
```
