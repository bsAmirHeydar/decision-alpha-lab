# CG Chapter 12 — Decision Map

```text
آیا واگرایی تأیید شده؟
  خیر → هنوز سیگنال نیست
  بله → آیا هر دو نماد مرجع را هانت کرده‌اند؟
      بله → واگرایی باطل است
      خیر → سیگنال زنده است
```

## قانون تصمیم

- اگر سیگنال زنده است، حذف نمی‌شود.
- اگر ابطال دوطرفه رخ دهد، سیگنال مرده است.
- کیفیت، اولویت، وزن و فیلتر بعداً با آمار تعیین می‌شود.
