# CH18 Execution Freedom Map

## Allowed without base restriction

- simultaneous CG signals;
- repeated same-CG signals;
- post-loss signals;
- post-win signals;
- opposite-direction signals;
- hedged exposure;
- multiple references;
- multiple clean-symbol entries.

## Not allowed

- execution when the divergence is invalidated;
- execution before candle-close confirmation;
- execution when the clean symbol is no longer clean.
