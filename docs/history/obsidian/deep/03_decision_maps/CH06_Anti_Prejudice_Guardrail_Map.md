# CH06 — Anti-Prejudice Guardrail Map

## هدف

این نقشه جلوی تبدیل حس اولیه به قانون را می‌گیرد.

## فیلتر محافظتی

قبل از هر حکم درباره یک CG بپرس:

1. آیا این حکم از داده آمده است؟
2. آیا نمونه کافی دارد؟
3. آیا در چند شرایط مختلف تست شده است؟
4. آیا فقط از ظاهر چارت آمده؟
5. آیا فقط از چند مثال دستی آمده؟
6. آیا ممکن است narrative fitting باشد؟
7. آیا آن را می‌توان به‌عنوان فرضیه نگه داشت نه قانون؟

## تصمیم

اگر پاسخ‌ها مطمئن نیستند، حکم باید به حالت فرضیه برگردد.
