# CH08 Signal Visibility Map

## Base Visibility Rule

```text
Confirmed divergence
↓
Show it
↓
Preserve it
↓
Study it later
```

## Do Not Hide Because Of

- cycle group size,
- time of day,
- hunter symbol,
- clean symbol,
- direction,
- reference distance,
- multiple simultaneous signals,
- visual candle shape.

## Purpose

Complete visibility creates a complete statistical and strategic memory.
