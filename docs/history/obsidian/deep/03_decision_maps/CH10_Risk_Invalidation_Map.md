# CH10 Risk Invalidation Map

## منطق ابطال مرجع clean

```text
نماد clean مرجع خود را حفظ کرده است
  ↓
این سلامت دلیل معامله است
  ↓
قیمت دوباره مرجع را لمس می‌کند؟
  ├─ خیر → ایده هنوز زنده است
  └─ بله → سلامت مرجع از بین رفته است
              ↓
          ایده clean-symbol شکست خورده است
```

## حالت‌های لمس مرجع

| حالت | نتیجه مدل پایه |
|---|---|
| لمس دقیق | باطل |
| عبور کوچک و برگشت | باطل |
| عبور عمیق | باطل |
| عبور سریع و برگشت سریع | باطل |

## اصل

مدل پایه tolerance ندارد. مرجع سالم یا ناسالم است.
