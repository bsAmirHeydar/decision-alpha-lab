# CH09 Statistical Discovery Map

## سؤال‌های آماری

- آیا clean symbol در همه CGها بهتر است؟
- آیا SPX clean بهتر از NDX clean است؟
- آیا بای بهتر از سل است؟
- آیا cash session clean-symbol logic را قوی‌تر می‌کند؟
- آیا مرجع سالم نزدیک یا دور تفاوت دارد؟

## نتیجه مطلوب

تبدیل doctrine پایه به طبقه‌بندی آماری قابل استفاده برای مدل تصمیم.
