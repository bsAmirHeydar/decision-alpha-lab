# CH14 Risk Red Flag Map

## red flagهای اصلی

- استاپ‌های پشت هم زیاد
- وین‌ریت خیلی بد
- برآیند منفی پایدار
- R:R ضعیف
- حرکت پیپی کم
- حرکت نسبت به نوسان روز ضعیف
- invalidation rate بالا

- حذف
- research-only
