# نقشه تصمیم فصل ۰۱ — از واگرایی تا طبقه‌بندی

## مسیر مفهومی

```text
دو نماد هم‌خانواده
↓
مرجع قیمتی در یک سایکل
↓
هانت در یک نماد
↓
عدم هانت در نماد دیگر
↓
عدم تقارن بین‌بازاری
↓
واگرایی در خانواده CG
↓
احتمال شروع جابه‌جایی قدرت
↓
سنجش آماری
↓
طبقه‌بندی خانواده
↓
تصمیم: معامله / هشدار / فیلتر / حذف
```

## تصمیم‌های قفل‌شده

| موضوع | تصمیم فصل اول |
|---|---|
| ماهیت واگرایی | زبان اختلاف رفتار دو بازار |
| منشأ واگرایی | عدم تقارن نقدینگی |
| ظرف معنا | سایکل‌گروپ |
| نقش CG | خانواده واگرایی |
| ارزش معامله | می‌تواند مستقل باشد |
| معیار نهایی | سودآوری |
| مأموریت آمار | طبقه‌بندی بازار و خانواده‌ها |

## تصمیم‌های باز برای فصل‌های بعدی

| موضوع | نیازمند پاسخ |
|---|---|
| مرجع دقیق | کدام high/low معتبر است؟ |
| کیفیت هانت | آیا همه لمس‌ها برابرند؟ |
| شخصیت CG | هر خانواده چه رفتاری دارد؟ |
| وزن زمان | کدام ساعت‌ها برترند؟ |
| نقش نمادها | hunter/clean کدام بهتر است؟ |
| مدل خروج | خروج زمانی، قیمتی، یا ترکیبی؟ |
| کیفیت سیگنال | چه چیزی سیگنال را درجه یک می‌کند؟ |

## قانون راهنما

هر جواب جدید باید در این نقشه قرار بگیرد. اگر جواب جدید به فهم عدم تقارن، سایکل درست، جابه‌جایی قدرت، سودآوری یا طبقه‌بندی کمک نکند، فعلاً در هسته استراتژی قرار نمی‌گیرد.
