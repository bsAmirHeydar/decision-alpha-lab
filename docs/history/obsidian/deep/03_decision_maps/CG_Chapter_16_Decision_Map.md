# CG Chapter 16 Decision Map

## سؤال مرکزی

آیا مدل باید تصمیم معامله بگیرد؟

```text
خیر
↓
مدل فقط آمار و کیفیت را گزارش می‌دهد
↓
معمار استراتژی تصمیم می‌گیرد
```

## مسیر تصمیم

```text
سیگنال‌های معتبر تاریخی
↓
گروه‌بندی بر اساس CG / direction / hunter-clean / time / reference / overlap
↓
محاسبه win rate / expectancy / R / pip / normalized pip
↓
بررسی stop streak / invalidation / sample size
↓
ساخت quality report
↓
تصمیم انسانی درباره rule promotion
```
