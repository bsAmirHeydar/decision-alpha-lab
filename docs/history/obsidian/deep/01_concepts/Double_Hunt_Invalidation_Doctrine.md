# Double Hunt Invalidation Doctrine

## Definition

Double hunt occurs when both symbols hunt their corresponding reference.

## Doctrine

If both symbols hunt, divergence is invalid.

## Why

Divergence is asymmetry. Double hunt removes asymmetry.

## Examples

| Condition | Result |
|---|---|
| SPXUSD hunts high, NDXUSD does not | Bearish divergence candidate. |
| NDXUSD hunts high, SPXUSD does not | Bearish divergence candidate. |
| Both hunt high | No bearish divergence. |
| SPXUSD hunts low, NDXUSD does not | Bullish divergence candidate. |
| NDXUSD hunts low, SPXUSD does not | Bullish divergence candidate. |
| Both hunt low | No bullish divergence. |
