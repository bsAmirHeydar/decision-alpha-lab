# No Filter, No Suppression — Base Layer

## تعریف

در لایه پایه، سیگنال معتبر واگرایی سرکوب نمی‌شود.

## سرکوب یعنی چه؟

نادیده گرفتن یک سیگنال فقط به دلیل عامل جانبی قبل از اینکه آمار ثابت کند آن عامل واقعاً مهم است.

## چرا ممنوع است؟

زیرا دیتاست را خراب می‌کند و باعث می‌شود مدل آینده از داده ناقص یاد بگیرد.

## قانون

> ابتدا همه سیگنال‌ها را ببین. بعداً آمار تصمیم می‌گیرد چه چیزی ارزش دارد.
