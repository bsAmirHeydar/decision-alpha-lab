# Future Combination With Price Targets

## اصل

تارگت زمانی در مدل پایه کافی است، اما بعداً می‌تواند با تارگت‌های قیمتی ترکیب شود.

## چرا فعلاً نه؟

چون ابتدا باید ارزش خام خروج زمانی سنجیده شود.

## ترکیب‌های آینده

- time target + fixed price target
- time target + R multiple
- time target + partial
- time target + trailing behavioral exit
- time target + CG-specific exit

## شرط ترکیب

هر ترکیب باید بعد از آمار خام و با مقایسه روشن ساخته شود.
