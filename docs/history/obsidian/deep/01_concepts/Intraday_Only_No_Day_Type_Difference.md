# Intraday Only — No Day Type Difference

## اصل

چون مدل درون‌روزی است، نوع روز در لایه پایه تفاوتی ایجاد نمی‌کند.

## مصادیق تفاوت‌نداشتن

- روز هفته
- قبل/بعد تعطیلی
- روز خاص یا عادی
- شکل کلی روز

## بازبینی آینده

اگر آمار نشان دهد نوع روز اثر معنادار دارد، می‌تواند بعداً به‌عنوان لایه جداگانه بررسی شود.
