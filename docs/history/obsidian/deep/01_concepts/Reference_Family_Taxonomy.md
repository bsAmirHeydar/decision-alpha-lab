# Reference Family Taxonomy

## خانواده‌ها

- Previous Cycle Reference
- Near Previous References
- Far Same-Day References
- First Cycles of Day References
- Pre-Cash References
- Cash Session References
- Multi-Reference Divergence
- Invalidation-Prone References

## هدف

این خانواده‌ها برای رتبه‌بندی اولیه نیستند. برای دیدن تفاوت‌ها در تست آماری آینده هستند.

## اصل

هر reference family باید جدا مطالعه شود، چون ممکن است شخصیت معاملاتی متفاوت داشته باشد.
