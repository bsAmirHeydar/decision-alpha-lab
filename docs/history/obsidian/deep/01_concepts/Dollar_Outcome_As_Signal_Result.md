# Dollar Outcome As Signal Result

## تعریف

برآیند دلاری مقدار سود یا زیان نهایی هر سیگنال است.

## اصل

معمار استراتژی پاسخ داد که مقدار سود دلاری، برآیند سیگنال را مشخص می‌کند.

## چرا مهم است؟

چون وین‌ریت به تنهایی کافی نیست. باید فهمید هر خانواده سیگنال واقعاً چقدر پول ساخته یا از دست داده است.

## کاربرد

برآیند دلاری بعداً برای طبقه‌بندی این موارد استفاده می‌شود:

- CGها
- جهت‌ها
- نمادهای clean
- زمان‌ها
- reference distance
- cash session
- سیگنال‌های چندمرجعی
