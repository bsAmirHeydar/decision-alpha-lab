# Cycle Group Observation Protocol

## هدف

مشاهده CGها باید منصفانه باشد تا مقایسه آماری بعداً معنی داشته باشد.

## قواعد مشاهده

1. هر CG مستقل دیده شود.
2. ظاهر چارت معیار اعتبار نباشد.
3. تعداد سیگنال به‌تنهایی خوب یا بد نیست.
4. اندازه زمانی معیار قدرت نیست.
5. همزمانی CGها فقط ثبت شود، نه تفسیر قطعی.
6. هر CG در contextهای مختلف بررسی شود.
7. هیچ نتیجه‌ای با نمونه کم قطعی نیست.

## حالت ذهنی مناسب

برای هر CG باید بگوییم:

> فعلاً نمی‌دانم این CG چه شخصیتی دارد. باید دیده و تست شود.
