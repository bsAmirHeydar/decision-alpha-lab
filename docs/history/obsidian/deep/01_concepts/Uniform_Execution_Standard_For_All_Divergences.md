# Uniform Execution Standard for All Divergences

## اصل

همه واگرایی‌های تأییدشده با یک استاندارد پایه دیده می‌شوند.

## یعنی چه؟

- همه CGها اجازه معامله دارند.
- بای و سل هر دو معتبرند.
- SPX clean و NDX clean هر دو معتبرند.
- هیچ گروهی قبل از آمار حذف نمی‌شود.

## چرا؟

چون پروژه باید ابتدا رفتار خام را ببیند، سپس تفاوت‌ها را از دل آمار استخراج کند.
