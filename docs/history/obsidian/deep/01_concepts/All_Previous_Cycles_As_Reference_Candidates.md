# All Previous Cycles as Reference Candidates

## تعریف

همه سایکل‌های پیشین همان روز، نامزد مرجع هستند.

## مثال مفهومی

اگر در سایکل فعلی `cg_30m` هستیم، فقط سایکل ۳۰ دقیقه‌ای قبل مهم نیست. همه سایکل‌های ۳۰ دقیقه‌ای قبلی همان روز می‌توانند high/low مرجع داشته باشند.

## دلیل

ما فعلاً نمی‌دانیم کدام فاصله از مرجع مهم‌تر است. حذف هر دسته قبل از تست آماری باعث از دست رفتن اطلاعات می‌شود.

## قانون

> اول همه را ببین، بعد با آمار بفهم کدام ارزش دارد.
