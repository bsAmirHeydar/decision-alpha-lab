# Clean Reference Retouch As Failure

## اصل

اگر نماد clean بعد از واگرایی مرجع خودش را دوباره لمس کند، ایده‌ی سالم‌بودن آن شکست خورده است.

## چرا؟

چون دلیل ورود روی نماد clean این بود که سطح مرجع آن سالم مانده بود. اگر همان سطح لمس شود، دیگر clean بودن رفتاری از بین رفته است.

## حالت‌ها

- لمس دقیق مرجع: شکست ایده
- عبور کوچک و برگشت: شکست ایده
- عبور عمیق: شکست ایده
- نفوذ سریع و برگشت سریع: شکست ایده
