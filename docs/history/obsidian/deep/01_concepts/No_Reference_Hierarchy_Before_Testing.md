# No Reference Hierarchy Before Testing

## اصل

هیچ مرجع، هیچ سایکل و هیچ فاصله‌ای قبل از تست آماری اولویت ندارد.

## چیزهایی که فعلاً ممنوع‌اند

- گفتن اینکه سایکل قبلی همیشه بهتر است.
- گفتن اینکه مرجع دورتر ضعیف‌تر است.
- گفتن اینکه high reference مهم‌تر از low reference است.
- گفتن اینکه cash reference همیشه بهتر است.

## چرا؟

چون این‌ها می‌توانند bias بسازند و باعث شوند مدل فقط چیزی را ببیند که ما از قبل باور داشته‌ایم.

## داکترین

> hierarchy باید کشف شود، نه تحمیل.
