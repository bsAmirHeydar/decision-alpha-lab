# No Confluence Assumption Before Testing

## تعریف

هم‌زمانی چند CG یا چند سیگنال به‌خودی‌خود قدرت بیشتر نیست.

## چرا؟

ممکن است confluence واقعی باشد، اما ممکن است فقط یک روایت بصری باشد. فصل ۱۱ می‌گوید تا قبل از تست آماری، confluence نباید اعتبار اضافه بدهد.

## اصل

هم‌زمانی CGها ثبت می‌شود، اما وزن تصمیمی نمی‌گیرد مگر بعداً آمار آن را تأیید کند.
