# Independent Testing For All Families

## تعریف

همه خانواده‌های سیگنال باید مستقل بررسی شوند. هیچ خانواده‌ای نباید داخل میانگین کلی مخفی شود.

## خانواده‌ها

- CGها
- buy/sell
- hunter/clean role
- cash/outside cash
- reference distance
- window outcome
- invalidation behavior
- multi-CG context

## چرا مهم است؟

اگر همه چیز با هم میانگین گرفته شود، ممکن است خانواده‌های خوب زیر خانواده‌های بد دفن شوند یا خانواده‌های بد پشت چند خانواده خوب پنهان شوند.
