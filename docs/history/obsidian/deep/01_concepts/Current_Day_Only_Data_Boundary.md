# Current-Day Only Data Boundary

## تعریف

مدل فقط مراجع ساخته‌شده در روز جاری را برای ورودهای همان روز بررسی می‌کند.

## دلیل

- سبک شدن تحلیل
- کاهش پیچیدگی
- جلوگیری از انباشت سطوح قدیمی
- تمرکز روی رفتار روز فعلی
- ساده‌تر شدن تست آماری

## نکته

این تصمیم به معنی بی‌ارزش بودن دیتای روز قبل نیست. فقط در نسخه پایه، برای تمیز ماندن مدل حذف می‌شود.
