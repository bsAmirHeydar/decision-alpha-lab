# FP-I06 Relation Instance Is A Frozen Reference Check Binding

## Definition

A relation instance is the immutable binding of one reference window, one check window, one relation code, one anchor trading date, and—when historical—one exact calendar offset.

## Operational consequence

- Encode the concept in immutable contracts.
- Include behavior-bearing inputs in semantic identity.
- Preserve negative and ambiguous outcomes as evidence.
- Test deterministic replay and changed-input divergence.
