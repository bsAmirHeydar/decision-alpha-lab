# Model Recommendations as Non-Automatic Rules

## تعریف

توصیه مدل قانون نیست. توصیه مدل candidate است.

## مسیر درست

1. مدل یک الگو پیدا می‌کند.
2. الگو گزارش می‌شود.
3. معمار بررسی می‌کند.
4. در صورت ارزش، وارد paper test یا نسخه بعدی می‌شود.
5. بعد از تأیید بیشتر ممکن است rule شود.

## مثال

مدل می‌گوید:

> cg_90m در cash session با NDX hunter و SPX clean وین‌ریت بهتری دارد.

این هنوز قانون نیست. فقط یک یافته آماری برای بررسی است.
