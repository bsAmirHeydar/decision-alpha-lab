# CH05 — چک‌لیست بازبینی معمار استراتژی

## برابری پایه

- [ ] آیا همه CGها در لایه پایه مجاز هستند؟
- [ ] آیا هیچ CG قبل از آمار برتر فرض نشده است؟
- [ ] آیا سایکل بزرگ‌تر خودبه‌خود قوی‌تر فرض نشده است؟
- [ ] آیا سایکل کوچک‌تر خودبه‌خود نویزی‌تر فرض نشده است؟

## مرز روز

- [ ] آیا روز معاملاتی از 18:00 نیویورک شروع می‌شود؟
- [ ] آیا پایان روز 17:00 نیویورک است؟
- [ ] آیا مرز 18:00 به‌عنوان قرارداد رفتاری پایدار فهم شده است؟

## استقلال CGها

- [ ] آیا هر CG به‌عنوان واحد رفتاری مستقل دیده می‌شود؟
- [ ] آیا سیگنال‌های CGهای مختلف با هم قاطی نشده‌اند؟
- [ ] آیا هر CG قابلیت بررسی جداگانه دارد؟

## کشف آماری

- [ ] آیا تفاوت CGها فقط بعد از تست پذیرفته می‌شود؟
- [ ] آیا امکان کشف وین‌ریت، برآیند، نرخ ابطال و زمان مناسب هر CG حفظ شده است؟
- [ ] آیا حذف یا وزن‌دهی CGها به بعد از داده موکول شده است؟

## جمله نهایی

- [ ] آیا این اصل حفظ شده است: همه CGها برابر شروع می‌کنند، اما آمار تعیین می‌کند چگونه ادامه دهند؟
