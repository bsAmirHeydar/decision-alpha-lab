# CH20 — Strategy Architect Review Checklist

## Current version boundary

- [ ] The model does not change strategy rules.
- [ ] The model only collects and analyzes statistics.
- [ ] Any recommendation remains non-automatic.
- [ ] Strategy architect approval is required before rule promotion.

## Future optimization

- [ ] Future optimization is documented as possible, not active.
- [ ] Optimized variants are separated from the base version.
- [ ] The base version remains measurable and comparable.

## CG overlap

- [ ] CG overlap is tracked as a complexity source.
- [ ] Overlap is not treated as automatically good or bad.
- [ ] Same-direction and opposite-direction overlap are measured separately.
- [ ] Hedge clusters are measured separately.

## Repetition and ambiguity

- [ ] Repeated questions reference existing doctrine.
- [ ] Unknown recommendations do not mutate the strategy.
- [ ] Future decisions remain in backlog until explicitly answered.
