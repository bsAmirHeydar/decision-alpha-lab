# CH03 Strategy Architect Review Checklist

## هدف

این چک‌لیست برای بازبینی فصل سوم استفاده می‌شود تا مطمئن شویم زبان هانت، مرجع و ابطال دقیق و بدون تناقض باقی مانده است.

## هانت

- [ ] آیا هانت به‌عنوان جمع‌آوری نقدینگی و شکست کاذب تعریف شده است؟
- [ ] آیا لمس و عبور هر دو هانت محسوب شده‌اند؟
- [ ] آیا سقف/کف مساوی هم هانت محسوب شده است؟
- [ ] آیا کلوز پشت سطح از شرط هانت حذف شده است؟
- [ ] آیا کلوز فقط برای قطعی‌شدن واگرایی استفاده شده است؟

## مرجع

- [ ] آیا مرجع تازه از مرجع مصرف‌شده جدا شده است؟
- [ ] آیا یک‌بارمصرف بودن مرجع قفل شده است؟
- [ ] آیا استفاده دوباره از مرجع مصرف‌شده ممنوع شده است؟
- [ ] آیا re-hunt فقط به‌عنوان موضوع پژوهش آینده دیده شده است؟

## واگرایی

- [ ] آیا واگرایی فقط با عدم تقارن بین دو نماد معنا دارد؟
- [ ] آیا هانت شدن طرف مقابل به‌عنوان ابطال کامل ثبت شده است؟
- [ ] آیا واگرایی باطل‌شده از واگرایی معتبر جدا شده است؟

## پژوهش آینده

- [ ] آیا همه هانت‌ها برای ثبت خام مهم دانسته شده‌اند؟
- [ ] آیا تفاوت زیرنوع‌های هانت فعلاً فیلتر نشده است؟
- [ ] آیا زیرنوع‌ها فقط به‌عنوان طبقه‌بندی آماری آینده تعریف شده‌اند؟
- [ ] آیا پرسش‌های آماری فصل سوم مشخص شده‌اند؟
