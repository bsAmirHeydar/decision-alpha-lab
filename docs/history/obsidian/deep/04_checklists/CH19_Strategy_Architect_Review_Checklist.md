# CH19 — چک‌لیست بازبینی معمار استراتژی

## جهت

- [ ] آیا high hunt همیشه sell divergence تعریف شده؟
- [ ] آیا low hunt همیشه buy divergence تعریف شده؟
- [ ] آیا جهت‌ها قبل از آمار رتبه‌بندی نشده‌اند؟

## استقلال

- [ ] آیا CGها مستقل مانده‌اند؟
- [ ] آیا سایکل‌های داخل CG مستقل مانده‌اند؟
- [ ] آیا buy/sell مستقل مانده‌اند؟
- [ ] آیا سیگنال‌های هم‌زمان حذف نشده‌اند؟

## محدودیت‌ها

- [ ] آیا ورود دیرهنگام فیلتر نشده؟
- [ ] آیا استاپ بزرگ فیلتر نشده؟
- [ ] آیا تعداد سیگنال‌ها اعتبار را تغییر نداده؟
- [ ] آیا hedge یا خلاف‌جهت بودن ممنوع نشده؟

## ابطال

- [ ] آیا ابطال در لحظه تأیید از ابطال بعد از تأیید جدا شده؟
- [ ] آیا post-confirmation invalidation ثبت می‌شود؟
- [ ] آیا رفتارهای غیرواگرایی وارد دیتاست واگرایی نشده‌اند؟

## آمار و مدل

- [ ] آیا مدل فقط تحلیل می‌کند؟
- [ ] آیا استراتژی بدون تصمیم معمار تغییر نکرده؟
- [ ] آیا همه نمونه‌ها برای آمار حفظ شده‌اند؟
