# CH10 Strategy Architect Review Checklist

## ابهام باز

- [ ] سؤال اول درباره معنای دقیق استاپ دوباره با زبان ساده‌تر پرسیده شود.
- [ ] مشخص شود استاپ فقط پایان معامله است یا ابطال رفتاری کامل.

## استاپ و ابطال

- [ ] آیا لمس دوباره مرجع clean همیشه شکست ایده است؟ پاسخ فعلی: بله.
- [ ] آیا عبور کوچک و برگشت هم باطل‌کننده است؟ پاسخ فعلی: بله.
- [ ] آیا استاپ باید مطلق باشد؟ پاسخ فعلی: بله.

## ریسک

- [ ] آیا ریسک برای همه CGها ثابت است؟ پاسخ فعلی: بله.
- [ ] آیا کیفیت واگرایی ریسک را تغییر می‌دهد؟ پاسخ فعلی: خیر.
- [ ] آیا ریسک ثابت تا قبل از آمار حفظ می‌شود؟ بله.

## خروج زمانی

- [ ] آیا خروج انتهای سایکل برای تارگت نسبی است؟ بله.
- [ ] آیا دلیل عمیق‌تری فعلاً برای خروج زمانی وجود دارد؟ خیر.
- [ ] آیا با سود بزرگ قبل از پایان سایکل خارج می‌شویم؟ در مدل پایه: خیر، می‌مانیم.

## نتیجه سیگنال

- [ ] آیا برآیند دلاری معیار نتیجه سیگنال است؟ بله.
- [ ] آیا وین‌ریت به تنهایی کافی نیست؟ باید با برآیند دلاری ترکیب شود.

## آینده

- [ ] آیا تارگت زمانی بعداً با تارگت قیمتی ترکیب می‌شود؟ بله.
- [ ] آیا این ترکیب باید بعد از آمار خام انجام شود؟ بله.
