# CH06 — Strategy Architect Review Checklist

## چک‌لیست فصل ششم

- [ ] آیا همه CGها قبل از تست آماری برابر دیده شده‌اند؟
- [ ] آیا هیچ CG به خاطر بزرگ‌تر بودن قوی‌تر فرض نشده است؟
- [ ] آیا هیچ CG به خاطر کوچک‌تر بودن نویزی‌تر فرض نشده است؟
- [ ] آیا هیچ CG به خاطر رند بودن معتبرتر فرض نشده است؟
- [ ] آیا هیچ CG به خاطر غیررند بودن ضعیف‌تر فرض نشده است؟
- [ ] آیا هیچ CG از پژوهش حذف نشده است؟
- [ ] آیا هیچ CG بدون آمار اولویت نگرفته است؟
- [ ] آیا تفاوت CGها به‌عنوان فرضیه نگه داشته شده، نه قانون؟
- [ ] آیا شخصیت CGها به بعد از تست آماری موکول شده است؟
- [ ] آیا همزمانی CGها به‌عنوان مشاهده ثبت شده، نه confluence قطعی؟
- [ ] آیا buy/sell، hunter/clean، session و reference برای هر CG جدا دیده خواهند شد؟
- [ ] آیا فصل ششم به فصل پنجم وصل شده و اصل بی‌طرفی را تقویت کرده است؟
- [ ] آیا زبان سند از قطعیت زودهنگام دوری کرده است؟
- [ ] آیا تمام نتیجه‌گیری‌های رفتاری به آمار واگذار شده‌اند؟

## جمله نهایی بازبینی

> تا قبل از آمار، هیچ CG شخصیت ندارد؛ فقط امکان دارد.
