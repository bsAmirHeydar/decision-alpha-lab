# CH02 Strategy Architect Review Checklist

## قبل از پذیرفتن فصل دوم

- [ ] آیا رابطه SPXUSD/NDXUSD دقیقاً به‌عنوان تاریخی، قیمتی و نسبی تعریف شده؟
- [ ] آیا علت چسبندگی رابطه توضیح داده شده؟
- [ ] آیا SPXUSD به‌عنوان جریان عمومی‌تر بازار تعریف شده بدون اینکه leader ثابت شود؟
- [ ] آیا اعتبار برابر دو نماد حفظ شده؟
- [ ] آیا نبود مبدا/مقصد ثابت قفل شده؟
- [ ] آیا hunt-only به‌عنوان معیار خام فصل دوم حفظ شده؟
- [ ] آیا نبود فیلتر اضافی در این مرحله روشن است؟
- [ ] آیا cash session به‌عنوان بازه معتبرتر، نه تنها بازه معتبر، تعریف شده؟
- [ ] آیا clean symbol به‌عنوان محل پایه معامله ثبت شده؟
- [ ] آیا برتری‌های احتمالی به آزمون آینده سپرده شده‌اند؟

## برای ادامه پژوهش

- [ ] آیا رویدادها بر اساس hunter/clean جدا می‌شوند؟
- [ ] آیا رویدادها بر اساس buy/sell جدا می‌شوند؟
- [ ] آیا cash و outside cash جدا می‌شوند؟
- [ ] آیا هر CG جدا بررسی می‌شود؟
- [ ] آیا SPX hunter و NDX hunter جدا بررسی می‌شوند؟
- [ ] آیا SPX clean و NDX clean جدا بررسی می‌شوند؟
- [ ] آیا نتیجه با میانگین کلی پنهان نمی‌شود؟

## خط قرمزها

- [ ] یکی از دو نماد بدون آمار برتر اعلام نشود.
- [ ] فیلترهای اضافی وارد تعریف پایه نشوند.
- [ ] cash session باعث حذف کامل بقیه روز نشود.
- [ ] SPXUSD به‌خاطر جریان عمومی‌تر بودن، leader دائمی فرض نشود.
- [ ] clean-symbol execution بدون ثبت نتایج و بررسی آینده رها نشود.
