# CH12 — Strategy Architect Review Checklist

## قانون ماندگاری

- [ ] آیا سیگنال فقط بعد از تأیید با کلوز بررسی شده است؟
- [ ] آیا تا زمان ابطال واقعی حذف نشده است؟
- [ ] آیا ابطال فقط با هانت دوطرفه مرجع تعریف شده است؟

## استقلال CGها

- [ ] آیا هر CG مستقل دیده شده است؟
- [ ] آیا سیگنال CG دیگر باعث حذف این CG نشده است؟
- [ ] آیا هم‌زمانی CGها فقط ثبت شده و نه تفسیر قطعی؟
- [ ] آیا تضاد CGها باعث حذف دستی نشده است؟

## عدم فیلتر زودهنگام

- [ ] آیا هیچ سیگنالی به دلیل ظاهر، حس، زمان، جهت یا نماد حذف نشده است؟
- [ ] آیا همه سیگنال‌های زنده وارد میدان پژوهش شده‌اند؟
- [ ] آیا تفاوت‌ها به آمار آینده واگذار شده‌اند؟

## reset روزانه

- [ ] آیا تصمیم روز جاری مستقل از روزهای قبل است؟
- [ ] آیا روزهای قبل فقط برای تحقیق استفاده می‌شوند، نه تصمیم خام؟

## تفکیک مفهومی

- [ ] آیا زنده بودن سیگنال با خوب بودن سیگنال اشتباه گرفته نشده است؟
- [ ] آیا پایان معامله از ابطال رفتاری سیگنال جدا دیده شده است؟
