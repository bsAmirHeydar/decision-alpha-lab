# F2 Waist-Hit Point 1/2

This concept corrects the specific F2 case where the F2 structure hits its own waist.

The correct grammar is:

```text
F2 hits its waist
→ waist-hit can become Point 1
→ next relevant hit/extension becomes Point 2
→ from Point 2 onward/beyond, reversal potential becomes active
```

This is not a direct-entry doctrine. It is a parent reversal-potential doctrine.

## Why It Matters

If the system treats “waist hit” as a generic reversal signal, it will overtrade. The actual value is that the waist-hit can re-anchor F2 and create a 1/2 relationship. Only after Point 2 exists does the reversal field become meaningful.

## Execution Policy

```text
Parent F2 reversal potential is not enough.
A stable entry edge and stop edge are required.
If the parent stop is not stable, use lower-timeframe child-zone refinement.
```

## Relationship to [[Zone_as_Risk_Contract]]

The structure becomes useful only if it can be converted into a risk contract:

```text
entry edge + stop/expiration edge + open reward potential
```

Without that, it is a watch zone.
