# Shared Terminal-Start Node

The Shared Terminal-Start Node is the exact node where one valid hook ends and the next valid hook begins.

It is the defining condition of Hook After Hook.

## Rule

The last node of Hook-1 must be the first node of Hook-2.

Nearness is not enough. Visual similarity is not enough. The node must be structurally identical.
