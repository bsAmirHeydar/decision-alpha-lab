# Direct Terminal Post F3 Hook

A Direct Terminal Post-F3 Hook starts from the terminal side of the opposing F3.

```text
F3 terminal side
→ opposite Hook starts there
→ Hook closes structurally or qualifies geometrically
```

## Structural version

Requires full Hook anatomy:

- origin at/near F3 terminal side;
- opposite crown;
- confirmed terminal node;
- closed Hook lifecycle.

## Geometric 80% version

Allowed only in explicit geometric mode.

It accepts a cycle/semicircle after F3 when the cycle reaches the configured near-death/completion threshold, candidate default: 80%.

## Not allowed

A direct candidate is not a Hook if origin is touched before its terminal node is confirmed, unless another new node forms before that death event and starts a new candidate.
