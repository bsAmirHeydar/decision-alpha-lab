# Eighty Percent Cycle Hook

An 80% Cycle Hook is a geometric post-F3 Hook candidate.

It is used for cases where the chart clearly shows a near-death semicircle/cycle but the full structural Hook sequence has not printed.

## Rule

A geometric candidate can be considered a Hook only when:

- geometric mode is explicitly enabled;
- it belongs to the post-F3 ownership window;
- it opposes the F3 direction;
- it reaches at least the configured cycle completion threshold, default candidate: 80%;
- it does not violate origin death before qualification.

## Important distinction

It is not the same thing as a structural Hook.

It should have its own family label, for example:

```text
F3H80-DIR
F3H80-REB
```
