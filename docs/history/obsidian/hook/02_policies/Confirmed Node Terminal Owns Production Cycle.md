# Confirmed Node Terminal Owns Production Cycle

The production Hook cycle ends at the confirmed terminal node.

## Positive Hook terminal

```text
lowest confirmed valley still above origin
```

## Negative Hook terminal

```text
highest confirmed peak still below origin
```

## Raw extremes

Raw candle highs/lows are not production terminal ownership.

They can be used for later diagnostics, but they must not extend production valid-only arcs or decide Hook-after-Hook continuity.
