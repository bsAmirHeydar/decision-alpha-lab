# Hook Validity Hard Rules

1. Only Hook After Hook and Hook After Opposing F3 are valid primary hook families.
2. A Hook After Hook requires an exact shared terminal-start node.
3. A Hook After Opposing F3 requires a hook direction opposite to the prior F3 direction.
4. Invalid hooks cannot generate primary tradable hook zones.
5. Hook validity must be checked before zone scoring.
6. A hook zone without a clear stop/expiration boundary is not directly tradable.
7. Fractal re-counting cannot create validity by itself.
8. Aesthetic pattern quality is not structural evidence.
9. Hindsight identification is not valid evidence.
10. Valid hooks may still require lower-timeframe child-zone refinement if their zones are wide.
