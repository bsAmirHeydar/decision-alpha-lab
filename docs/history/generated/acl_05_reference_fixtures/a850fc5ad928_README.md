# ACL-05 Reference Fixtures

These inputs are deterministic, synthetic and intentionally non-production. They exercise ACL-04 intake, candidate/search freeze, known-time validation, label maturity, purged walk-forward splitting, environment isolation, compute budgets and byte-exact artifact storage.

The fixture data is not evidence of market quality or alpha. `reference_batch/` is generated from these files and the accepted ACL-04 reference factory output. Changes to any material fixture must create a different Batch ID.
