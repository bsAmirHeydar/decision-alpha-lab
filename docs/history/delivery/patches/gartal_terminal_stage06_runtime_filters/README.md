# gartal terminal — Stage 06 Runtime Filter Engine Patch

This patch implements the interactive dashboard filter layer for `gartal terminal`.

## Adds

- `GartalNewsFilters.mqh`
- clickable impact filters
- clickable special filters
- clickable currency chips
- utility presets
- store metric recalculation after click
- dashboard/timeline repaint after click
- runtime filter diagnostics
- Stage 06 Obsidian documentation
- Stage 06 canvas and validation script

## Scope

This patch does not implement the alert state machine or Forex Factory parser. Those remain Stage 07 and Stage 08.
