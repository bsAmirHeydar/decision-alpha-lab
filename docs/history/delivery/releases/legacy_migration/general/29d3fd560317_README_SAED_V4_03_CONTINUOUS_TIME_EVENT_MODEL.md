# SAED V4-03 Continuous-Time Event Model

This patch implements the deterministic continuous-time event foundation above V4-02 Context Digital Twin and below V4-04 Multimodal View Platform. It includes Python code, closed contracts, fixtures, tests, MQL5 diagnostics, Obsidian documentation, release validation and bounded handoff artifacts.

The event model has no Treatment, risk, runtime, broker, network or order authority.
