# Install F2 Waist-Hit Correction Patch

Place `alpha_lab_f2_waist_hit_correction_patch.zip` in the project root and run:

```powershell
Expand-Archive -Path .\alpha_lab_f2_waist_hit_correction_patch.zip -DestinationPath . -Force
Remove-Item .\alpha_lab_f2_waist_hit_correction_patch.zip
```

Then open Obsidian from the project root and start from:

```text
00_F2_WAIST_HIT_CORRECTION_START_HERE.md
```
