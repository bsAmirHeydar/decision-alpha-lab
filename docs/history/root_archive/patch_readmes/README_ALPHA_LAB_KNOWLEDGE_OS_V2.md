
# Alpha Lab Knowledge OS V2

این خروجی یک لایه Obsidian عمیق برای Decision Alpha Lab است.

## خروجی‌های ساخته‌شده

- مدل canonical پروژه
- hard rules
- ontology رسمی
- نردبان شواهد
- research contract
- concept pages برای 20 مفهوم اصلی
- source cards برای 891 فایل مستند/متنی
- relationship map بین sourceها
- entity map برای 80 entity استخراج‌شده
- traceability matrix
- code-to-concept map برای 523 فایل کد/ابزار
- workflowهای research، hypothesis، patch، agent و journal
- conversation-derived knowledge از اصولی که در پروژه گفتی
- Canvasهای تصویری برای معماری سیستم

## هدف

این لایه قرار است پروژه را از حالت «انبوه README و کد» به یک **سیستم دانشی قابل ردیابی، قابل audit و قابل توسعه با AI Agent** تبدیل کند.
