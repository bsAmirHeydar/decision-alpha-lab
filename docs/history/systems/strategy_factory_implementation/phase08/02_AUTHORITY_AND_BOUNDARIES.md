# Authority and Boundaries

MQL5 remains the primary runtime authority. Anatomy owns what happened. Context owns what was knowable. Candidate policies may only transform those immutable inputs into hypothetical entry, stop and exit plans. A policy cannot mutate an event, feature snapshot, context state, market cache, model artifact or account state.

## Operational rules

- All identifiers and versions are explicit.
- Inputs are immutable and causal.
- Work and memory are bounded.
- Failure is explicit and fail-closed.
- No previous strategy is integrated in this phase.
- Every future extension must preserve deterministic candidate identity.
