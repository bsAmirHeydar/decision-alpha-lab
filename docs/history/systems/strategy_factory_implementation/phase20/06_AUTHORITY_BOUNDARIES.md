# Authority Boundaries

| Component | Authority |
|---|---|
| Legacy EXP0017 detector | anatomy classification |
| SF20 mapper | contract translation |
| Context/Candidate engines | research derivation |
| Inference | gated until governed EXP0017 model exists |
| Decision | forced skip while inference is gated |
| Paper/Shadow | receives no intent |
