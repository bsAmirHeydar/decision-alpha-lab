# Doctrine Preservation

Preserved hard rules:
1. Cycle groups remain independent observations.
2. A divergence requires a one-sided hunt.
3. Symmetric hunts do not become divergence events.
4. The clean symbol is the trade-side symbol.
5. The hunter symbol remains the reference symbol.
6. Missing data is not classified as divergence.
7. Raw divergence does not imply confirmation or trade permission.
8. No manual quality label suppresses raw anatomy collection.
