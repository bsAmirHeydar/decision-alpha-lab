# Package

```text
strategy_factory_market
```

The mirror implements:

- time and DST rules;
- session matching;
- tick and bar caches;
- synchronization;
- specification generations;
- telemetry.

## Role

Python is used for:

- deterministic unit tests;
- fixture generation;
- cross-language conformance;
- offline audit;
- research dataset validation.

Python does not own live bars, live new-bar identity, or broker specification truth.

## Parity principle

Any logic that affects event timing or runtime readiness must either be:

1. generated by MQL5 and consumed as an artifact; or
2. mirrored with golden fixtures proving semantic parity.

## Package version

Phase 03 updates the package to `0.3.0` and includes contracts, runtime, and market mirrors.

## Dependency discipline

The mirror uses only Python standard library and Phase 01 contracts. It deliberately avoids pandas in contract-level code so tests remain lightweight and deterministic.
