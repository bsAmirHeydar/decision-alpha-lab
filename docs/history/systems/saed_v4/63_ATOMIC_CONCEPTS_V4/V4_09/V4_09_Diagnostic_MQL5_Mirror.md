# Diagnostic MQL5 Mirror

## Definition

A non-order mirror for static authority, identity, latency, queue, lifecycle, and handoff checks.

## Identity and ownership

The artifact is owned by SAED V4-09, exact-versioned, content-addressed, and subordinate to V4-08 source truth and UCEE authority. It cannot rank or select treatments, allocate risk, activate runtime, send an order, or replace prospective and shadow evidence.

## Validation

Validation requires closed contracts, deterministic reproduction, source identity preservation, complete exposure where applicable, negative authority tests, and explicit classification of repository evidence versus external broker and MetaEditor evidence.

## Failure semantics

Unknown fields, hash mismatch, missing source binding, invalid range, or authority escalation fail closed and emit a source-bound quarantine record. No implicit repair is permitted.
