# SAED V4-17 Phase Delivery

This directory is the implementation dossier for SAED V4-17 Causal Mechanism Discovery. It contains the authority boundary, immutable V4-16 input contract, variable and environment registries, graph constraint language, synthetic benchmark, association baseline, temporally constrained graph discovery, structural equations, invariant-mechanism diagnostics, identification audits, negative controls, hidden-confounder sensitivity, transport diagnostics, tournament, checkpoint registry, replay, integrity, testing, limitations and V4-18 handoff. All evidence is deterministic synthetic reference evidence and is not a real causal or production claim.

The review sequence begins with the authority boundary and evidence classification. Reviewers then verify the V4-16 hash binding, closed variable identities, environment assignment, temporal tiers, required and forbidden edges, acyclicity, negative-control isolation and the synthetic-only watermark. The association baseline must remain reproducible before any challenger result is considered. Conditional association, structural equations, invariant mechanisms and orthogonal scores are diagnostics only. Back-door and front-door compatibility do not constitute identification. Hidden-confounder sensitivity, environment permutation, edge reversal and transport overlap must remain visible even when the reference tournament selects a champion.

Every checkpoint is immutable, non-production and incapable of asserting real causality, ranking treatments, selecting treatments, allocating risk, signing promotion, compiling runtime, activating runtime or sending orders. The V4-18 handoff is narrow and read-only. MetaEditor compilation, real-data replication, protected evaluation, prospective paper, shadow, micro-live and live evidence remain external gates.
