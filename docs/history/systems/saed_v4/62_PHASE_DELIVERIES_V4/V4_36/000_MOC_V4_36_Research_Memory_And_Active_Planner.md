# V4-36 Research Memory and Active Planner

## Mission

Create a sovereign, append-only research memory that preserves positive and negative knowledge, exposes contradictions and evidence gaps, and produces deterministic budgeted research agendas for explicit human review. The phase prevents repeated failed work without turning the planner into an autonomous execution authority.

## Architecture

The implementation contains upstream V4-35 binding, a twenty-clause constitution, immutable memory and evidence registries, semantic fingerprints, supersession links, hash-chain and Merkle integrity, negative-knowledge preservation, claim and contradiction state, deterministic retrieval, evidence-gap coverage, budget/risk controls, value-of-information scoring, protected exploration and replication floors, prerequisite-aware selection, wave scheduling, three-role governance, independent challenge, evidence certificate and bounded V4-37 handoff.

## Navigation

The delivery corpus contains 130 detailed delivery notes and 126 atomic concept notes. Code, tests, schemas, golden and negative fixtures, MQL5 static mirrors, QA, inventory, index and SHA-256 ledger are all part of the patch.

## Authority

The planner may propose and rank research. It cannot launch experiments, select treatments, allocate capital, mutate UCEE, compile runtime, submit orders or authorize production. All schedules are explicitly marked NOT_EXECUTED.
