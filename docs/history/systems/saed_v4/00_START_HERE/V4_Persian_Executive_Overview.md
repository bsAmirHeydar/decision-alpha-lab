# نمای کلی فارسی SAED V4

هدف V4 ساخت مدلی نیست که فقط پیش‌بینی دقیق‌تری بدهد. هدف ساخت یک مؤسسه تحقیقاتی نرم‌افزاری است که بتواند هر کانتکس را عمیق بفهمد، تمام ستاپ‌های معتبر را در یک فضای محدود بسازد، مسیر و هزینه اجرای آن‌ها را بازسازی کند، مدل‌های ساده و پیشرفته را رقابت دهد و نتیجه جذاب ولی جعلی را قبل از رسیدن به سرمایه نابود کند.

## تعریف یادگیری عمیق در این معماری

یادگیری عمیق فقط Deep Learning نیست. سیستم باید پنج عمق را هم‌زمان داشته باشد:

1. عمق معنایی: درک آناتومی، lifecycle، reference و روابط کانتکس.
2. عمق زمانی: tick، event، bar، session، cycle و higher timeframe.
3. عمق تصمیم: مقایسه کامل Trade، Skip، Abstain و Treatmentهای مختلف.
4. عمق علمی: کنترل تعدد آزمون، leakage، انتقال، عدم قطعیت و replication.
5. عمق عملیاتی: fill، spread، slippage، capacity، portfolio و runtime parity.

## اصل نهایی

بزرگ‌ترین مدل برنده نیست.
