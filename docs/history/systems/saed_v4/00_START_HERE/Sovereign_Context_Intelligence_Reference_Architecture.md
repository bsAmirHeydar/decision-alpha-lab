# Reference architecture

SAED V4 is separated into six constitutional planes.

## 1. Truth plane

UCEE canonical Context, known-time event truth, bitemporal lineage, feature/view contracts and context lifecycle.

## 2. Intelligence plane

Digital twins, continuous-time encoders, multimodal representations, graph memory, causal hypotheses and Context-specific models.

## 3. Decision plane

Treatment DSL, constraint compiler, outcome cube, utility/risk objectives, ranking, set-valued selection, Skip and Abstain.

## 4. Scientific evidence plane

Nested walk-forward, complete trial/exposure universe, anytime-valid inference, hidden evaluation, red team and replication network.

## 5. Sovereign platform plane

Lakehouse, feature/sequence/graph/path stores, artifact graph, distributed compute, confidential evaluation, model registry, security and recovery.

## 6. UCEE operational plane

I12 promotion, I13 authority/fallback, I14 runtime parity, I17 portfolio and I18 qualification. SAED cannot bypass these gates.

## Authority principle

```text
AI may propose, estimate, rank, simulate and challenge.
AI may not redefine Context, expand risk, sign promotion, activate runtime or place orders.
```
