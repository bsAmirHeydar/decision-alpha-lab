# Ultimate anti-overfit scientific constitution

The system assumes every attractive result is guilty until it survives independent attempts to destroy it.

## Constitutional rules

1. No protected evidence is visible during design or adaptive search.
2. Every attempted idea, parameter change, chart inspection, prompt and agent proposal is part of the exposure universe.
3. Every treatment sibling remains inside the same opportunity cluster.
4. Every complexity increase must beat a simpler baseline on protected lower-bound utility.
5. Synthetic data may falsify but cannot positively promote.
6. Causal language requires an identification dossier and sensitivity analysis.
7. OOD, missing-view, stale calibration and unsupported actions fail closed.
8. Final evaluation is isolated, budgeted and bounded in information returned.
9. Material capital requires independent multi-lab replication and prospective evidence.
10. Production is immutable; learning creates a new challenger generation.

## Promotion score

```text
promotion_value =
  lower_confidence_economic_utility
  - multiplicity_penalty
  - transport_penalty
  - model_risk_penalty
  - complexity_penalty

```

A candidate with high backtest profit but unstable support, poor capacity, model concentration or unresolved red-team findings is rejected.
