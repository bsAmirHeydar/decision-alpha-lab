## Acceptance decision

Accepted as a deterministic, synthetic, research-only reference implementation. Internal immutable compilation and synthetic MQL5 semantic parity pass. Actual MetaEditor compilation, actual MT5 Terminal vector replay, cross-runtime state replay and Windows boundary evidence remain `PENDING_EXTERNAL`.

## Claim ceiling
