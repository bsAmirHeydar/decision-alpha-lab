# V4-23 Offline Policy Research

## Mission
V4-23 implements a bounded, deterministic and independently reproducible offline-policy research laboratory above immutable V4-22 evidence. It trains conservative tabular reference challengers, audits logged rewards and behavior support, performs multiple off-policy evaluations, applies hard action masks and safe projections, preserves the manual baseline, and emits a research-only certificate plus a narrow handoff to V4-24.

## Delivered capability
- Exact V4-22 intake verification and content-addressed lineage.
- Closed logged-trajectory, action, reward, behavior, support, CQL, IQL, sequence-policy, OPE, projection and budget contracts.
- Known-time and cluster-aware logged replay validation.
- Behavior-policy reconstruction with probability floors.
- Reward-component audit and action-mask compilation.
- Conservative Q-Learning, Implicit Q-Learning and sequence-policy reference challengers.
- Support diagnostics, effective sample size, clipped importance ratios and unsupported-mass controls.
- WIS, PDIS, FQE and doubly-robust OPE with deterministic bootstrap intervals.
- Safe projection toward observed support and the immutable behavior/manual baseline.
- V4-22 synthetic-path evidence used only as a veto and falsification channel.
- Complete trial, exposure and budget ledgers.
- Research-only certificate, replay receipt, model-risk review, security review and V4-24 handoff.

## Authority ceiling
This phase cannot promote a policy, compile a runtime, allocate capital, submit an order, learn online, mutate UCEE truth or claim real alpha. The selected identifier is a research challenger only. Skip, abstain, manual baseline, reject and quarantine remain valid terminal outcomes.

## Acceptance state
The local deterministic reference implementation, closed schemas, golden/negative/mutation tests, static MQL5 mirrors, Obsidian corpus and delivery ledgers are complete. Actual MetaEditor compilation, Python/MQL5 runtime parity, real external replication, prospective shadow evidence and production authorization remain explicitly outside this phase.
