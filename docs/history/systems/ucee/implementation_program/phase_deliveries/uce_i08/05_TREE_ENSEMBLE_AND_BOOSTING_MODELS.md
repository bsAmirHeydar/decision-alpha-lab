# Trees, Ensembles, and Boosting

Decision trees provide auditable nonlinear partitions. Random forests and extra trees provide variance-reduced nonlinear baselines. Gradient and histogram boosting provide stronger tabular references. XGBoost, LightGBM, and CatBoost are optional exact adapters with typed dependency evidence and deterministic single-worker defaults.

Tree depth, leaf support, estimator count, learning rate, feature subsampling, and class weighting are behavior-changing parameters. They belong in configuration identity and the complete trial ledger. Unbounded search is prohibited before UCE-I11 multiplicity accounting.

Impurity importance is never treated as causal evidence. It is paired with fold-aware permutation or ablation evidence and documented dependence bias. Exportability is recorded independently from predictive utility.
