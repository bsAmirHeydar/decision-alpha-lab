# Failure Modes, Residual Risks, and Handoff

Primary risks are weak action support disguised by flexible estimators, invalid propensity estimates, censoring misspecification, ranking metrics that do not survive portfolio constraints, quantile miscalibration in tails, sparse regime overfitting, and policy-learning terminology that obscures extrapolation.

The phase mitigates these risks with masks, support audits, effective sample size, censor-aware metrics, top-k economics, subgroup coverage, global fallback, abstention, and mandatory comparison reports. Residual risk remains because synthetic fixtures cannot prove real market edge.

UCE-I10 receives exact task contracts, trainer keys, output semantics, action/horizon/quantile ordering, support requirements, and golden vectors. Deep multi-view models must beat these advanced tabular/task baselines under the same evidence gates.
