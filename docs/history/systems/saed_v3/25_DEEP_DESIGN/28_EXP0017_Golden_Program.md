# Objective

Define the first end-to-end implementation proving that the institutional architecture can transform an immutable EXP0017 context occurrence into a finite treatment tournament, adversarial evidence dossier and bounded runtime handoff.

## Capability tier

**Core Production**

# Non-negotiable principles

- EXP0017 is an infrastructure and scientific-method pilot, not assumed alpha.
- The context doctrine, known-time semantics and occurrence identity are frozen upstream.
- Payoff profiles and entry mechanisms are predeclared before protected outcomes are opened.
- All sibling treatments share opportunity-cluster identity and remain in the evidence ledger.
- Fixture success cannot satisfy prospective or production gates.

# Reference architecture

- Input package binds EXP0017 context version, F-counting anatomy, intermarket views, lifecycle and freshness.
- Candidate lattice combines P1–P5 payoff profiles with compatible breakout, market and pullback/limit mechanisms.
- Canonical initial universe uses constrained stop/exit families to isolate entry and payoff effects.
- Outcome cube replays bid/ask path, fills, expiry, slippage, stops, fixed destinations and trails.
- Baseline ladder proceeds manual → unconditional → classical → ranking → survival/distributional → governed challengers.
- Independent red team reconstructs folds, economics, multiplicity and transport before promotion.
- Winner, if any, passes prospective paper and UCEE I12–I18 handoff without special-case core changes.

# Algorithms and decision logic

- Freeze candidate compatibility before generating outcome labels.
- Use one row per occurrence-treatment and one cluster per occurrence across all folds.
- Run profile-specific objectives: hit-rate constrained P1/P5, convex-tail P2/P3, trend-capture P4.
- Estimate fill hazard separately from conditional outcome for limit and trigger entries.
- Compare fixed versus trailing exits with path-aware replay and captured-tail metrics.
- Apply purged nested walk-forward, full trial ledger, nulls, cost/delay stress and best-component removals.
- Generate a signed promotion dossier only if prospective evidence and practical capacity survive.

# Data, role and lineage controls

1. Raw, canonical, feature, outcome, training, calibration, selection-validation, locked-final, prospective, shadow and live roles are distinct.
2. Human, model, agent, dashboard and report access to protected evidence is recorded in the exposure ledger.
3. Revisions create a new artifact and never rewrite decision-time evidence.
4. Cross-fold preprocessing, tokenization, graph construction, feature selection and model selection are prohibited.
5. Trial, candidate, failure, retry, prune, timeout and waiver records remain immutable.

# Measurement system

- Independent occurrence count and cluster balance.
- Utility and calibration by payoff/entry pair.
- Fill hazard, missed opportunity and adverse selection.
- Convexity, hit-rate, trend-capture and tail metrics by profile.
- Selection stability, multiplicity and transport results.
- Manual-to-AI incremental attribution.

Metrics are segmented by time, symbol, context, regime, payoff profile, entry mechanism, broker/economics profile, support bucket and evidence class. Aggregates may not hide unstable subgroups.

# Authority boundary

- Research components propose and estimate; they cannot sign promotion.
- AI agents cannot alter context truth, data roles, protected evidence, risk limits, runtime generations or live authorizations.
- Policies remain bounded by UCEE I12 admission, I13 authority/fallback, I14 compilation, I17 risk/portfolio and I18 release qualification.
- Unsupported, stale, incomplete, OOD, mismatched or corrupt paths resolve to Manual, Skip, Abstain, Reject or Quarantine.

# Acceptance checklist

- [ ] Exact upstream context hashes are bound.
- [ ] Finite universe and objectives are frozen.
- [ ] Outcome cube and folds pass lineage/known-time audit.
- [ ] All trials and exposures are retained.
- [ ] No promotion occurs without prospective and runtime qualification.

- Positive, negative, boundary, mutation and adversarial tests.
- Baseline, ablation, stress, transport and reproducibility reports.
