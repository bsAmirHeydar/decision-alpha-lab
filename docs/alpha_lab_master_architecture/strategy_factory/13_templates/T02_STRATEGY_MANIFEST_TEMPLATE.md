# Strategy Manifest Template

Use JSON in production. Declare strategy identity/version/status, thesis/null/kill criteria, adapter and known-time field, shared and specific feature lists, candidate entries/stops/exits and compatibility, labels/horizon, purged validation and anti-overfit suite, baseline/challenger models, and paper/live/risk configuration. Start from `lab/11_strategy_factory/examples/manifests/temporal_divergence.json`.
