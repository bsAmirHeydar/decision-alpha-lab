# Example — Deterministic ICT Execution Family

ICT concepts are admitted only as mechanical event and execution policies.

## Sequence

L-node sweep → FVG → IFVG/CISD → confirmation known time. Each object has exact candle and price rules; no post-hoc order block selection.

## Candidates

Market proxy, retracement to imbalance, sweep-extreme stop, opposite node target, fixed R, and time expiry.

## Controls

Sweep-only, displacement-only, generic breakout, session-matched random, and definition stability across coders. Narrative confluence is not a feature unless formalized.
