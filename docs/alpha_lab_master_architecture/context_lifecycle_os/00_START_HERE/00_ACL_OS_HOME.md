# ACL-OS Home

The Context Lifecycle OS is the governed path from an authored market Context to evidence-backed, immutable and continuously surveilled execution. This note is the canonical navigation root.

## Operating thesis

Alpha Lab must not repeatedly hand-wire data extraction, Setup generation, experiments, reports, promotion and runtime glue for each Context. Those are platform capabilities. A Context package supplies domain semantics and approved extensions; ACL-OS supplies the repeatable machinery.

## The three planes

1. **Knowledge and research plane:** doctrine, occurrences, features, human/AI Setup candidates, experiments, validation and experience.
2. **Lifecycle control plane:** identity, planning, state, policy, evidence, orchestration, reporting and entitlements.
3. **Runtime and security plane:** signed immutable bundles, a minimal trusted computing base, MQL5 parity, execution guards and continuous detection.

## Canonical lifecycle

`DRAFT_CONTEXT → SEMANTICALLY_VALIDATED → CONTEXT_COMPILED → REPLAY_VALIDATED → OCCURRENCE_DATASET_READY → SETUP_UNIVERSE_READY → BATCH_REGISTERED → RESEARCH_RUNNING → EVIDENCE_COMPLETE → STATISTICALLY_ELIGIBLE → RUNTIME_COMPATIBLE → PAPER_CHALLENGER → SHADOW_CHALLENGER → MICRO_LIVE_ELIGIBLE → CHAMPION → SUSPENDED/RETIRED`

## Authority rule

No state is inferred from a folder, model file, passing test, connectivity or score. Every transition requires exact evidence, a versioned policy decision, an authorized principal and an append-only event.
