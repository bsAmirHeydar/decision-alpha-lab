# SAED and UCEE Integration Map

ACL-OS orchestrates existing engines through versioned ports; it does not reimplement them.

## SAED authority

SAED retains Context digital twins, event models, representations, learning, causal reasoning, decision-focused research, uncertainty, interpretability, research governance, runtime qualification and surveillance algorithms.

## UCEE authority

UCEE retains Treatment compilation, outcome construction, datasets, trainers, search, promotion primitives, policy graphs, runtime compilation, portfolio economics and execution contracts.

## ACL-OS authority

ACL-OS owns intake, completeness, lifecycle planning, global identity/lineage, state transitions, extension governance, security enforcement, Batch sealing, evidence assembly, reports, memory and the unified operator interface.

## Adapter rule

ACL-OS exchanges immutable references and evidence through public adapters. It does not import private engine internals or infer engine state from files. Every adapter has golden contract, parity, failure and authority-boundary tests.
