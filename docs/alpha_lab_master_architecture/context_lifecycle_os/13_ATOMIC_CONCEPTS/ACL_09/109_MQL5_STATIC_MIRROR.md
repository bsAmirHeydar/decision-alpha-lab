# MQL5 Static Mirror

**Definition.** MQL5 Static Mirror is a bounded ACL-09 contract element used in governed memory admission or non-executing active research planning.

**Invariant.** It preserves source identity, validation semantics and authority denials. UNKNOWN and diagnostic isolation remain explicit.

**Failure.** Missing, ambiguous, incompatible or mutated material fails closed with a registered reason code.

**Non-claim.** This concept does not prove alpha, authorize research execution, promote a candidate, submit an order or activate capital.
