# Technical Owner

## Definition

Technical Owner is a bounded ACL-01 concept used by the repository identity, registry, locator, compatibility, migration or lineage control plane. It must be represented by a versioned machine contract or a stable policy entry; prose alone is not authoritative.

## Invariant

The concept cannot grant live-order submission or capital activation. Missing, ambiguous, unregistered or integrity-invalid values fail closed with stable reason codes.
