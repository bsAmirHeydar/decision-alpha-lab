# Pilot Contract Binding

## Definition

A deterministic ACL-15 concept used to register the ACL-14 reference package, preserve its exact evidence status and close the lifecycle without execution or capital authority.

## Invariant

This concept cannot invent pilot outcomes, convert reference design into prospective evidence, bypass validation/promotion, mutate closed history or create runtime, order or capital authority.

## Verification

Covered by direct tests, ACL-14 regression, registry validation, event/provenance replay and delivery integrity checks.
