# Migration Dashboard and Status Reporting

The dashboard reports counts by state, family, owner, risk, parity status, open ambiguity, active legacy consumer, quarantine age and deletion eligibility. It is evidence, not authority. Status changes are derived from signed migration packets, not manually edited percentages.
