# Controlled Deletion Standard

Deletion requires all of the following: canonical successor or archive-only decision; full mapping; zero active references; compile/test/replay success; owner and independent reviewer approval; baseline and quarantine hashes; rollback tag; documentation update; completed quarantine period; and a signed deletion eligibility record.

Never delete unknown files, evidence, fixtures, decision logs, manifests, source-authority documents or unresolved divergent implementations.
