# Artifact Ordinal

## Definition

The deterministic one-based position of an artifact in the sorted baseline path sequence.

## Invariants

It is not a persistent domain identity and must not be used as a Context or Setup ID.

## Evidence and use

Supports coverage audits and stable CSV review.
