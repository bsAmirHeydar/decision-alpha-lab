# Metadata-Only Scan

## Definition

The scan mode used for binary or otherwise non-text artifacts.

## Invariants

No semantic content conclusion may be produced.

## Evidence and use

Records path, size, hash and lineage while preserving binary semantics as UNKNOWN.
