# Treatment Package Target

Treatments own entry references, protective references, cancellation, expiry and management rules. Treatment packages are versioned separately from Setups so the same Setup can be evaluated under multiple frozen treatments without semantic duplication.

Execution adapters translate an authorized treatment instruction. They do not alter the treatment or Context.
