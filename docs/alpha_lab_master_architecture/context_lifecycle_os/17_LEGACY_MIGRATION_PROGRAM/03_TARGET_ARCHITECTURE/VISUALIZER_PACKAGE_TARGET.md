# Visualizer Package Target

Visualizers consume immutable domain events and emit object specifications. They may not be a hidden signal engine.

A visual contract includes source identity, anchor time, anchor price, ownership prefix, update policy, delete policy, redraw policy, restart behavior, timeframe behavior and style registry. Object IDs are deterministic and instance-safe.
