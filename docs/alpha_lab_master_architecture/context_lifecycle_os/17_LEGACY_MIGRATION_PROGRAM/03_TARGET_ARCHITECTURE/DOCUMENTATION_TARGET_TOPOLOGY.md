# Documentation Target Topology

Canonical doctrine and architecture live in master-architecture namespaces or the domain package. Generated source cards, atomic concepts and canvases are marked derived and rebuilt from canonical documents. Experiment documents remain source evidence until migrated, then receive a status and `canonical_successor` link.

Redirect stubs are retained for renamed high-traffic pages during the deprecation window. A stub must not duplicate the canonical body.
