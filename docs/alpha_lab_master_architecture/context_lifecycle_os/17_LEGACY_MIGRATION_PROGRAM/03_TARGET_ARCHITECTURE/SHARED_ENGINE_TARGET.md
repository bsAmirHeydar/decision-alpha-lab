# Shared Engine Target

Shared engines are admitted only after at least two consumers have documented equivalent semantics or explicitly parameterized variance. Candidate engines include time/session/DST, closed-bar mapping, reference lifecycle, divergence primitives, object ownership, event identity, reason codes and configuration hashing.

Premature extraction is prohibited. If two implementations differ in wick/close semantics, equal-high handling, consumed-reference policy, current-bar access or session boundaries, those differences remain explicit variants.
