# Visual Parity

Visual parity compares domain anchors rather than screenshots alone: source event, bar time, price, line start/end, object ownership, style, persistence and deletion behavior. Screenshot review is supplementary.

A change in line endpoint from the confirming bar high/low to the signal-time high/low is semantic and requires an approved variant, even when the signal decision is unchanged.
