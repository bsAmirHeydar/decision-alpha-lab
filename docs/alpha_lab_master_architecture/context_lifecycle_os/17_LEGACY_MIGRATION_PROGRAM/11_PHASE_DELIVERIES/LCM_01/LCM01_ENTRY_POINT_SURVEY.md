# LCM-01 Entry-Point Survey

Entry-point candidates include MQL5 compile units, Python command modules and Python test entry modules. The reference survey reports 1,858 candidates.

Entry-point status is a static candidate only. It does not prove that a file is installed, loaded on a chart, invoked in CI, or active in an operational environment.
