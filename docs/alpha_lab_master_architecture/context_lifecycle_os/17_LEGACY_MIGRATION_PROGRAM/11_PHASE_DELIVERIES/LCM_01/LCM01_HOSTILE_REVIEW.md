# LCM-01 Hostile Review

Hostile review targets false resolution from filename similarity, generated-document authority inflation, comments mistaken for active capabilities, dynamic registration hidden from static scans, preprocessor aliasing, parse failures, path traversal, Windows collisions and output partiality.

The review also checks that inventory labels remain candidates and that no order or capital authority is inferred from API-token presence.
