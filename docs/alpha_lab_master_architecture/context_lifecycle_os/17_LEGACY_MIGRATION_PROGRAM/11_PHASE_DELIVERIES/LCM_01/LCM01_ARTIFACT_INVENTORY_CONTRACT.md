# LCM-01 Artifact Inventory Contract

The artifact inventory contains exactly one row for every one of the 38,595 baseline records. Each row records ordinal, root-relative path, case-folded path, namespace, filename, extension, language candidate, media family, size, SHA-256, source-layer lineage, family candidate, semantic-role candidate, generated-likelihood candidate, scan status and unknown reasons.

Candidate labels are not semantic approvals. The inventory is a complete observation surface for LCM-02, not a canonical domain registry.
