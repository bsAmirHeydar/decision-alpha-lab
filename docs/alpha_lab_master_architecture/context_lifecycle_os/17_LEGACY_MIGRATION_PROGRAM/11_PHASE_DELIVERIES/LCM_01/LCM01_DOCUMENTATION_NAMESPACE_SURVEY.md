# LCM-01 Documentation Namespace Survey

The survey fingerprints 121 documentation namespaces using relative-path/hash maps. Namespaces are candidate-classified as generated/derived, archive/release history, canonical-architecture candidate, domain-documentation candidate or unknown.

Volume and path location do not establish authority. Generated trees cannot outvote canonical doctrine merely by containing more files.
