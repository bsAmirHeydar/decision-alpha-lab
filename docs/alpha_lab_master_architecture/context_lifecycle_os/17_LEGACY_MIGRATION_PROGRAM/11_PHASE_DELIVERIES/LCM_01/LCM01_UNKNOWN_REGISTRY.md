# LCM-01 Unknown Registry

Unknowns include inherited LCM-00 blockers, unresolved/ambiguous edges, path escapes, parse failures, binary semantics, unknown semantic roles, edge truncations, dynamic registration reachability and preprocessor alias reachability.

UNKNOWN is neither PASS nor absence. It cannot authorize merge, movement, cutover, quarantine, deletion, runtime or capital.
