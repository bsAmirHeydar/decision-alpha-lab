# LCM-01 Authority Permit

The phase action is closed to `LCM01_RUN_FORENSIC_REPOSITORY_SURVEY`. The permit binds the baseline identity, baseline manifest digest, source handoff digest, issuer, issuance time and claim ceiling.

Network access, secret access, source movement, source deletion, semantic refactoring, runtime authority, live-order submission and capital activation are false. A permit with any elevated capability is invalid even when all other fields and digests are correct.
