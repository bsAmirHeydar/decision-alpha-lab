# LCM-01 Family-Candidate Classification

Repository-specific path evidence is used to propose family candidates such as ACL-OS, Strategy Factory, EXP0015–EXP0019, Flag/NDS/Hook/Zone, M-series, execution E-series, Astro, research, documentation, registry and root-release history.

The classifier outputs confidence basis points and never merges families. A path candidate is a queueing aid for LCM-02 ownership work, not proof that all files under a named experiment implement one Context.
