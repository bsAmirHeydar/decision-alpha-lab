# LCM-01 Order-API Surface

Order-related static indicators appear on 38 baseline paths. These paths are security-sensitive candidates for later authority classification and execution separation.

LCM-01 does not call, wrap, disable or rewrite order APIs. It does not determine whether a hit is dead code, a test, a comment, a compatibility shell or an active broker path.
