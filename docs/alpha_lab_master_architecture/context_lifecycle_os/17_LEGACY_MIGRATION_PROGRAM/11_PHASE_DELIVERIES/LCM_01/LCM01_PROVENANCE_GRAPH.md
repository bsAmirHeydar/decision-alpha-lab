# LCM-01 Provenance Graph

The provenance graph connects the LCM-00 baseline and handoff to the LCM-01 survey identity, summary and LCM-02 handoff. It explicitly records that source mutation, semantic refactor and authority escalation did not occur.

Every downstream classification record must be able to trace back to this survey and ultimately to a byte-exact LCM-00 artifact.
