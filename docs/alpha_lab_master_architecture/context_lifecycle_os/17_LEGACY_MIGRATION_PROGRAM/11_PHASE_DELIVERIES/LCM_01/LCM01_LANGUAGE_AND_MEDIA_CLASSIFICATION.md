# LCM-01 Language and Media Classification

Extension-based language and media classification separates source text, structured text, documentation text, packaged binaries and unknown media. Binary files receive metadata-only scan status.

Extension classification is observational. A `.md` file is not automatically canonical doctrine, a `.mq5` file is not automatically active runtime, and a `.json` file is not automatically a contract.
