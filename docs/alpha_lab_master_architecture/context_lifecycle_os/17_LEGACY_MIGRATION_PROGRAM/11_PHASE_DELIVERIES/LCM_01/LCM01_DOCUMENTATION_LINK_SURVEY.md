# LCM-01 Documentation Link Survey

Markdown links and Obsidian wikilinks are scanned against the exact baseline path set. Relative parent traversal is normalized inside the repository; only traversal beyond the repository root is a path escape.

The reference survey records 94,234 documentation edges. A resolved link proves path existence, not that the linked document is authoritative or semantically current.
