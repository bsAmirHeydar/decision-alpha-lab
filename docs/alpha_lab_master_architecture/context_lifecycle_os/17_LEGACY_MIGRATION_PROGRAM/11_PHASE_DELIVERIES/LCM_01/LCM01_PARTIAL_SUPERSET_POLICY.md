# LCM-01 Partial-Superset Policy

Namespace pairs may be reported when a substantial exact relative-file overlap suggests a superset relationship. The reference survey reports 0 qualifying candidates under the frozen threshold.

Partial overlap never proves semantic replacement. LCM-02 and LCM-12 must resolve authority and link impact before any documentation consolidation.
