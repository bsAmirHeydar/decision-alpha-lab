# File Ledger Boundary

## Purpose

Read and mutation capabilities are inventoried because files can become hidden entitlement or reconciliation authority.

## Engineering contract

LCM-10A grants no entitlement status to a ledger. LCM-10B must define the boundary before any adapter consumes it.

## Non-compensatory boundary

This artifact creates no promotion, runtime, live-order or capital authority. Missing evidence remains UNKNOWN, all legacy source bytes remain unchanged, and downstream use is restricted by the digest-bound LCM-10A handoff.
