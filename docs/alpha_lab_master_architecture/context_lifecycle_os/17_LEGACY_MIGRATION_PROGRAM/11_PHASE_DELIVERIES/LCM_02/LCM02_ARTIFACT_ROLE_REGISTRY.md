# Closed Artifact Role Registry

Twenty roles separate context, setup, treatment, visualization, adapters, primitives, research, diagnostics, platform, generated knowledge, evidence, release metadata, governance, contracts, tests and unknowns.

## Invariants

- UNKNOWN is blocking.
- Classification is not semantic approval.
- No move, delete, refactor, merge, cutover, runtime, order or capital authority is created.

## Verification

The machine package, closed registries, tests and output manifest must preserve these statements exactly.
