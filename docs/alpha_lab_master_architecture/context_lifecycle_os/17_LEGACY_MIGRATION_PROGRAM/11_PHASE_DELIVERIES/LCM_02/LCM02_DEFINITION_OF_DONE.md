# Definition of Done

All surveyed artifacts have one disposition; active items are role-bound or blocked; security paths isolated; generated docs non-canonical; platform protected; no destructive action.

## Invariants

- UNKNOWN is blocking.
- Classification is not semantic approval.
- No move, delete, refactor, merge, cutover, runtime, order or capital authority is created.

## Verification

The machine package, closed registries, tests and output manifest must preserve these statements exactly.
