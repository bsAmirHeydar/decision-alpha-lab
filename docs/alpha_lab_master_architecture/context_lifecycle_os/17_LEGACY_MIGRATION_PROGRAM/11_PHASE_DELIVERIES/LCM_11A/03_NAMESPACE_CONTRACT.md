# ALV1 Namespace Contract

Canonical visual IDs use the ordered identity tuple: namespace version, owner, subsystem, instance, chart, symbol, timeframe, event, role and visual token. Random suffixes and global unowned prefixes are forbidden. Cleanup uses the exact owner/subsystem/instance/chart prefix and must never delete outside that scope.

Observed legacy names are evidence only. High-risk static or unproven names become LCM-11B remediation blockers; they do not invalidate the deterministic canonical contract.
