# Visual Inventory Protocol

A visual surface is one chart-object creation site, indicator-buffer binding or bounded report projection. Each record contains source path and digest, line, function, object type, observed name expression, chart scope, owner, subsystem, source-event binding, active status and blockers. Test and fixture surfaces remain inventoried but are excluded from active acceptance counts.

Discovery is lexical and deterministic. It does not compile, execute, move or edit legacy source. Shared primitives are represented as caller-bound event consumers rather than being assigned invented domain semantics.
