# Anchor Contract

Every visual surface declares anchor kind, chart-projection scope, source-candle semantics, availability time, first and second time/price anchors, extension behavior and host-chart dependency. Pixel-corner panels are explicitly non-market-time anchored. Indicator buffers are series-index anchored. Report projections are input-digest anchored.

Any current-bar or runtime ambiguity is blocking. A drawing cannot be described as closed-bar confirmation unless its availability evidence proves that state. Non-host symbol projections require explicit chart scope in LCM-11B.
