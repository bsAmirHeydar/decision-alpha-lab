# Collision and Isolation Protocol

The canonical namespace is simulated under same-chart different-instance, different-chart same-instance, same-symbol different-timeframe and same-scope different-event scenarios. Canonical collision tolerance is zero. Observed legacy collision groups are retained as explicit remediation evidence.

LCM-11A proves the namespace design, not runtime multi-chart parity. Runtime isolation, restart and history-reload evidence belong to LCM-11B.
