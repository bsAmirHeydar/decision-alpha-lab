# Variance Adjudication

Any mismatch must be classified as implementation defect, legacy defect, approved semantic amendment, fixture defect, or UNKNOWN. No mismatch exists in the accepted pilot. Future corrections cannot be hidden in adapter code and require an ADR plus a new version.
