# LCM-00 Program Constitution

The constitution binds the program identity, state machine, claim ceiling, UNKNOWN semantics, amendment discipline, and destructive-action prohibition. A lower-level script, developer convenience, or migration deadline cannot override it.

Any proposed exception requires an ADR and cannot authorize deletion before LCM-15.
