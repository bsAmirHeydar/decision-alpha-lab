# LCM-01 Entry Checklist

- Baseline package verifies.
- Operational Git tag exists.
- No baseline path changed.
- Patch additions are declared.
- Program owner assignment is resolved or the survey runs explicitly under reference-only authority.
- Host-local and ignored-file gaps are listed.
- No move, deletion, refactor, or cutover is staged.
