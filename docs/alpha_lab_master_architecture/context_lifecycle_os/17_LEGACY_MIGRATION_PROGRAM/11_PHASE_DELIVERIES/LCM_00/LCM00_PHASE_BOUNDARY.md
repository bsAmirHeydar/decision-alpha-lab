# LCM-00 Phase Boundary

LCM-00 may observe, hash, classify baseline scope, record authority, rehearse content restoration, and publish a non-destructive handoff. It may not relocate, delete, merge, refactor, quarantine, cut over, execute orders, or activate capital.

The phase input is the repository after the LCM implementation-program patch. The phase output is an additive governance and evidence package. Every source path present at phase entry must remain byte-identical.
