# LCM Definition of Done

A migrated identity is complete only when it has canonical ID and owner, package contract, known-time definition, legacy mapping, source hashes, golden cases, event traces, parity report, ACL-OS binding, documentation, security classification, cutover and rollback plan, quarantine status and zero hidden authority.

Program closure additionally requires clean-clone validation, all active consumers resolved to canonical artifacts, no unresolved active legacy path, approved deletion ledger, preserved source evidence and a residual-risk report.
