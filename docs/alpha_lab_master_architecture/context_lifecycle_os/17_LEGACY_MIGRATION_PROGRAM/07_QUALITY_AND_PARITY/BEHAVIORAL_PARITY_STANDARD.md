# Behavioral Parity Standard

Parity is evaluated by dimension. Hard dimensions require exact equality unless an owner-approved correction version exists. Soft dimensions require a declared tolerance and materiality rationale.

Hard dimensions include known-time, signal identity, direction, state transitions, invalidation, expiry, consumed-reference behavior, no-trade, reason severity and execution authority. Visual style and performance may use bounded tolerances, but anchor time/price and object ownership remain hard.
