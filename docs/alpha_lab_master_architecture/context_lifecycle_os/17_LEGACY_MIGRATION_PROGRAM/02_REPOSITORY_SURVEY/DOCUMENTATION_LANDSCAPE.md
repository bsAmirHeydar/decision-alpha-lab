# Documentation Landscape

## Authority classes

1. Master architecture and accepted ADRs.
2. Domain normative specifications and owner-decision freezes.
3. Implementation and test evidence.
4. Generated Obsidian projections, source cards and atomic concepts.
5. Patch readmes, historical reports and archived material.

## Confirmed duplicate namespace candidates

The initial survey found byte-identical copies for:

- `docs/ai_algorithm_engineering_os` and its master-architecture copy;
- `docs/strategy_factory` and its master-architecture copy;
- `docs/strategy_factory_v2` and its master-architecture copy.

These are deletion candidates only after link, locator and external-reference analysis. The UCEE pair is not identical and requires reconciliation.

## Generated knowledge

Large namespaces such as `docs/obsidian_deep` and atomic-concept projections are valuable navigation artifacts but must be marked generated or derived. They may not override canonical doctrine.
