# Domain Family Portfolio

## Protected platform

ACL-OS, Strategy Factory, SAED and UCE/UCEE are platform/kernel assets. They supply contracts, orchestration, evidence and runtime custody. They are not migrated as legacy Context families.

## Domain migration families

| Family | Initial posture | Principal risk |
|---|---|---|
| EXP0015 Intermarket Time Divergence | early pilot candidate after ownership review | time/session semantics |
| ICT and Structural Nodes | shared primitive candidate | implicit structural definitions |
| M0001–M0007 | medium wave | scattered doctrine, state and visual coupling |
| EXP0018 Daye Trader | medium-high wave | multi-timeframe, sessions, drawing lifecycle |
| EXP0016 Intermarket Execution | high wave | execution and broker coupling |
| EXP0017 Cycle Group | high wave | reference lifecycle, statistics and execution links |
| EXP0019 Faerie Protocol | very high wave | weekly/session relations, quota, M1 ordering, paper path |
| FlagCounting/NDS/Hook/Zone | critical wave | very large stateful codebase, file I/O, drawing and order paths |
| E-series Execution | final authority wave | direct order APIs and treatment coupling |
| Astro research/execution | separate high-risk lane | file-fed features and order shell |
| Research experiments | archive or research-package lane | not necessarily a trading Context |

Wave assignments are provisional until LCM-02 confirms ownership and active reachability.
