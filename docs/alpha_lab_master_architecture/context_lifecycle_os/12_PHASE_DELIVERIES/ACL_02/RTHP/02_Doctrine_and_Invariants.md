# 02 Doctrine and Invariants

The invariant of RTHP is an asymmetric touch state between corresponding symbol-local cycle levels. The two compared cycles may be sequential or non-sequential, but both must be defined by a versioned cycle contract.

Cycle hours, lookback, cycle pairings, and confirmation timeframe are versioned configuration. They may change only through an explicit semantic amendment; the cross-symbol divergence invariant does not change silently.
