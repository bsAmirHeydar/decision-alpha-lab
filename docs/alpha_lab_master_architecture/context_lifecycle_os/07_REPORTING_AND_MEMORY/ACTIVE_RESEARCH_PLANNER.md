# Active Research Planner

ACL-09 compiles bounded research proposals from admitted non-baseline, non-diagnostic memory entries. It uses a closed question registry, duplicate suppression, deterministic priority scoring and fixed proposal/cost caps.

A selected proposal remains `SELECTED_PROPOSAL_NOT_AUTHORIZED`. It is not scheduled or executed. Human approval, a separate permit, a new frozen batch and downstream lifecycle gates remain mandatory.
