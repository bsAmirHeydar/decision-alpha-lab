# Obsidian Projection Standard

Markdown is a deterministic human projection of machine artifacts. Generated pages carry `generated-reference` status, stable Report ID and explicit claim ceiling. Each candidate page links to a machine report digest and displays decision and gate states without reinterpretation.

Generated Markdown is never the operational source of truth and must not be hand-edited. Durable human annotations use separate notes linked to the generated artifact and must declare author, date and authority.
