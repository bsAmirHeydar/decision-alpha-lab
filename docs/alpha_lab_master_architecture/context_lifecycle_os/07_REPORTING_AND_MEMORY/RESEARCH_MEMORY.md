# Research Memory

Research Memory is an ACL-09 responsibility. ACL-08 only emits immutable experience candidates and duplicate fingerprints. No ACL-08 artifact is admitted to memory automatically.

Admission must verify provenance, security classification, semantic identity, duplicate status, retention policy and poisoning defenses. Memory must preserve failures and unknowns, not merely successful narratives.
