# ACL-03 Context Compiler and Onboarding

Consumes only an ACL-02 Context package that is semantically validated by ACL-00 authority. It will compile detector IR, occurrence identity, known-time guards, schemas, adapters, golden replay, generated documentation and onboarding evidence. It must not broaden Context semantics or treatment authority.
