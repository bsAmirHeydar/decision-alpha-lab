# ACL-08 — Reporting and Experience

## Mission

Convert the complete ACL-07 validation package into reproducible machine reports, controlled audience views, deterministic Obsidian projections and non-promotional experience candidates. Preserve every validation decision and reason code exactly.

## Owned responsibilities

- ACL-07 input integrity and authority checks.
- Closed report policy and report-block registry.
- Batch, executive and candidate reports.
- Internal, executive and external restricted views.
- Redaction verification.
- Experience, negative-knowledge and unknown-evidence packages.
- Optional material report diff.
- Event ledger, provenance, receipt and atomic publication.
- Immutable `ACL08_TO_ACL09` handoff.

## Explicit non-goals

ACL-08 does not re-run validation, infer alpha, ingest durable memory, resolve duplicates, prioritize experiments, modify doctrine, promote candidates, submit orders or activate capital.

## Definition of Done

The reference package must replay deterministically, preserve all twelve ACL-07 decisions, keep one diagnostic candidate non-selectable, classify four baselines and seven insufficient-evidence candidates correctly, redact restricted views, emit no authority and pass direct plus ACL-07 regression tests.
