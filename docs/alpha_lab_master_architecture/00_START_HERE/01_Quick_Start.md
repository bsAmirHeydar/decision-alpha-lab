## Canonical rule

Before implementing a new trading idea, decide which artifact is being created:

```text
Market doctrine
Context specification
Context implementation design
Context engine
Human setup
AI treatment search
Experiment
Evidence bundle
Capital policy
Runtime generation
Monitoring contract
```

A document or Engine must not silently perform the authority of another layer.
