# Golden Context Proof and Factory Definition of Done

## Three proofs

1. RTHP proves multi-symbol synchronization, stale handling, closed M1 bars and research activation.
2. A single-symbol Momentum or Mean-Reversion Context proves the shared engine is not specialized for RTHP.
3. A path-dependent MQL5 Context proves compiled runtime, restart, management and terminal parity.

## Kernel-change rule

Golden Context two and three must reach evidence without modifying shared engine semantics. New bounded extension implementations are allowed through existing ports.

## Factory done

The Factory is done when all three Contexts are created from authored packages, generated deterministically, operated by the same CLI and lifecycle, reproduced in a clean clone and evaluated through the same evidence model.

## Economic result

A Golden Context may be rejected. Trustworthy rejection still proves the platform. Acceptance cannot be forced by changing the Context after protected evidence is observed.
