# Normative, Generated, Operational and Historical Documents

## Normative

Architecture, standards, contracts, policies, ADRs and runbooks that govern behavior. Authored and reviewed.

## Generated

Schema references, CLI references, Context projections, state diagrams and registry indexes derived from machine sources. Carry source digests and are not hand-edited.

## Operational

Current procedures, environment instructions, incident playbooks and supported workflows. Versioned and tested where executable.

## Historical

Old phase reports, patch instructions, superseded designs and preserved evidence. Searchable through history or archive but clearly non-authoritative.

## Classification

Every documentation file receives one class and succession status during UC-01 and UC-02.
