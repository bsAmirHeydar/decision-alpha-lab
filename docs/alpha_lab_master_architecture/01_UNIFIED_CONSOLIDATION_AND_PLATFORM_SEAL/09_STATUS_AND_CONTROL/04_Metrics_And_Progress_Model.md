# Metrics and Progress Model

## Structural metrics

Root-file count, unclassified-file count, production files outside canonical root, duplicate canonical docs, broken links and unresolved package owners.

## Logical metrics

Capabilities with multiple active implementations, unexplained differential mismatches, active legacy imports, Context-specific shared-engine branches and missing preservation certificates.

## Mechanization metrics

Manual workflow steps, Context-specific CLI commands, hand-edited generated files, unresolved Wizard questions, compiler determinism and lifecycle transitions with missing evidence.

## Cutover metrics

Known consumers, migrated consumers, shim invocations, unresolved external consumers, terminal parity and Golden Context completion.

## Quality metrics

P0/P1 defects, mutation strength on critical modules, flaky tests, unknown evidence dimensions, clean-clone result and recovery drill result.

Metrics do not replace gates; they show direction and expose stalled work.
