# Recovery, Rollback, Incident and Disaster Drills

## Recovery levels

1. file and package restoration;
2. registry and state reconstruction;
3. generated artifact rebuild;
4. terminal and external environment restoration;
5. remote repository and artifact-store recovery.

## Rollback

Move and merge waves define preconditions, rollback command, data compatibility and forward-fix option. Destructive rollback is tested before deletion authority is granted.

## Incidents

Incidents have severity, affected authority, containment, evidence preservation, root cause, correction, regression test and requalification scope.

## Drill acceptance

A local copy test does not prove disaster recovery. The drill must match the claimed recovery boundary and verify restored behavior and identity.
