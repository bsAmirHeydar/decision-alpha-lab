# Security, Authority, Secrets and Supply Chain

## Authority

Capabilities are deny-by-default. Research, AI, Context compilation and documentation tooling cannot create order, broker or capital authority. Runtime bundles carry explicit entitlements and environment restrictions.

## Secrets

No credential is committed. Adapters request secrets through approved environment or secret-store ports. Logs, receipts and fixtures redact sensitive values while preserving auditability.

## Supply chain

Dependencies are locked, licensed, vulnerability-scanned and reproducible. Binary tools and MQL5 outputs record digests and producer environment. Generated code cannot execute unreviewed network or process-spawn behavior.

## Negative tests

The suite actively tests privilege escalation, path traversal, malicious manifests, schema confusion, unsigned artifacts, stale approvals and secret leakage.
