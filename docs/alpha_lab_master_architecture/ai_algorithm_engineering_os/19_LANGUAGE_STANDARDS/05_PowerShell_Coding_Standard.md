# PowerShell Coding Standard

Use `Set-StrictMode -Version Latest`, `$ErrorActionPreference = "Stop"`, quoted paths, `Join-Path`, explicit parameters, idempotent operations, clear exit codes, and no broad Git staging. Scripts should run from repository root or resolve their own location.
