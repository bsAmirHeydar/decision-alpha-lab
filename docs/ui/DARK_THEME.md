# Dark Theme System

The Quant Lab interface uses a dark-dark terminal style.

## Visual language

- Almost black background.
- Deep graphite panels.
- Cyan for selected/active evidence.
- Violet for experiment windows.
- Amber for warnings.
- Red/pink for failure, hunt, and danger.
- Green-cyan for pass/confirmed states.

## Interaction principle

Default overlays are quiet and low-opacity.

Hover and selection reveal detail.
