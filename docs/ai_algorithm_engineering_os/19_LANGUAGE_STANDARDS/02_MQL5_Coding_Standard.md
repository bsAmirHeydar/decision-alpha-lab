# MQL5 Coding Standard

Use include guards, explicit state ownership, checked platform calls, closed-bar semantics, documented series indexing, deterministic object names, symbol/time synchronization, and bounded redraw/history work.

Never use `StringToUpper/Lower` as value-returning functions. Do not assume `LongToString`. Research experts contain no order APIs. Compile target is the actual MetaEditor build with zero errors and reviewed warnings.
