# Cross-Language Base Standard

All languages follow explicit contracts, deterministic behavior, bounded mutation, stable serialization, observable failure, and tests. Language idioms may differ; domain semantics and data contracts may not.

Use formatters/linters where available, but tools do not replace design review. Public interfaces document units, time basis, null behavior, and errors.
