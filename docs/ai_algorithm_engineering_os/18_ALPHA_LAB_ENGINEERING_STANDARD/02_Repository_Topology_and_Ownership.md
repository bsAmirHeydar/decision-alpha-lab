# Repository Topology and Ownership

Decision Alpha Lab’s `lab/01` through `lab/10` directories are lifecycle stages, not storage conveniences. Artifacts move by promotion and linking, not by copying ambiguous truth.

## Ownership

- Observation owns facts, not mechanisms.
- Hypothesis owns falsifiable claims.
- Experiment owns method/config/result evidence.
- Validation owns robustness/OOS decisions.
- Production owns approved immutable contracts.
- Monitoring owns drift, incidents, and retirement evidence.
- Execution owns broker mechanics, not research meaning.
- Infrastructure owns reusable technical support, not domain rules.

Caches are disposable. Registries are canonical indexes. Generated outputs never replace source contracts.
