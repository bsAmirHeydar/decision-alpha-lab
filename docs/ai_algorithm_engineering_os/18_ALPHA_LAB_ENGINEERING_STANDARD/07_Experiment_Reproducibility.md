# Experiment Reproducibility Contract

A reproducible experiment freezes code version, config, data contract/version, sample period, seed, fold plan, metrics, baseline, and output locations. It provides one command to regenerate outputs and records environment/runtime versions.

If external data cannot be redistributed, store checksums, acquisition instructions, and lineage metadata.
