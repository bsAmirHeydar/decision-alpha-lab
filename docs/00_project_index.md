# Project Index — Decision Alpha Lab

This index connects the major ideas, experiments, validations, and execution families of the project.

---

## Purpose

Decision Alpha Lab exists to find market facts that remain meaningful under strict causal replay. A pattern is not enough. A backtest is not enough. A structural report is not enough. A claim must survive the question:

> Could the same decision have been made at that time, using only what was knowable then?

---

## Core research axis

The project no longer treats fixed windows as the primary x-axis. The x-axis is the sequence of structural events:

1. node formation,
2. node confirmation,
3. zone expansion,
4. revisit,
5. hunt or break,
6. event completion,
7. regime becoming knowable,
8. subsequent decision.

The y-axis is the current market state: reversal pressure, continuation pressure, ambiguity, and path quality.

---

## Official live hierarchy

| Level | Name | Valid use | Limitation |
|---|---|---|---|
| 1 | Classic sample report | Discovery and debugging | May sequence same-candle outcomes artificially. |
| 2 | Causal sample-batch report | Stronger research validation | Still starts from completed branch samples. |
| 3 | Atomic no-sample report | Official live-style validation | Slower and stricter, but closest to tradable logic. |
| 4 | Execution EA report | Trading model validation | Must include costs, stop/TP/trailing, fill policy. |

Official claims about H0004 and H0005 must now use level 3 or level 4.

## Hypotheses

### H0001 — Structural decision nodes

Question: are structural highs/lows different from random locations?

### H0002 — Node territory and revisit lifecycle

Question: do confirmed nodes continue to matter when revisited, and when are they consumed?

### H0004 — Regime memory

Question: do reversal and continuation regimes cluster beyond random ordering when measured by known-time batches?

Official status: classic sample reports showed strong inertia, but inflated it. Causal batching reduced the effect but it remained statistically meaningful. Atomic no-sample replay is the preferred contract.

### H0005 — Directional memory and execution

Question: can a known regime improve the next structural decision?

Official status: reversal appears to be a short reaction edge; continuation appears to produce larger paths, but old continuation PF was path-normalized and not a real trading PF. Main H5 must use atomic replay and explicit risk.

### H0007 — Flag counting / F1 start structure

Question: can the first flag start structure be counted mechanically from known-time structural nodes?

Official status: design lock. F1 is a protected-waist grammar object. The internal roof/floor between count node 1 and node 2 is only a trigger; final F1 confirmation requires breaking the main second roof/floor. No alpha or execution claim is made yet.

---

## Most important lessons

1. Same-candle regime labels are simultaneous.
2. A label is only useful after it is knowable.
3. Branch samples are dangerous if used as live decision objects.
4. Continuation without a real stop has no real R multiple.
5. Reversal and continuation must not be judged as one combined family.
6. Debug validators are useful only until their rules are promoted into the main Expert.
7. Every report must declare whether it is discovery, validation, or execution.
