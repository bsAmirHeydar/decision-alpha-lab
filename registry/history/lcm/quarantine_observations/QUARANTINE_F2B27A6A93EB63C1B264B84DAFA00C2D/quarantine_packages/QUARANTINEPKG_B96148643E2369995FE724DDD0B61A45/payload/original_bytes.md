# EXP0013 Astro Dashboard V12 - Clean Header, Minimize Mode, Cleaner Oscillator

This patch improves three user-facing areas:

## 1) Header cleanup
- clearer header text hierarchy
- explicit Symbol / TF / View line
- explicit Status and File line
- cleaner Broker / UTC line
- header should now be readable instead of overlapping

## 2) Minimize mode
- new MINIMIZE / EXPAND button
- minimized mode hides the cards and lower oscillator so the chart becomes visible
- header stays available so the dashboard remains controllable

## 3) Lower compact oscillator cleanup
- better spacing between metric names, numbers, buckets, and bars
- removed the extra sparkline junk after the bars
- cleaner visual layout

The stable in-place update behavior is preserved.
