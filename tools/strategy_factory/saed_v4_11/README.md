# SAED V4-11 Tooling

This directory contains the deterministic test runner, closed-contract validator, boundary guard, MQL5 static validator, Obsidian validator, independent golden reproducer, reference-bundle CLI wrapper, delivery validator and Windows MetaEditor compile helper for SAED V4-11.

The tooling proves local reference conformance only. It does not convert synthetic training, static MQL5 checks or local replay into real-corpus, distributed, prospective, runtime or production evidence.
