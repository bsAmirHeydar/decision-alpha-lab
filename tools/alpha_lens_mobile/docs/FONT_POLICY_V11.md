# FONT-POLICY-V11 — تغییر کامل فونت فارسی Alpha Lens

## تصمیم

در v11 فونت فارسی اپ از stack قبلی به یک stack جدید تغییر کرد:

```css
"Noto Sans Arabic",
"Noto Naskh Arabic",
"Segoe UI",
Tahoma,
Arial,
sans-serif
```

## چرا؟

نسخه قبلی به فونت‌هایی مثل `SF Pro Arabic`، `Vazirmatn`، `IRANSansX` و `Dana` اولویت می‌داد. روی بعضی دستگاه‌ها این فونت‌ها نصب نیستند و مرورگر به fallback نامناسب می‌افتد.

در v11 اولویت به `Noto Sans Arabic` و `Noto Naskh Arabic` داده شد که روی بسیاری از محیط‌های اندرویدی و مرورگرها رفتار نرم‌تر و پایدارتر دارند.

## محدودیت

برای حفظ آفلاین بودن و سبک بودن اپ، فونت فایل جداگانه bundle نشده است. این patch فونت‌فایل منتشر نمی‌کند و فقط font stack داخلی CSS را تغییر می‌دهد.

## هدف بصری

- فارسی نرم‌تر
- وزن کمتر و کمتر زمخت
- خوانایی بهتر در دارک مود
- ظاهر یکنواخت‌تر در کنترل‌ها، کارت‌ها، segmented controls و دکمه‌ها
