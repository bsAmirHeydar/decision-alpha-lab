# Alpha Lens Matrix — اپ آفلاین موبایل

این یک PWA آفلاین برای ماتریس نگاه بازار است:

- هوک صعودی
- رالی صعودی
- هوک نزولی
- رالی نزولی

در سه تایم‌فریم:

- 1H
- 10M
- 1M

برای هر سلول ثبت می‌کنی:

- Risk
- Reward
- Action
- Score
- Notes

داده‌ها داخل مرورگر موبایل با `localStorage` ذخیره می‌شوند و اینترنت لازم ندارند.

## اجرای سریع روی ویندوز

داخل ریشه پروژه:

```powershell
cd .\tools\alpha_lens_mobile
python -m http.server 8787
```

بعد در موبایل، اگر موبایل و کامپیوتر روی یک Wi-Fi هستند، آدرس IP کامپیوتر را باز کن:

```text
http://YOUR-PC-IP:8787
```

نمونه:

```text
http://192.168.1.25:8787
```

## نصب روی موبایل مثل اپ

### Android / Chrome

1. صفحه را در Chrome باز کن.
2. منوی سه‌نقطه را بزن.
3. `Add to Home screen` یا `Install app` را بزن.
4. بعد از نصب، اپ آفلاین باز می‌شود.

### iPhone / Safari

1. صفحه را در Safari باز کن.
2. Share را بزن.
3. `Add to Home Screen` را بزن.

نکته: روی iPhone برای PWA بهتر است ابتدا یک بار صفحه کامل load شود. بعد از آن داده‌ها محلی ذخیره می‌شوند.

## خروجی و بکاپ

از دکمه `خروجی JSON` می‌توانی وضعیت فعلی و Snapshotها را بکاپ بگیری.
از دکمه `ورود JSON` می‌توانی بکاپ را برگردانی.
