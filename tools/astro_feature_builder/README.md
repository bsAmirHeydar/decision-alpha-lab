# Astro Feature Builder

This tool generates deterministic candle-by-candle astrological feature stores for MQL5 Strategy Tester and live execution.

The engine is Python-first for ephemeris generation and MQL5-first for execution and visualization.

## Install

```powershell
python -m pip install -r tools/astro_feature_builder/requirements.txt
```

## Generate M1 features

```powershell
python tools/astro_feature_builder/astro_feature_builder.py `
  --start-broker "2024-01-01 00:00:00" `
  --end-broker "2024-02-01 00:00:00" `
  --timeframe-minutes 1 `
  --broker-gmt-offset-hours 2 `
  --ephe-path "tools/astro_feature_builder/ephe" `
  --out "astro_XAUUSD_M1_202401.csv"
```

Copy the output CSV to the terminal data folder:

```text
<META_TRADER_DATA_FOLDER>/MQL5/Files/astro/astro_XAUUSD_M1_202401.csv
```

Then set the MQL5 input:

```text
InpAstroCsvFile = astro/astro_XAUUSD_M1_202401.csv
InpBrokerGmtOffsetHours = 2
```

## Time contract

The CSV is generated by broker bar-open time.

```text
broker_time = UTC + broker_gmt_offset_hours
utc_time    = broker_time - broker_gmt_offset_hours
```

If broker time is UTC+2, use:

```text
--broker-gmt-offset-hours 2
```

The MQL5 side matches `iTime(symbol, timeframe, shift)` against `broker_time` in the CSV.

## Philosophy

The generated feature store is causal. Every row represents the sky state at the candle open time. It does not use future market data or future astrological values.
