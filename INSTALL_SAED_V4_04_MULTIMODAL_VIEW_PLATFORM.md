# Install SAED V4-04

Apply this patch only after V4-00 through V4-03 are present.

1. Expand the ZIP into the repository root.
2. Run `python tools/strategy_factory/saed_v4_04/run_saed_v4_04_full_qa.py`.
3. On Windows with MetaTrader 5, run the MetaEditor compile script and retain the logs as external actual evidence.
4. Stage only paths in `SAED_V4_04_FILE_INDEX.txt`.

Static MQL5 validation is not MetaEditor compile evidence.
