# Tools

این بخش برای ابزارهایی است که مستقیماً اندیکاتور نیستند اما خط تولید محصول را سریع‌تر، تمیزتر یا قابل فروش‌تر می‌کنند.

نمونه ابزارها:

- License generator
- Release packager
- Screenshot collector
- Validation report builder
- Customer registry exporter
- Pricing and plan tracker

## ساخت ابزار جدید

```powershell
.\product_lab\scripts\New-ProductLabItem.ps1 -Type tool -Slug "release-packager" -Title "Release Packager"
```
