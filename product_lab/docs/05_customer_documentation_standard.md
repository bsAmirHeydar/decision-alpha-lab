# استاندارد مستندات مشتری

مستند مشتری باید ساده‌تر از مستند داخلی باشد. مشتری نباید برای استفاده از محصول مجبور شود معماری کل پروژه را بفهمد.

## ساختار راهنمای مشتری

```text
1. این ابزار چیست؟
2. برای چه کسی مناسب است؟
3. چه چیزی را نشان می‌دهد؟
4. نصب در MetaTrader یا پلتفرم هدف
5. ورودی‌های مهم
6. مثال‌های تصویری
7. محدودیت‌ها
8. خطاهای رایج
9. دریافت پشتیبانی
10. تغییرات نسخه
```

## زبان مجاز

مجاز:

- «این ابزار کمک می‌کند...»
- «این وضعیت را هایلایت می‌کند...»
- «برای تحلیل شخصی و تست استفاده شود...»

نامناسب:

- «قطعاً وارد شو»
- «بدون ضرر»
- «سود ثابت»
- «جایگزین مدیریت ریسک»

## کیفیت تصویری

هر محصول باید حداقل این تصاویر را داشته باشد:

- چارت خام قبل از ابزار
- چارت بعد از فعال‌سازی ابزار
- نمونه ورودی‌ها
- نمونه خطا یا محدودیت
- نمونه خروجی درست
- نمونه خروجی که نباید بیش‌تفسیر شود
