# عملیات لایسنس، فروش و پشتیبانی

این سند چارچوب عملی فروش اشتراکی اندیکاتورها و ابزارها را مشخص می‌کند.

## اطلاعات هر مشتری

برای هر مشتری باید این اطلاعات ثبت شود:

| فیلد | توضیح |
|---|---|
| Customer ID | شناسه داخلی مثل `user0001` |
| Full Name | نام و نام خانوادگی |
| Email / Telegram | مسیر ارتباطی |
| Product | محصول خریداری‌شده |
| Plan | ماهانه، سالانه، Lifetime محدود |
| License Key | کلید لایسنس |
| Start Date | تاریخ شروع |
| Expiry Date | تاریخ پایان |
| Machine/Account Binding | وابستگی به دستگاه یا حساب، اگر وجود دارد |
| Support Status | فعال، منقضی، مسدود، تستی |

## سیاست پشتیبانی

سطح پشتیبانی باید از اول مشخص باشد. پیشنهاد:

| پلن | پشتیبانی |
|---|---|
| Starter | فقط راهنمای نصب و FAQ |
| Pro | پشتیبانی پیام متنی محدود |
| Elite | بررسی موردی اسکرین‌شات و آپدیت زودتر |

## قوانین ضد سوءاستفاده

- هر کلید لایسنس باید قابل ردیابی باشد.
- انتشار عمومی فایل بدون لایسنس نباید محصول را قابل استفاده کامل کند.
- نسخه Beta باید زمان‌دار باشد.
- فایل‌های مشتری نباید شامل مستندات داخلی و الگوریتم‌های حساس باشند.

## پیام فروش سالم

محصول باید با زبان حرفه‌ای فروخته شود؛ نه با وعده سود. محور فروش:

- کاهش آشفتگی تصمیم
- استانداردسازی مشاهده
- سرعت‌بخشیدن به تحلیل
- آماده‌سازی برای ژورنال و تست

## مسیر تبدیل لید به مشتری

1. نمایش یک مسئله واقعی در چارت.
2. نمایش اینکه ابزار چطور همان مسئله را تمیزتر می‌کند.
3. ارائه نسخه Demo یا ویدئوی کوتاه.
4. فروش پلن سبک ماهانه.
5. گرفتن بازخورد و ارتقا به Pro.
