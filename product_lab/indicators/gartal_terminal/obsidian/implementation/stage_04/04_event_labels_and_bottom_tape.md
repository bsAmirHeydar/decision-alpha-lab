# Event Labels and Bottom Tape

## Event Labels

Labels are chart-anchored `OBJ_TEXT` objects at event broker time. They are rotated vertically to reduce collision and placed in multiple rows near the lower chart region.

## Bottom Tape

The bottom tape is a screen-space summary of the next visible events. It acts like the Forex Factory center list compressed into an on-chart terminal.

## Collision Doctrine

Stage 04 uses row cycling, not full collision solving. Full adaptive collision management belongs to later UI polish after real data density is known.
