# Utility Presets

## RED ONLY

Shows only high-impact events. This is the fastest mode for traders who only care about high-risk macro moments.

## ALL IMP

Enables all impact categories.

## ALL CCY

Restores the core Forex Factory currency set:

```text
USD,EUR,GBP,JPY,CHF,CAD,AUD,NZD,CNY
```

## RESET

Restores runtime filters from MT5 input defaults.
