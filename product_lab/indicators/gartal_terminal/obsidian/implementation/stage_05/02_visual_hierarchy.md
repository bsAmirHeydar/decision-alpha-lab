# Visual Hierarchy

The dashboard prioritizes decision speed. The eye path is:

```text
Health -> Next Event -> Next Red -> Metrics -> Filters -> Table
```

## Design Logic

- Health badge tells whether the terminal is trustworthy.
- Next Event card answers: what matters next?
- Next Red card isolates high-risk macro events.
- Metrics summarize today's tape without reading rows.
- Filter preview tells what is currently included.
- Event table gives operational detail.

## Product Requirement

The surface must look premium enough for paid users before live data is connected.
