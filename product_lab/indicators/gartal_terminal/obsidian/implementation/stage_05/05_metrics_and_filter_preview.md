# Metrics and Filter Preview

## Metrics

The metric cards show:

```text
RED
ORANGE
YELLOW
SPEECH
BREAK
VISIBLE
```

These are sourced from `GT_NewsStore` counters.

## Filter Preview

The filter strip is visual in Stage 05. It shows whether high, medium, low, speech, and breaking filters are enabled. Stage 06 will turn these badges into runtime click targets.
