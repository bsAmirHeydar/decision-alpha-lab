# Product Spec — gartal terminal

## 1. مسئله

تریدرها قبل از ورود یا مدیریت معامله باید بدانند چه خبرهای مهمی در پیش است. مشکل این است که تقویم اقتصادی بیرون از چارت است و ذهن تریدر باید بین چارت، سایت خبری، ساعت بروکر، ساعت محلی، جفت‌ارز و شدت خبر رفت‌وبرگشت کند. این رفت‌وبرگشت باعث خطا، فراموشی، ورود بد، خروج احساسی و نادیده گرفتن ریسک زمان می‌شود.

`gartal terminal` این مسئله را حل می‌کند: خبر باید دقیقاً همان‌جایی دیده شود که تصمیم گرفته می‌شود؛ روی چارت.

## 2. هدف محصول

ساخت یک ترمینال خبری روی چارت که:

- خبرهای امروز را از منبع تقویم دریافت کند
- خبرها را بر اساس ارز، impact، نوع خبر و زمان فیلتر کند
- خبرهای آینده را در داشبورد و پایین چارت نشان دهد
- روی زمان خبر در چارت خط/marker رسم کند
- برای هر خبر هشدار قبل/حین/بعد بدهد
- برای فروش اشتراکی و لایسنس آماده باشد

## 3. کاربر هدف

### کاربر اصلی

- تریدر فارکس/طلا/شاخص‌ها
- استفاده‌کننده MT5
- نیازمند آگاهی از NFP, CPI, FOMC, Rate Decision, GDP, PMI, Unemployment, Retail Sales
- ممکن است پراپ تریدر باشد و نمی‌خواهد اطراف خبرهای قرمز وارد ریسک ناخواسته شود

### کاربر پیشرفته

- تریدر خبرمحور
- تریدر اسکالپ روی سشن‌های لندن/نیویورک
- سیستم‌تریدر یا اکسپرت‌نویس که می‌خواهد news filter را کنار استراتژی بگذارد

## 4. ارزش پیشنهادی

- حذف نیاز به چک‌کردن دستی Forex Factory
- کاهش ریسک ورود نزدیک خبرهای high impact
- دیدن کل نقشه خبری روز روی چارت
- هشدار دقیق قبل از خبر
- قابلیت تمرکز فقط روی ارزهای relevant چارت
- UI لوکس و قابل فروش

## 5. دامنه نسخه اول

### داخل دامنه

- تقویم اقتصادی امروز
- بازه configurable: today / tomorrow / week / custom days
- فیلتر ارزها
- فیلتر impact
- فیلتر speech/tentative/holiday/breaking
- داشبورد
- خط زمانی پایین چارت
- خطوط عمودی خبر
- alert engine
- broker GMT input
- auto GMT detection طراحی‌شده
- cache داخلی

### خارج از دامنه نسخه اول

- معامله خودکار
- تحلیل جهت خبر
- پیش‌بینی actual/forecast
- NLP روی متن خبرها
- فروشگاه/پرداخت
- لایسنس آنلاین نهایی

## 6. Naming

- Internal slug: `gartal_terminal`
- Product display: `gartal terminal`
- Indicator file: `GartalTerminal.mq5`
- Object prefix: `GT_`
- Global variable prefix: `GTNEWS_`

## 7. UX Promise

کاربر باید با یک نگاه بفهمد:

1. خبر بعدی چیست؟
2. چند دقیقه مانده؟
3. مربوط به کدام ارز است؟
4. شدت آن چیست؟
5. آیا چارت فعلی را تحت تأثیر قرار می‌دهد؟
6. alert روشن است یا نه؟
