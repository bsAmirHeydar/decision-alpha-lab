# 00 — gartal terminal START HERE

این صفحه ورودی Obsidian برای محصول `gartal terminal` است.

## جمله مرکزی محصول

`gartal terminal` تقویم اقتصادی را از حالت جدول بیرونی خارج می‌کند و به یک ترمینال زمانی زنده روی چارت تبدیل می‌کند؛ یعنی تریدر بدون خروج از چارت می‌فهمد امروز چه خبرهایی، برای کدام ارزها، در چه ساعتی، با چه شدت و با چه ریسک زمانی در پیش است.

## اصل طراحی

اندیکاتور نباید فقط خبر را «نشان بدهد». باید ریسک زمانی بازار را قابل دیدن کند.

بنابراین سه لایه دارد:

1. **Macro Feed Layer** — دریافت و نرمال‌سازی خبر
2. **Terminal Layer** — داشبورد و فیلترهای تعاملی
3. **Chart Intelligence Layer** — تبدیل خبر به object زمانی روی چارت

## تصمیم‌های قفل‌شده

- نام محصول: `gartal terminal`
- منبع اولیه: Forex Factory Calendar
- مبنای نمایش: تقویم امروز، قابل تغییر با input
- دسته‌بندی: ارز محور، نه XAU/BTC محور
- XAU به شکل مستقیم خبر ندارد؛ برای طلا، خبرهای USD و ریسک‌های High Impact مهم‌ترند
- خط زمانی پایین چارت باید خبرهای باقی‌مانده روز را جلوتر از قیمت فعلی نمایش دهد
- فیلترها باید داخل خود داشبورد قابل کنترل باشند، نه فقط input پنجره اندیکاتور
- broker GMT offset باید input داشته باشد و auto-detect هم طراحی شود
- UI باید لوکس، مینیمال، تاریک، تمیز و محصولی باشد

## تعریف موفقیت نسخه اول

نسخه اول وقتی قابل قبول است که:

- اخبار امروز را بدون خروج از چارت نشان دهد
- زمان‌ها را به broker time درست تبدیل کند
- رنگ impact اشتباه نداشته باشد
- داشبورد قابل خواندن باشد
- alert دوبار یا چندبار تکراری ندهد
- اگر منبع داده fail شد، چارت خراب نشود
- اگر ساختار Forex Factory عوض شد، فقط data adapter نیاز به تغییر داشته باشد
