# Install FP-I11

1. Place the ZIP in the repository root.
2. Expand it into the repository root with overwrite enabled.
3. Delete the ZIP from the repository root.
4. Stage only paths in `EXP0019_FP_I11_FILE_INDEX.txt`.
5. Commit using `COMMIT_MESSAGE.md`.
6. Push `main`.
7. Compile the production and self-test indicators in MetaEditor.
