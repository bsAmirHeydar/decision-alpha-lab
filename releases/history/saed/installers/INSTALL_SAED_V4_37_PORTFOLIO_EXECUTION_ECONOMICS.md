# Install SAED V4-37

1. Place the ZIP patch in the repository root.
2. Expand it into the repository root with overwrite enabled.
3. Remove the ZIP from the repository root.
4. Run full QA and delivery validation.
5. Stage only paths in `SAED_V4_37_FILE_INDEX.txt`.
6. Validate staged diff, commit with `COMMIT_MESSAGE.md`, and push.

V4-36 must already be installed. Capability files are additive; the canonical V4-37 roadmap note and root commit metadata are updated in place.
