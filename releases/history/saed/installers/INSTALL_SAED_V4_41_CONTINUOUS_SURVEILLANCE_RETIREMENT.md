# Install SAED V4-41

1. Place the V4-41 ZIP patch in the repository root.
2. Expand it with overwrite enabled.
3. Remove the ZIP from the repository root.
4. Run V4-41 full QA and delivery validation.
5. Stage only paths listed in `SAED_V4_41_FILE_INDEX.txt`.
6. Check the staged diff, commit with `COMMIT_MESSAGE.md`, and push.

SAED V4-40 must already be installed. This patch closes the numbered SAED V4 reference roadmap and hands the system to continuous operations and external qualification; it does not infer production authority from reference completion.
