# Installation

Expand the patch at repository root, remove the ZIP, run `python tools/strategy_factory/saed_v4_15/run_saed_v4_15_full_qa.py`, then run `python tools/strategy_factory/saed_v4_15/validate_saed_v4_15_delivery.py`. Stage only paths listed in `SAED_V4_15_FILE_INDEX.txt`, review the staged diff, commit with `COMMIT_MESSAGE.md`, and push.
