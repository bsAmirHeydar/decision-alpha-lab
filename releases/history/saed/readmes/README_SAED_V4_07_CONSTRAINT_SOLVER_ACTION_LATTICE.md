# SAED V4-07 — Constraint Solver and Action Lattice

This patch implements the bounded deterministic structural solver between the V4-06 finite Treatment DSL and the V4-08 Executable Path Outcome Cube. It adds exact parameter-domain contracts, candidate enumeration, frozen constraint evaluation, feasibility certificates, pruning and exposure ledgers, mandatory Skip/Abstain fallback, atomic adjacency DAG construction, deterministic replay/diff/partitioning, integrity receipts, CLI, closed schemas, golden and negative fixtures, tests, diagnostic-only MQL5 mirrors, Obsidian implementation notes and bounded handoff artifacts.

The patch does not train models, use realized outcomes, rank treatments, allocate risk, activate runtime or place orders. MetaEditor compilation and external reproduction remain pending evidence gates.
