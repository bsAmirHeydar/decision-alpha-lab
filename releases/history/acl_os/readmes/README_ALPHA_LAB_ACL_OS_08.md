# Alpha Lab ACL-08 — Reporting and Experience

ACL-08 consumes the immutable ACL-07 validation package and produces deterministic Batch, candidate and executive reports, audience-specific redacted views, non-promotional experience records, Obsidian projections, event/provenance evidence and an immutable ACL-09 handoff.

Claim ceiling: `REPORTING_AND_EXPERIENCE_REFERENCE_ONLY`.

The implementation does not infer alpha, ingest durable memory, plan or run research, promote candidates, submit orders or activate capital.
