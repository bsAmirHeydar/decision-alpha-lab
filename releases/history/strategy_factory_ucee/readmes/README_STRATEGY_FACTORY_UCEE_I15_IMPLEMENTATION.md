# Strategy Factory UCE-I15 — First Real-Context Tournament

UCE-I15 provides the complete deterministic tournament and prospective-paper governance path for EXP0017 and Hook/Zone. It freezes context, treatment, algorithm, fold, budget, metric, gate, and runtime identities; retains the full declared trial universe; reconciles expected and observed paper behavior; and produces a champion, pending, challenge, or legitimate rejection decision.

- `strategy_factory_tournament_v3`: 22 Python modules.
- `tournament_*.schema.json`: 25 closed schemas.
- `examples/uce_i15`: EXP0017 and Hook/Zone fixtures, frozen universes, reference tournament, prospective plan/report, decision, evidence, capability, and real-data templates.
- `ContextTournament`: 10 MQL5 includes plus four diagnostic/self-test experts.
- `phase_uce_i15_real_context_tournament`: 116 contract, causality, determinism, freeze, ledger, tournament, prospective, decision, schema, CLI, and boundary tests.
- 43 detailed implementation chapters and 12 atomic Obsidian concepts.

## Evidence classification

The repository contains reference fixtures, not a real historical market dataset or a completed prospective paper period. The reference tournament therefore proves infrastructure closure and deterministic rejection. It does not assert market edge and cannot promote a champion.
