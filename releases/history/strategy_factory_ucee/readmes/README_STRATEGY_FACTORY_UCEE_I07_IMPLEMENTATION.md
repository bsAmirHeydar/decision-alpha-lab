# UCEE-I07 — Universal Trainer SDK, Capability Registry, and Task Orchestrator

This patch implements the seventh UCEE execution phase. It adds exact-version trainer capabilities and registration, task-aware compatibility routing, role-guarded datasets, final-test sealing, fold-local OOF orchestration, calibration and threshold partitions, deterministic resource budgets, cancellation and timeout semantics, complete prediction lineage and access audits, retained failed-trial ledgers, canonical model-state and artifact contracts, three reference trainer families, Python and MQL5 conformance surfaces, closed JSON schemas, golden vectors, cumulative tests, and detailed English Obsidian documentation.

The delivery is an offline research control plane. It adds no market, inference, risk, execution, network, or live-order authority. Reference trainers are conformance oracles and are explicitly not production edge models.
