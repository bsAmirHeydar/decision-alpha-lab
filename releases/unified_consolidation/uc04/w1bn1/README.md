# UC04-W1B-N1 Native Host Qualification Hardening

This release adds a Windows PowerShell 5.1-compatible native qualification runner for the already-characterized deterministic MQL5 datetime formatter candidate. It changes no production consumer, trading rule, execution authority, context, model or market-data contract.

The runner performs isolated MetaEditor compilation, test-only MT5 runtime verification, independent evidence review, optional non-apply candidate generation and sanitized evidence export outside the repository.
