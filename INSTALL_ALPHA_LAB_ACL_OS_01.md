# Install ACL-OS ACL-01

1. Expand the ZIP at repository root.
2. Remove the ZIP.
3. Run ACL-01 full QA and delivery validation.
4. Stage only `ACL_OS_01_FILE_INDEX.txt` paths.
5. Commit using `COMMIT_MESSAGE.md` and push.

The patch assumes the ACL-OS architecture baseline and ACL-00 are already installed.
