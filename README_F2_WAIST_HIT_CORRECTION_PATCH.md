# F2 Waist-Hit Correction Patch

This documentation-only patch corrects the F2 Case B doctrine in the Zone-Centric Antifragile Alpha documentation.

## What changed

The previous text described F2 Case B too loosely as “F2 makes point 1/2 and also hits the waist.”

The corrected interpretation is:

- F2 may hit its own waist.
- That waist-hit can become Point 1.
- The following hit/extension becomes Point 2.
- From Point 2 and beyond, reversal potential becomes active.
- The case is still usually a parent watch/reversal-potential zone, not a direct parent execution zone.
- Lower-timeframe child-zone refinement is required unless a stable stop edge exists.
